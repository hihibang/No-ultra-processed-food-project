# 요리명: 비름나물 된장무침

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 60.3 kcal
- 나트륨 함량: 130.4 mg

## 필요한 재료
•필수 재료 : 비름나물(70g), 양파(10g), 마늘(3g), 생강(1g)
•다시마 육수 : 물(200g), 다시마(5g)
•양념장 :  된장(2g), 고추장(1g), 마요네즈(2g), 고춧가루(1g)
•양념 : 참깨(1g), 참기름(4g)

## 조리 순서
1. 비름나물을 적당한 길이로 잘라 다시마육수에 데친 뒤 찬물에 헹궈 물기를 뺀다., 2. 양파는 2mm 두께로 채 썰고 생강과 마늘은 곱게 다진다., 3. 된장을 곱게 다진 뒤 구멍이 큰 체에 걸러 식감을 살리고 고추장, 마요네즈, 고춧가루와 섞는다., 4. 양념장에 다진 생강, 마늘을 섞는다., 5. 비름나물에 양파, 양념장을 넣고 골고루 무친다., 6. 참기름을 둘러 가볍게 섞은 뒤 깨를 뿌려 마무리한다.
