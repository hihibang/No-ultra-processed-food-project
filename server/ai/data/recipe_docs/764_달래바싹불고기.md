# 요리명: 달래바싹불고기

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 굽기
- 열량(칼로리): 197.0 kcal
- 나트륨 함량: 237.6 mg

## 필요한 재료
주재료: 쇠고기등심 60, 달래 5, 올리브유 5 양념장: 간장 4, 설탕 3, 다진 양파 15, 다진 마늘 2, 후추 0.01

## 조리 순서
1. 달래를 3cm 길이로 썬다., 2. 양념장 재료를 모두 섞어 양념장을 만든다., 3. 소고기에 달래와 양념장을 넣고 간이 배도록 잘 주무른다., 4. 기름 두른 팬에 양념한 고기를 한 덩이씩 떼서 모양을 잡아준다., 5. 뭉친 고기는 앞뒤로 고루 익혀낸다., 6. 그릇에 담아 마무리 한다.
