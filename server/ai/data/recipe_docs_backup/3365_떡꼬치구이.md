# 요리명: 떡꼬치구이

## 기본 정보
- 요리 분류: 기타
- 조리 방식: 굽기
- 열량(칼로리): 160.9 kcal
- 나트륨 함량: 214.0 mg

## 필요한 재료
•필수 재료 : 떡볶이떡(40g), 파(3.5g), 양파(7g), 식용유(3g)
•양념장 : 케첩(8g), 스리라차(3g), 올리고당(2g), 다진마늘(2g), 간장(1g), 참기름(1g), 통깨(0.5g)

## 조리 순서
1. 떡볶이 떡은 끓는 물에 데쳐 건진다., 2. 꼬치에 데친 떡을 꽂는다., 3. 파와 양파는 다진다., 4. 양념장 재료에 다진 양파와 파를 섞어 양념장을 만든다., 5. 팬에 식용유를 두른 뒤 양념장을 볶는다., 6. 양념장을 떡꼬치에 묻힌 뒤 통깨를 뿌려 마무리한다.
