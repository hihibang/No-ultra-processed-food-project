# 요리명: 파인애플떡갈비

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 굽기
- 열량(칼로리): 336.8 kcal
- 나트륨 함량: 21.1 mg

## 필요한 재료
소고기(갈빗살, 60g), 파인애플(45g),
양파(8g), 표고버섯(7g), 전분(10g),
파(5g), 마늘(2g), 진간장(3g), 설탕(1g),
참기름(1.5g), 후춧가루(0.2g)

## 조리 순서
1. 파인애플은 7cm로 자르고 남은 자투리와 파, 마늘, 양파, 표고버섯은 곱게 다진다., 2. 갈빗살은 곱게 다져 간장, 설탕, 파, 마늘, 참기름, 추후로 양념한다., 3. 다진 파인애플, 양파, 표고버섯은 볶아 수분을 제거한다., 4. 전분 일부와 갈빗살, 다진 파인애플, 양파, 표고버섯을 섞고 치댄다., 5. 잘라둔 파인애플에 남은 전분을 묻힌 뒤 고기반죽으로 감싼다., 6. 팬 또는 오븐(180℃, 15분)에 노릇하게 굽는다.
