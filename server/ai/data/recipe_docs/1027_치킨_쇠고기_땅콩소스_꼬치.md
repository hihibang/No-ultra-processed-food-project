# 요리명: 치킨 쇠고기 땅콩소스 꼬치

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 굽기
- 열량(칼로리): 148.0 kcal
- 나트륨 함량: 536.0 mg

## 필요한 재료
닭가슴살 30g, 쇠고기 등심 30g, 간장 3g, 카레가루 2g, 땅콩버터 3g, 참기름 0.5g, 올리브오일 2g, 설탕 1.5g, 생강다진것 1g

## 조리 순서
1. 닭가슴살과 소고기안심을 먹기 좋은 크기로 자른다., 2. 간장, 카레가루, 땅콩버서, 참기름, 올리브오일, 설탕, 다진 생강을 섞어 소스를 만든다., 3. 꼬치에 1을 번갈아 끼운다., 4. 고기를 끼운 꼬치에 2의 소스를 바른다., 5. 오븐을 176℃로 예열한다., 6. 예열된 오븐에 소스를 바른 꼬치를 구워준다.
