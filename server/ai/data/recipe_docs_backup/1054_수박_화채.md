# 요리명: 수박 화채

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 기타
- 열량(칼로리): 126.0 kcal
- 나트륨 함량: 2.0 mg

## 필요한 재료
찹쌀가루 12g, 물 8g, 수박 180g, 팥 5g, 설탕 5g

## 조리 순서
1. 찹쌀가루에 뜨거운 물을 넣어 익반죽을 한다., 2. 찹쌀 반죽을 동그랗게 빚는다., 3. 찹쌀 경단을 끓는 물에 삶은 뒤 차갑게 식힌다., 4. 수박은 씨를 제거한 뒤 곱게 갈아 차갑게 식힌다., 5. 그릇에 3과 4를 넣는다., 6. 기호에 따라 팥을 삶아 설탕에 졸여 넣는다.
