# 요리명: 카레감자전

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 굽기
- 열량(칼로리): 186.9 kcal
- 나트륨 함량: 491.9 mg

## 필요한 재료
감자 150g, 유기농 밀가루 50g, 카레가루 15g, 양파 70g, 루콜라 3g, 마늘기름 30g
소스 : 발사믹식초 30g, 저염간장 15g, 설탕 15g

## 조리 순서
1. 감자는 껍질을 벗겨서 1개를 채 썰고 물에 담가둔다., 2. 감자 1개는 강판에 갈아서 즙과 건지를 따로 분리해준다., 3. 양파를 곱게 채 썰어주고 볼에 강판에 간 건지와 채 썬 감자, 채 썬 양파를 섞어 반죽을 만들어 준다., 4. 소스를 만들어준다., 5. 팬에 한입 크기로 전을 부쳐준다., 6. 루콜라를 물에 살짝 헹궈주고 전과 함께 접시에 셋팅한다.
