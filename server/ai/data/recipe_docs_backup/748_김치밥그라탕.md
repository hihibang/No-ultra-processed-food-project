# 요리명: 김치밥그라탕

## 기본 정보
- 요리 분류: 밥
- 조리 방식: 굽기
- 열량(칼로리): 515.1 kcal
- 나트륨 함량: 679.8 mg

## 필요한 재료
밥 180, 배추김치(줄기부분) 30, 양파 20, 생 표고버섯 40, 방울토마토 200, 올리브유 12, 간장 4, 피자치즈(모짜렐라) 30, 다진 실파 5

## 조리 순서
1. 김치, 양파, 버섯은 다진다., 2. 방울토마토는 4등분한다., 3. 팬에 올리브유를 두르고 김치, 양파, 버섯, 토마토를 볶는다., 4. 밥을 넣어 볶은 뒤 간장으로 간한다., 5. 3, 4를 그릇에 담고 피자치즈를 올려 전자렌지에 치즈가 녹을 정도로 익힌다., 6. 실파를 뿌려 마무리한다.
