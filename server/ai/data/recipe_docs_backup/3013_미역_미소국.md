# 요리명: 미역 미소국

## 기본 정보
- 요리 분류: 국&찌개
- 조리 방식: 끓이기
- 열량(칼로리): 15.1 kcal
- 나트륨 함량: 196.8 mg

## 필요한 재료
•필수 재료 : 건미역(2g), 가다랑어포(0.3g)
•양념 : 미소된장(3g), 미향(0.3g), 물(350g)

## 조리 순서
1. 건미역을 물에 불린다., 2. 불린 미역을 잘게 썬다., 3. 냄비에 물(350g)과 가다랑어포를 넣어 우려내 육수를 만든다., 4. 육수에 미소된장을 곱게 푼다., 5. 국에 미역을 넣어 한소끔 끓인다., 6. 미향을 넣어 마무리한다.
