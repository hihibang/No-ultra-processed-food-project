# 요리명: 전복내장밥

## 기본 정보
- 요리 분류: 밥
- 조리 방식: 끓이기
- 열량(칼로리): 279.8 kcal
- 나트륨 함량: 183.8 mg

## 필요한 재료
전복 100g, 칵테일새우 25g, 바지락살 25g, 당근 15g, 연근 25g, 단호박 25g
찹쌀 50g, 다진마늘 7g, 참기름 15g, 소주 15g, 흰후추 1g, 마늘기름 15g

## 조리 순서
1. 전복은 손질해 잘라주고 전복내장과 소주를 넣어서 믹서에 간다., 2. 참기름과 마늘기름을 섞어서 불린 쌀을 볶는다., 3. 연근, 당근, 단호박은 작은 깍두기 모양으로 잘라 각각 볶아준다., 4. 전복은 작은 깍두기 모양으로 잘라서 칵테일새우, 바지락살, 다진마늘, 청주를 넣어 살짝 볶아준다., 5. 냄비에 갈아준 전복내장을 만들어준 기름에 볶아주다 쌀을 넣고 볶고, 나머지 채소를 넣어 볶는다., 6. 마지막으로 새우, 바지락을 넣고 볶아 완성한다.
