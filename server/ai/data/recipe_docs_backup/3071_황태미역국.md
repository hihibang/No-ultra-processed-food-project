# 요리명: 황태미역국

## 기본 정보
- 요리 분류: 국&찌개
- 조리 방식: 끓이기
- 열량(칼로리): 46.0 kcal
- 나트륨 함량: 170.4 mg

## 필요한 재료
•필수 재료 : 건미역(2g), 황태(4g)
•육수 : 황태머리(5g), 다시마(1g), 표고버섯(1g), 대파(1g), 물(250g)
•양념 : 참기름(1g), 다진마늘(1g), 저염국간장(2g)

## 조리 순서
1. 물과 육수 재료를 넣고 끓여 육수를 만든다., 2. 끓인 육수를 체에 거른다., 3. 건미역과 황태를 물에 불린 후, 먹기 좋은 크기로 썬다., 4. 냄비에 참기름을 두르고 미역과 황태를 넣어 볶는다., 5. 냄비에 육수를 넣고 끓인다, 6. 다진마늘과 저염국간장으로 간을 맞춰 마무리한다.
