# 핑퐁 (PingPong) — 성분·가공도 기반 건강 식품 탐색 & AI 레시피 챗봇

## 시연 영상

[핑퐁 시연 영상 보기 (YouTube)]([https://youtu.be/4EMrAx_Q70w])

---

원재료·첨가물·영양성분 데이터를 바탕으로 식품의 초가공식품(UPF) 가공 정도와 건강 점수를 판별하고, 비슷한 식품 비교, 협업 필터링 추천, 주방 환경 맞춤형 AI 레시피 챗봇을 제공하는 웹 서비스 프로젝트입니다.

### 주요 기능

- **가공도 판별 및 건강 점수:** NOVA 등급 기준과 영양 성분·첨가물 조건을 반영해 식품별 건강 점수를 산출하고 직관적으로 확인
- **유사 식품 비교:** 후보 식품 간 영양 성분과 가공도, 개선 포인트를 나란히 비교
- **AI 맞춤형 레시피 챗봇:** 사용자 취향·보유 주방 도구·식이 제한 프로필을 반영한 레시피 추천 및 연관 상품 매칭
- **맞춤형 추천 & 기록:** 유사 취향 기반 추천, 푸드저널, 마이페이지 레시피 보관함 제공

### 프로젝트 구성

- `front/`: 홈, 상품 카탈로그·비교, AI 레시피 챗봇, 푸드저널, 마이페이지 등을 구현한 프론트엔드
- `server/`: 식품·비교·추천·챗봇 세션 등 핵심 API 및 점수/매칭 로직을 담당하는 백엔드
- `n8n` / AI·데이터 파이프라인: 공공데이터 적재 및 프로필·조리도구 제약 반영 레시피 추천 워크플로우

> 실제 운영 환경 설정값, API 키, 대용량 원본 데이터 등 민감하거나 용량이 큰 파일은 저장소에 포함하지 않습니다.
