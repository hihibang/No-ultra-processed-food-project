4개 수정사항 중 '2. 레시피 챗봇: 유사 유저 / 인플루언서 레시피' 기능을 구현해줘.

### 목표 및 원칙
1. **데이터 오염 방지:** 일반 유저가 임의로 수정하거나 저장한 챗봇 레시피 텍스트는 벡터 DB나 일반 검색 풀에 섞지 않고 기존 품질을 유지해줘.
2. **맥락 기반 노출:** 챗봇 첫 진입 화면(초기 인사/빈 화면)에 바로 띄우지 말고, 레시피/식단 추천 응답이 생성될 때(또는 관련 맥락이 있을 때) *"내가 찜한 인플루언서"* 또는 *"비슷한 취향의 유저들이 선호하는 인플루언서 레시피"*를 함께 제안해줘.

### 1. 백엔드 구현/연동 요구사항
- 인플루언서 레시피 테이블/데이터와 유저의 인플루언서 찜(팔로우) 이력, 그리고 유저 간 유사도(협업 필터링) 데이터를 확인해줘.
- 레시피 챗봇 응답 생성/추천 API에서 다음 조건에 맞는 검증된 인플루언서 레시피 후보(예: 1~2개)를 내려주도록 구성해줘.
  1) 현재 로그인한 유저가 찜한 인플루언서의 레시피가 있다면 우선 반영(`source: "followed_influencer"`)
  2) 부족하거나 없는 경우, 나와 취향/찜/저장 이력이 비슷한 유사 유저들이 선호하는 인플루언서 레시피 반영(`source: "similar_user_influencer"`)
- 일반 유저의 커스텀/저장 레시피는 후보 풀에 포함하지 않도록 명확히 분리해줘.

### 2. 프론트엔드(챗봇 UI) 구현 요구사항
- 챗봇 첫 화면(대화가 시작되기 전 초기 상태)에서는 인플루언서/유사 유저 레시피 추천 카드를 노출하지 마.
- 레시피 추천 답변이 생성된 이후 맥락에 맞춰 답변 하단 또는 보조 영역에 인플루언서 레시피 카드를 보여줘.
  - 카드에는 레시피명, 크리에이터/인플루언서명, 그리고 맥락 배지(예: `내가 찜한 크리에이터 레시피` 또는 `유사 취향 유저 픽 인플루언서 레시피`)를 표시하고, 클릭 시 해당 레시피 상세/인플루언서 레시피 보기로 연결되도록 해줘.
  - 추천할 인플루언서 레시피가 없거나 초기 상태일 때는 억지로 띄우지 말고 깔끔하게 숨겨줘.

수정 후 기존 레시피 챗봇 답변과 '레시피 → 상품 추천' 영역에 깨지는 부분이 없는지, 그리고 첫 화면 미노출 + 레시피 답변 시 인플루언서 레시피 카드 노출 흐름이 자연스러운지 확인해줘.
