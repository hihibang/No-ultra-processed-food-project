# 요리명: 라이스버거떡갈비

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 굽기
- 열량(칼로리): 206.2 kcal
- 나트륨 함량: 206.1 mg

## 필요한 재료
라이스버거 : 밥 200g, 맛간장 15g, 전분가루 15g, 팽이버섯 20g, 흰후추 1g, 달걀 60g
떡갈비 : 다진소고기 50g, 다진돼지고기 50g, 다진양파 30g, 다진쪽파 15g, 맛간장 10g, 후추 1g
토마토겉절이 : 토마토 80g, 미나리 20g, 맛간장 5g, 청고추 15g, 홍고추 15g

## 조리 순서
1. 팽이버섯을 송송 다진 후 라이스버거 재료로 라이스버거를 만들어준다., 2. 만들어준 버거는 팬에 구워준다., 3. 토마토와 미나리를 먹기 좋게 잘라서 겉절이를 만들어준다., 4. 떡갈비 재료로 떡 갈비를 만들어준다., 5. 만들어진 떡갈비를 구워준다., 6. 접시에 토마토 겉절이를 담고 라이스버거와 떡갈비를 올려 완성한다.
