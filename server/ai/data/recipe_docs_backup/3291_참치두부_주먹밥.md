# 요리명: 참치두부 주먹밥

## 기본 정보
- 요리 분류: 밥
- 조리 방식: 기타
- 열량(칼로리): 299.7 kcal
- 나트륨 함량: 248.3 mg

## 필요한 재료
[ 2인분 ] 두부(1모=300g), 파프리카(빨강, 노랑 각 ¼개), 깻잎(4장), 잡곡밥(70g), 통조림 참치(50g), 스테비아(0.5Ts), 간장(0.5Ts), 참기름(1Ts)

## 조리 순서
1. 큰 볼에 두부를 담은 뒤 물이 담긴 무거운 그릇을 3분간 올려 수분을 제거한다., 2. 두부 속을 사각형 모양으로 파내고, 파낸 두부 속은 물기를 꼭 짜 으깬다., 3. 파프리카와 깻잎은 잘게 썬다., 4. 통조림 참치는 체에 밭친 뒤, 뜨거운 물을 부어 기름과 염분을 제거한다., 5. 볼에 으깬 두부, 손질한 채소, 잡곡밥, 참치를 넣은 뒤 양념해 고루 섞는다., 6. 주먹밥을 동그랗게 만들고, 속을 판 두부 속에 넣어 마무리한다.
