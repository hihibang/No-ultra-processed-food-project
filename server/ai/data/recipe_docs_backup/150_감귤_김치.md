# 요리명: 감귤 김치

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 21.2 kcal
- 나트륨 함량: 64.9 mg

## 필요한 재료
●주재료 : 배추 10g(1/60개), 미나리 5g, 홍고추 5g(1/2개), 소금 5g(1작은술)
●김치국물 : 귤 100g(1개), 고춧가루 5g(1작은술), 다진 마늘 10g(2작은술), 생강즙 5g(1작은술)

## 조리 순서
1. 귤은 껍질을 까서 믹서에 갈아 체에 내린다., 2. 배추는 3×3cm로 썰어 소금에 절인 후 체에 받치고 미나리, 홍고추는 길이 3cm로 썬다., 3. 귤즙에 고춧가루, 생강즙, 다진 마늘을 넣고 김치 국물을 만들고 배추, 미나리, 홍고추에 김치 국물을 부어 실온에 2일 숙성시킨다.
