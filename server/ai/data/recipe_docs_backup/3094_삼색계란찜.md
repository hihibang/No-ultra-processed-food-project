# 요리명: 삼색계란찜

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 찌기
- 열량(칼로리): 178.6 kcal
- 나트륨 함량: 459.1 mg

## 필요한 재료
계란 60g, 시금치 20g, 비트 10g, 우유 20g, 애플민트 1g, 다시마 3g, 소금 0.5g

## 조리 순서
1. 다시마를 물에 씻어 낸 후 찬물에 우려낸다., 2. 시금치와 비트는 다시마 우린물을 넣고 각각 갈아 준다., 3. 계란과 우유를 섞어 계란물을 만든다., 4. 계란물을 3등분 하여 나눠 담아 놓는다., 5. 나눠 놓은 계란물에 시금치, 비트를 각각 섞는다., 6. 3가지 계란물을 순서대로 쪄 내고, 애플민트로 장식한다.
