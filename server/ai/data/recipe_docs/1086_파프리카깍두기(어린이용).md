# 요리명: 파프리카깍두기(어린이용)

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 122.6 kcal
- 나트륨 함량: 19.1 mg

## 필요한 재료
무(80g), 파프리카(20g), 사과(5g),
현미(5g), 실파(0.5g), 멸치(5g), 마늘(3g),
멸치액젓(5g), 올리고당(2g), 천일염(5g)

## 조리 순서
1. 무를 깍둑썰기하여 소금에 30분  간 절인다., 2. 실파를 잘게 다진다., 3. 파프리카, 사과, 멸치액젓, 올리고당을 믹서에 넣고 간다., 4. 멸치로 다시물을 만들고 현미밥과 다시물을 1:1로 넣어 끓인 후 현미풀을 만든다., 5. 3번에 실파, 현미풀, 다진 마늘을 넣고 양념을 만든다., 6. 절인 무를 체에 받쳐 소금물을 제거하고 양념을 넣어 버무린다.
