# 요리명: 단호박 생선탕수, 키위소스

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 튀기기
- 열량(칼로리): 116.56 kcal
- 나트륨 함량: 140.65 mg

## 필요한 재료
동태살 120g, 단호박 10g, 당근 15g, 오이 15g, 양파 15g, 전분 30g, 계란 110g, 튀김가루 10g, 목이버섯 3g, 식초 15g, 키위소스 20g

## 조리 순서
1. 따뜻한 물에 부린 목이버섯, 동태살, 당근, 오이, 양파를 먹기 좋은 크기로 썬다., 2. 동태살에 소금과 흰후추로 밑간을 하고 녹말과 계란 흰자를 섞어 튀김옷을 만든다., 3. 동태살에 튀김옷을 입혀 기름에 튀긴다., 4. 물, 계란, 튀김가루를 섞어 튀김옷을 만든 뒤 단호박을 튀긴다., 5. 프라이팬에 기름을 두르고 당근, 양파, 목이버섯을 볶는다., 6. 5에 키위소스, 식초를 넣고 전분물을 넣어 농도를 맞춘 뒤 튀긴 재료와 오이를 섞는다.
