# 요리명: 바지락매생이전

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 굽기
- 열량(칼로리): 83.6 kcal
- 나트륨 함량: 386.1 mg

## 필요한 재료
매생이 30g, 바지락살 10g, 부침가루 5g, 튀김가루 5g, 홍고추 1g, 대두유 12g

## 조리 순서
1. 매생이와 바지락은 소금기를 없애기 위해 물에 여러 번 헹군다., 2. 튀김가루, 부침가루에 물을 넣고 반죽을 만든다., 3. 매생이를 잘게 다져 반죽에 섞어준다., 4. 팬에 매생이 반죽을 얹고 바지락살을 넣고 노릇하게 구워준다., 5. 구워진 전에 홍고추 고명을 얹어 준다., 6. 그릇에 담아 마무리 한다.
