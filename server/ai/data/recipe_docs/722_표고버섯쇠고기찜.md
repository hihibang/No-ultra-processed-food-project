# 요리명: 표고버섯쇠고기찜

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 찌기
- 열량(칼로리): 78.7 kcal
- 나트륨 함량: 318.4 mg

## 필요한 재료
표고버섯 30g, 다진 쇠고기 등심 20g, 양파 3g, 대파 2.5g, 다진 마늘 1.25g, 간장 3g, 설탕 2g, 참기름 1g, 말린 청양고추 0.5g

## 조리 순서
1. 표고버섯의 기둥을 떼 낸다., 2. 버섯 기둥과 양파, 대파는 다진다., 3. 말린 고추는 으깨준다., 4. 고기에 2, 3과 나머지 양념을 넣어 잘 치댄다., 5. 표고버섯에 양념한 고기를 채운다., 6. 찜기에 젖은 면보를 깔고 10분간 쪄 낸다.
