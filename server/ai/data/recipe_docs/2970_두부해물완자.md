# 요리명: 두부해물완자

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 116.15 kcal
- 나트륨 함량: 209.76 mg

## 필요한 재료
두부 50g, 오징어 14g, 칵테일 새우 14g, 감자전분 15g, 부침가루 10g, 계란 20g, 꿀 5g, 새우가루 5g, 마늘 2g, 파 2g, 양파 10g, 저염간장 5g

## 조리 순서
1. 두부를 으깨고 오징어와 새우는 잘게 다진다., 2. 볼에 1의 재료와 감자전분을 넣고 섞어 완자모양으로 만든다., 3. 감자전분과 부침가루를 섞어 완자에 묻힌다., 4. 가루를 묻힌 완자에 계란물을 입혀 기름 두른 팬에 굴려가며 익힌다., 5. 마늘과 파를 다진 뒤 새우가루, 꿀, 저염간장을 섞어 소스를 만든다., 6. 양파를 채 썰어 냄비에 소스와 함께 끓인 뒤 전분물을 넣어 농도를 맞추고 완자를 넣는다.
