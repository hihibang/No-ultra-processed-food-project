현재 개발 중인 AI 레시피 챗봇 프로젝트에 다음 기능들을 프론트엔드와 백엔드에 구현하려고 해. 아래 요구사항을 바탕으로 필요한 코드와 수정 방안을 작성해줘.

### 📌 프로젝트 환경 및 사전 준비 사항
- 백엔드 DB에 대화 기록 및 마이페이지 로그 저장을 위한 아래 두 개의 테이블이 이미 생성되어 있음.
  1. `chat_sessions` 테이블: 
     - `id` (VARCHAR(64), PK - 세션 UUID)
     - `user_id` (INT, FK -> users.user_id)
     - `title` (VARCHAR)
     - `messages` (JSON - 대화 내용 배열)
     - `created_at`, `updated_at`
  2. `mypage_logs` 테이블 (마이페이지 통합 로그/보관함):
     - `id` (INT, PK, Auto Increment)
     - `user_id` (INT, FK -> users.user_id)
     - `log_type` (VARCHAR - 예: 'recipe'는 내 레시피, 'comparison'은 비교 히스토리)
     - `title` (VARCHAR - 레시피 제목 등)
     - `content` (JSON - 레시피 상세 본문 등)
     - `created_at`

---

### 🛠️ 구현해야 할 4가지 요구사항

1. **챗봇 답변 방식 통일**
   - 챗봇의 모든 답변 카드 및 UI 형식을 일관되게 유지하도록 정돈해줘.

2. **퀵 액션 버튼 추가 ("다음으로 무엇을 할까요?" 영역)**
   - 챗봇 답변 하단에 노출되는 퀵 액션 버튼에 다음 2가지를 추가해줘.
     - 3번째 버튼: **"다른 레시피 추천하기"** (클릭 시 동일 재료나 새로운 조건으로 레시피 재요청 트리거)
     - 4번째 버튼: **"이 레시피 저장하기"** (클릭 시 현재 출력된 레시피를 마이페이지에 저장)

3. **로그인 상태에 따른 대화 기록 관리**
   - **로그인하지 않은 경우:** 대화 기록을 서버 DB에 저장하지 않고 브라우저 임시 상태로만 유지하거나 남기지 않음.
   - **로그인한 경우:** 백엔드 API를 통해 `chat_sessions` 테이블에 현재 대화 세션과 메시지(`messages`)가 자동으로 저장 및 연동되도록 구현. 마이페이지나 사이드바에서 내 대화 목록만 불러올 수 있게 처리.

4. **"이 레시피 저장하기" 버튼 연동 (마이페이지 내 레시피 보관함)**
   - 4번째 버튼("이 레시피 저장하기")을 누르면, 백엔드 API를 호출하여 `mypage_logs` 테이블에 `log_type = 'recipe'`로 현재 레시피 정보가 저장되도록 구현.
   - 마이페이지 내에서 해당 레시피들이 리스트 형태로 깔끔하게 조회될 수 있도록 연동 코드 작성.
