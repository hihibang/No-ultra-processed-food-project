# 요리명: 톡톡! 오미자 펀치

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 기타
- 열량(칼로리): 65.9 kcal
- 나트륨 함량: 26.1 mg

## 필요한 재료
말린오미자(5g), 배(50g), 꿀(5g), 잣(3알),
생수(150g), 각얼음(3개)

## 조리 순서
1. 말린오미자는 깨끗이 씻은 뒤 생수 150g을 부어 하루정도 우려낸다., 2. 우려낸 오미자를 체에 거른다., 3. 배를 강판에 곱게 간 뒤 면포에 싸서 배즙을 짠다., 4. 우린 오미자와 배즙을 섞은 후 꿀을 넣고 골고루 섞는다., 5. 믹서기에 얼음을 갈아 한 스푼 얹는다., 6. 잣을 띄워 장식한다.
