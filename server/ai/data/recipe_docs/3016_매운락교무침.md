# 요리명: 매운락교무침

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 46.9 kcal
- 나트륨 함량: 500.6 mg

## 필요한 재료
•필수 재료 : 락교(30g), 쪽파(2g), 마늘(0.1g)
•양념장 : 고춧가루(0.3g), 설탕(0.3g), 참기름(0.1g), 참깨(0.1g)

## 조리 순서
1. 락교는 물에 헹군다., 2. 락교의 물기를 제거한다., 3. 쪽파는 송송 썬다., 4. 마늘은 곱게 다진다., 5. 양념장을 만든다., 6. 락교와 쪽파, 다진마늘에 양념장을 골고루 버무려 마무리한다.
