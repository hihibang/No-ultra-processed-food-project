# 요리명: 콩 판나코타

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 기타
- 열량(칼로리): 300.1 kcal
- 나트륨 함량: 4.7 mg

## 필요한 재료
렌틸콩(레드, 20g), 완두콩(30g),
생크림(40g), 설탕(8g), 판젤라틴(2g)

## 조리 순서
1. 완두콩과 렌틸콩은 각각 삶은 뒤 믹서에 간다., 2. 완두콩과 렌틸콩에 각각 생크림(20g)과 설탕(4g)을 넣고 냄비에 끓인다., 3. 젤라틴 1g을 물에 넣어 불린다., 4. 2번에 각각 불린 젤라틴을 혼합하여 녹인다., 5. 용기에 4번의 렌틸콩을 붓고 얼린다., 6. 5번이 어느정도 굳으면 4번의 완두콩을 붓고 얼린다.
