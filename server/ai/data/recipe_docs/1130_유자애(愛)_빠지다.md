# 요리명: 유자애(愛) 빠지다

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 기타
- 열량(칼로리): 153.2 kcal
- 나트륨 함량: 15.2 mg

## 필요한 재료
유자(200g), 밤(25g), 대추(15g), 배(50g),
석류(20g), 꿀(10g), 소금(0.5g), 물(300g)

## 조리 순서
1. 유자는 십자로 갈집을 낸 뒤 끓는 소금물에 데쳐 껍질을 깨끗이 한다., 2. 유자는 속을 꺼내 씨를 제거하고 유자속과 속껍질을 얇게 채 썬다., 3. 밤, 대추, 배는 채 썰고 2번과 섞어 소를 만든다., 4. 속을 빼낸 유자에 소를 2/3쯤 채워 입구를 실로 묶는다., 5. 유자묶음을 용기에 채워 넣은 후 꿀물을 붓고 잘 밀봉하여 냉장고에 보관한다., 6. 3~4주 정도 숙성한 뒤 석류를 곁들여 먹는다.
