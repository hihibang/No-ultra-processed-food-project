# 요리명: 룰룰랄라

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 볶기
- 열량(칼로리): 242.5 kcal
- 나트륨 함량: 55.5 mg

## 필요한 재료
양상추(120g), 소고기(120g), 부추(100g), 닭고기(120g),
토마토(100g), 양파(50g), 전복(1개), 당근(20g),
양송이버섯(3개), 쌀(200g), 소금(0.3g)

## 조리 순서
1. 양상추, 부추를 데친다., 2. 양송이버섯은 얇게 슬라이스하고 팬에 기름을 살짝 두르고 굽는다., 3. 전복은 수저로 떼어 소금으로 씻고 일정한 크기로 썰어 팬에 굽는다., 4. 닭고기는 일정한 크기로 썬 뒤 삶고, 소고기도 일정한 크기로 썰어 양념 한 뒤 볶는다., 5. 토마토, 양파, 당근은 잘게 썰고, 쌀은 깨끗이 씻어 불려 야채를 넣고 밥을 짓는다., 6. 쪄낸 양배추에 볶은 고기, 삶은 닭고기, 구운 전복, 밥을 넣고 돌돌 말아 부추로 묶어 접시에 담고, 한쪽에 구운 버섯을 담는다.
