현재 레시피 챗봇 서비스의 기능과 UI를 아래 4가지 요구사항 및 퀵 액션 버튼 기획에 맞춰 전면 수정하려고 해. 관련 파일들을 확인하고 코드를 수정해줘.

1. 후속 대화 및 추가 질문 처리 분리 (퀵 액션 버튼 도입 포함)
   - n8n 워크플로우는 초기 레시피 검색 및 추천에만 집중하고, 이후 사용자의 디테일한 추가 질문이나 연속된 대화 이어가기는 로컬 백엔드 서버에서 OpenAI API를 직접 호출하는 방식으로 처리해줘.
   - 챗봇이 레시피를 추천한 직후, 메시지 하단에 다음과 같은 3가지 '퀵 액션 버튼(Quick Action Buttons)' UI 컴포넌트를 추가해줘:
     ① "이 레시피에 대해 추가 질문하기": 현재 레시피를 기준으로 로컬 서버 OpenAI와 히스토리(sessionId)를 이어가며 세부 질문 모드 진입
     ② "목록의 다른 레시피 보기 (2번, 3번 등)": 추가 벡터 검색 없이 이미 가져온 직전 검색 결과 데이터에서 다른 후보 레시피 페이로드를 즉시 렌더링
     ③ "완전히 새로운 레시피 검색하기": 입력창 및 상태를 초기화하고 n8n 벡터 검색 워크플로우부터 새로 실행

2. 레시피 출력 가독성 개선
   - AI가 생성하는 레시피 답변의 가독성을 높이기 위해, 마크다운(Markdown) 포맷, 불릿 포인트, 굵기 강조 등을 적극 활용해 재료와 조리 순서가 한눈에 들어오도록 UI 또는 프롬프트를 다듬어줘.

3. 취향 프로필 블록 우선순위 재배치 (Format Context 또는 프롬프트 조립 로직)
   - AI에게 전달되는 취향 프로필 블록의 항목 순서를 중요도와 안전(식이 제한)에 맞춰 다음과 같이 변경해줘:
     • 1순위: 식이 제한 · 현재 상황 (알레르기 등 안전을 위해 최상단 배치)
     • 2순위: 보유 주방 도구
     • 3순위: 요리 숙련도 및 선호 요리

4. 프론트엔드 UI 레이아웃 변경
   - 메인 화면의 레이아웃을 변경해줘:
     • 왼쪽: 대화 창 (채팅 영역 및 퀵 액션 버튼)
     • 오른쪽: '내 취향 설정' 및 '대화 기록' 패널 (사이드바)
     - 일반적인 표준 챗봇 UI(ChatGPT 등)처럼 왼쪽에 채팅, 오른쪽에 설정/기록이 오도록 배치해줘.

위 사항들을 반영하기 위해 수정해야 할 프론트엔드 코드(채팅 UI 및 버튼 컴포넌트 포함), 백엔드 코드, 그리고 n8n 관련 스크립트 부분을 검토하고 코드를 작성해 줘.
