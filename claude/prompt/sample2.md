식품 쇼핑몰 카탈로그의 **좌측 사이드바 필터 컴포넌트**를 만드는 작업계획을 .md 파일로 만들어줘

첨부된 UI 레이아웃을 기반으로 하며, 핵심 요구사항은 다음과 같아:

1. **사이드바 구성**:
   - 상단: 식품 카테고리 목록
   - 중단: **NOVA 가공 등급 필터** (다중 선택 체크박스)
     - NOVA 1 (자연/최소 가공) - 녹색 도트(#10B981)
     - NOVA 2 (가공 식재료) - 노란색 도트(#F59E0B)
     - NOVA 3 (가공식품) - 주황색 도트(#F97316)
     - NOVA 4 (초가공식품) - 빨간색 도트(#EF4444)
   - 하단 1: 영양성분 필터 (저당, 저염/저나트륨, 무트랜스지방 체크박스)
   - 하단 2: 제외할 첨가물 필터 (합성감미료 제외, 합성향료 제외, 보존료 제외 등)
   - 최하단: "선택 필터 초기화" 버튼

2. **핵심 기능: NOVA 설명 툴팁/팝오버 (중요)**
   - `NOVA 가공 등급` 타이틀 바로 옆에 `?` (물음표 원형 아이콘 또는 Info 아이콘) 버튼 배치.
   - 아이콘 사용할 때: <svg xmlns="http://www.w3.org/2000/svg" width="15" height="15" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" class="lucide lucide-shield-question-mark"><path d="M20 13c0 5-3.5 7.5-7.66 8.95a1 1 0 0 1-.67-.01C7.5 20.5 4 18 4 13V6a1 1 0 0 1 1-1c2 0 4.5-1.2 6.24-2.72a1.17 1.17 0 0 1 1.52 0C14.51 3.81 17 5 19 5a1 1 0 0 1 1 1z"/><path d="M9.1 9a3 3 0 0 1 5.82 1c0 2-3 3-3 3"/><path d="M12 17h.01"/></svg> 
   - 이 `?` 아이콘을 클릭하거나 마우스 호버(Hover) 시, 플로팅 툴팁(Tooltip / Popover) 창이 부드럽게 나타나야 함.
   - **팝오버 내용**:
     - 제목: "NOVA 식품 분류 체계란?"
     - 설명: 브라질 상파울루 대학에서 개발한 가공 정도에 따른 4단계 국제 공인 식품 분류 기준.
     - 1등급(녹색): 가공되지 않거나 최소 가공된 자연 식품
     - 2등급(노랑): 조리에 사용되는 가공 식재료 (기름, 소금, 설탕 등)
     - 3등급(주황): 1등급+2등급 결합 가공식품 (통조림, 단순 치즈 등)
     - 4등급(빨강): 공업적 공정을 거친 초가공식품 (UPF / 착향료, 감미료, 유화제 등 포함)
   - 외부 영역 클릭 시 팝오버가 닫히는 동작 포함 (Click Outside to Close).

3. **상태 관리**:
   - 체크된 필터 값들을 객체나 배열로 상위 컴포넌트에 전달할 수 있도록 `onFilterChange` 콜백 구현.
   - 깔끔한 모던 UI 디자인과 부드러운 인터랙션 트랜지션 적용.
