# 요리명: 쿠스쿠스 삼계롤

## 기본 정보
- 요리 분류: 일품
- 조리 방식: 끓이기
- 열량(칼로리): 633.5 kcal
- 나트륨 함량: 419.1 mg

## 필요한 재료
주재료 
쿠스쿠스 30g, 닭다리살 200g, 밤 10g, 은행 5g, 대추 5g,
대파 5g, 홍고추 5g

닭뼈육수 재료 닭뼈 250g, 물 700ml, 대파 30g, 양파 50g, 마늘 5g,
생강 5g

양념 들깻가루 20g, 소금 1g, 후추 1g

## 조리 순서
1. 팬에 손질한 닭뼈를 넣고 살짝 굽는다. 냄비에 구운 닭뼈와 나머지 닭뼈육수 재료를 모두 넣고 30분간 끓여 닭뼈육수를 만든다., 2. 볼에 쿠스쿠스를 넣고 뜨거운 닭뼈육수를 잠길 만큼 넣는다. 10분간 익힌 후 포크로 부드럽게 풀어준다., 3. 닭뼈육수에 들깻가루를 넣고 한소끔 끓인다., 4. 손질한 닭다리살에 소금, 후추로 간한다. 랩을 깔고 닭다리살을 넓게 펴고 밤, 은행, 대추를 올려 돌돌 말아 15분간 찐 후 식혀 삼계롤을 만든다., 5. 삼계롤을 한입 크기로 썰고, 대파와 홍고추를 잘게 썰어 고명을 만든다., 6. 그릇에 삼계롤, 닭뼈육수를 넣고, 쿠스쿠스, 대파와 홍고추 고명을 올려 마무리한다.
