# 요리명: 고구마순나물

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 50.18 kcal
- 나트륨 함량: 94.33 mg

## 필요한 재료
고구마순 25g, 양파 10g, 된장 10g, 두부 5g, 마늘 10g, 흑임자 5g, 설탕 5g, 식초 5g, 참기름 5g

## 조리 순서
1. 두부를 데친 뒤 식혀 으깬다., 2. 으깬 두부에 식초, 설탕, 된장을 섞어 양념을 만든다., 3. 손질한 고구마순을 4cm 길이로 썬다., 4. 고구마순을 데친다., 5. 양파를 곱게 채 썬다., 6. 고구마순에 채 썬 양파와 양념, 흑임자을 넣고 무친다.
