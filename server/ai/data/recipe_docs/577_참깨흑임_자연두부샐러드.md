# 요리명: 참깨흑임 자연두부샐러드

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 309.2 kcal
- 나트륨 함량: 159.9 mg

## 필요한 재료
연두부(100g), 참깨(20g), 흑임자(20g), 파프리카(50g),
무순(10g), 날치알(20g), 설탕(20g), 식초(10g), 마요네즈(30g),
우유(30g)

## 조리 순서
1. 참깨와 흑임자를 섞어 곱게 간다., 2. 갈아 놓은 참깨와 흑임자에 설탕과 식초를 넣고 섞는다., 3. 2번에 우유와 마요네즈를 넣고 골고루 섞어 참깨 흑임자 드레싱을 만든다., 4. 연두부는 동그랗게 자른다., 5. 파프리카는 채 썬다., 6. 접시에 드레싱, 연두부, 파프리카, 무순, 날치알 순으로 올린다.
