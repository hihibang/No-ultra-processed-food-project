# 요리명: 청경채 김치

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 53.7 kcal
- 나트륨 함량: 382.6 mg

## 필요한 재료
•필수 재료 : 청경채(60g), 배(10g)
•양념장 : 매실액(5g), 고춧가루(5g), 저염간장(3g), 다진마늘(1g), 다진생강(2g)
•양념 : 소금(2g), 찹쌀가루(10g)

## 조리 순서
1. 청경채는 반으로 자른 후 줄기 부분에 칼집을 넣는다., 2. 청경채에 소금을 뿌려 30~40분 정도 절인다., 3. 배는 껍질을 벗긴 후 강판에 갈아 즙을 만든다., 4. 냄비에 물(30g)과 찹쌀가루를 넣고 끓여 찹쌀풀을 만들고, 충분히 식힌다., 5. 볼에 식힌 찹쌀풀, 배즙, 양념장 재료를 넣고 고루 섞어 양념장을 만든다., 6. 절인 청경채의 물기를 제거하고, 양념장을 버무려 마무리한다.
