# 요리명: 고등어구이

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 굽기
- 열량(칼로리): 279.9 kcal
- 나트륨 함량: 105.0 mg

## 필요한 재료
고등어 70g, 밀가루 4g[소스소개]저나트륨발사믹소스:간장 1g, 올리브오일 13g, 발사믹식초 6g, 꿀 4g

## 조리 순서
1. 손질된 고등어는 5cm 길이로 토막낸 뒤 껍질에 칼집을 넣는다., 2. 칼집 낸 고등어에 밀가루를 묻힌다., 3. 오븐을 200℃로 예열한다., 4. 간장, 올리브오일, 발사믹식초, 꿀을 섞어 소스를 완성한다., 5. 고등어를 팬에 넣어 오븐에 굽는다., 6. 저나트륨발사믹소스와 구운 고등어를 함께 제공한다.
