# 요리명: 멍게비빔밥

## 기본 정보
- 요리 분류: 밥
- 조리 방식: 기타
- 열량(칼로리): 399.5 kcal
- 나트륨 함량: 532.8 mg

## 필요한 재료
비빔밥: 쌀밥 210, 멍게살 50, 부추 10, 무순 5, 김 0.5, 참기름 4, 통깨 1.5 양념장: 고추장 5, 설탕 1, 레몬즙 3, 간 양파 3, 매실액 3

## 조리 순서
1. 멍게는 꼭지를 따고 껍질을 벗겨 한입 크기로 썬다., 2. 부추는 2cm 길이로 썬다., 3. 김도 부추와 같은 길이로 가늘게 채 썬다., 4. 양념장 재료를 모두 섞어 양념장을 만든다., 5. 손질한 멍게에 참기름을 넣어 가볍게 버무린다., 6. 그릇에 밥을 담고 부추, 무순, 멍게, 김, 통깨를 올리고 양념장을 넣어 비벼 먹는다.
