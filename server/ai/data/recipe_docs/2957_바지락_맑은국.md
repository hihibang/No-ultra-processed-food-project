# 요리명: 바지락 맑은국

## 기본 정보
- 요리 분류: 국&찌개
- 조리 방식: 끓이기
- 열량(칼로리): 46.89 kcal
- 나트륨 함량: 359.39 mg

## 필요한 재료
바지락 30g, 팽이버섯 10g, 홍고추 3g, 쑥갓 1g, 청양고추 3g, 무 8g, 대파 5g, 다시마 5g

## 조리 순서
1. 물에 무와 다시마, 대파, 청양고추를 넣고 끓인다., 2. 끓으면 청양고추와 다시마를 건진다., 3. 해감한 바지락을 넣고 끓인다., 4. 팽이버섯 밑둥을 자른다., 5. 3에 팽이버섯을 넣고 끓인다., 6. 고명으로 어슷 썬 홍고추, 쑥갓을 올린다.
