# 요리명: 녹차 파나코타

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 기타
- 열량(칼로리): 310.3 kcal
- 나트륨 함량: 62.0 mg

## 필요한 재료
녹차가루 6g, 판젤라틴 5.3g, 설탕 32g, 물 15g, 생크림 30g, 우유 55.7g, 바닐라에센스 0.1g, 통조림단팥장식용,민트장식용

## 조리 순서
1. 볼에 물을 담고 판 젤라틴을 넣어 3분 가량 불린 뒤 건진다., 2. 냄비에 녹차가루와 소량의 물을 넣고 진하게 섞는다., 3. 2에 우유와 크림, 설탕, 바닐라 에센스를 넣고 약한 불에서 설탕이 녹을 정도로 끓인다., 4. 3에 불린 젤라틴을 넣고 젤라틴이 녹을 때까지 가열한다., 5. 용기에 녹차 파나코타를 부은 후 실온에서 식힌다., 6. 냉장고에서 한번 더 식혀 완성한다.
