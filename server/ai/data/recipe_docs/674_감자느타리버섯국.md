# 요리명: 감자느타리버섯국

## 기본 정보
- 요리 분류: 국&찌개
- 조리 방식: 끓이기
- 열량(칼로리): 53.3 kcal
- 나트륨 함량: 404.0 mg

## 필요한 재료
감자 30g, 느타리버섯 15g, 두부 8g, 파 5g, 물 300g, 국멸치 5g, 홍고추 3g, 건다시마 3g, 다진 마늘 3g, 소금 0.5g

## 조리 순서
1. 물 1컵 반에 국멸치와 건다시마를 넣어 멸치다시마국물을 만든다., 2. 국물을 우린 다시마는 채썬다., 3. 느타리버섯은 끓는 물에 데친 후 찢는다., 4. 감자와 두부는 3~4cm 가량으로 채를 썰고 홍고추와 대파는 어슷썬다., 5. 멸치다시마국물 1컵에 감자를 넣고 끓인 뒤 느타리버섯을 넣어 한소끔 끓이고 두부, 파, 다진 마늘, 홍고추를 넣고 소금으로 간 한다., 6. 채 썬 다시마를 고명으로 얹는다
