# 요리명: 곤약 감자조림

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 37.8 kcal
- 나트륨 함량: 305.0 mg

## 필요한 재료
곤약 100g, 감자 50g, 풋고추 5g, 홍고추 5g, 다시마 10g, 간장 15g, 설탕 10g, 미림 15g, 참기름 3g, 식초 10g, 물 200g

## 조리 순서
1. 곤약과 감자는 2cm ? 2cm 크기로 썰고 풋고추와 홍고추는 송송 썰어 씨를 제거한다., 2. 물(200g)에 다시마를 넣고 끓여 육수를 만든 뒤 다시마를 건진다., 3. 육수에 간장, 설탕, 미림을 섞어 조림장을 만든다., 4. 곤약과 감자를 끓는 물에 넣고 80% 정도 익힌 뒤 건져 식힌다., 5. 4에 조림장 50g을 넣고 살짝 졸인다., 6. 불을 끄고 참기름을 섞는다.
