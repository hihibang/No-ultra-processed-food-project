# 요리명: 민들레무침

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 24.9 kcal
- 나트륨 함량: 127.9 mg

## 필요한 재료
주재료: 민들레 15, 양파 10 양념: 고춧가루 1.25, 깨소금 1, 소금 0.25, 다진 파 1.25, 다진 마늘 0.5, 매실액 4.5

## 조리 순서
1. 민들레는 흐르는 물에 씻는다., 2. 깨끗이 씻은 민들레는 한입 크기로 뜯고 물기를 살짝 제거해준다., 3. 양파는 얇게 채썬다., 4. 양념장 재료를 모두 섞어 양념장을 만든다., 5. 양파와 민들레를 볼에 담고 양념을 넣어 가볍게 무쳐낸다., 6. 그릇에 담아 마무리 한다.
