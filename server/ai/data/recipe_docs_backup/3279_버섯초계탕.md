# 요리명: 버섯초계탕

## 기본 정보
- 요리 분류: 일품
- 조리 방식: 끓이기
- 열량(칼로리): 277.3 kcal
- 나트륨 함량: 178.9 mg

## 필요한 재료
[ 2인분 ] 닭(1마리), 양파(1개), 대파(1대), 미나리(½줌), 새송이버섯(3개), 팽이버섯(1봉), 마늘(6쪽), 양송이버섯(4개), 달걀(1개), 전분(0.7Ts), 간장(0.5Ts), 소금(0.3ts), 후춧가루(약간)

## 조리 순서
1. 닭은 깨끗하게 씻어 준비하고, 양파와 대파는 4등분한다., 2. 새송이버섯은 모양대로 두툼하게 썰고, 팽이버섯은 밑동을 자른 뒤 낱낱이 가르고, 미나리는 한입 크기로 썬다., 3. 냄비에 닭을 넣고 잠길 만큼 물을 붓고, 양파, 대파, 미나리(½분량), 마늘을 넣어 센 불로 올린 뒤 닭이 익을 때까지 끓인다., 4. 닭, 양파, 미나리를 건져내 한 김 식히고, 닭은 살을 발라낸다., 5. 닭고기, 양파, 남은 미나리, 달걀, 전분을 고루 섞어 닭볼을 만든다., 6. 육수에 닭볼, 새송이버섯, 팽이버섯, 양송이버섯, 남은 미나리를 넣고, 양념으로 간한 뒤 한소끔 끓여 마무리한다.
