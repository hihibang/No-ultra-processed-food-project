기존에 내가 만든 웹페이지 코드에서 [AI 챗봇 파트] 영역만 교체 및 고도화하려고 해. 아래 조건에 맞춰 챗봇 UI와 연동 로직을 포함한 코드를 작성해줘.

1. 화면 구성 (기존 페이지와 어울리는 모던한 디자인):
   - 마이페이지/프로필 설정 영역 (요리 난이도, 보유 주방 도구/상태, 식이 선호 등 취향 입력 폼)
   - 챗봇 대화 화면 (사용자 입력창 및 AI 답변 출력 영역)

2. 기능 요구사항:
   - 사용자가 마이페이지에서 설정한 취향/상태 데이터와 질문을 함께 묶어서 1차 레시피 추천용 n8n 웹훅(Webhook URL)로 POST 요청을 보냄.
   - 1차 레시피 추천 이후, 사용자가 이어서 추가 질문(예: "여기서 소금 빼도 돼?", "불 조절은 어떻게 해?")을 할 경우, RAG(벡터 DB 검색)를 타지 않고 이전 대화 맥락을 유지한 채 후속 대화용 n8n 웹훅 엔드포인트(또는 백엔드)를 통하여 답변을 받아올 수 있도록 챗봇 UI 및 전송 로직 구조를 설계해줘.
   - 사용자가 질문한 내용과 추천받은 레시피 기록이 마이페이지(또는 별도의 기록 탭/영역)에 로컬 스토리지(localStorage) 기반으로 저장되어 언제든 다시 꺼내 볼 수 있게 구현해줘.

3. 기술 스택 및 아키텍처 보안 가이드:
   - Tailwind CSS를 활용한 직관적이고 깔끔한 UI
   - 기존 페이지에 쉽게 이식할 수 있는 컴포넌트 형태 또는 독립적인 챗봇 섹션 코드
   - [중요 보안] 프론트엔드에서 OpenAI API 키를 직접 호출하지 않고, 1차 추천 및 후속 대화 질문 모두 n8n 웹훅 엔드포인트를 경유하도록 설계할 것 (OpenAI API 키인 OPENAI_API_KEY는 n8n 서버/.env 측에서 관리)
