# 요리명: 두부빼빼로

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 굽기
- 열량(칼로리): 411.0 kcal
- 나트륨 함량: 8.5 mg

## 필요한 재료
두부(25g), 포도(10g), 호두(1g),
검은깨(1g), 식빵(7.5g), 밀가루(5g),
계피가루(1g), 소금(0.1g), 꿀(2g),
식용유(5g), 물(8g)

## 조리 순서
1. 두부를 칼등으로 곱게 으깬 후 면포에 싸서 물기를 짠다., 2. 식빵은 믹서에 갈아 빵가루를 만들고, 포도는 믹서에 간 뒤 걸러 포도즙을 만든다., 3. 냄비에 포도즙, 꿀, 물, 소금을 넣고 끓으면 불을 끄고 식용유를 넣고 섞는다., 4. 밀가루에 계피가루, 으깬 두부, 검은깨, 다진 호두를 넣고 반죽한다., 5. 짤주머니에 반죽을 넣고 15cm 길이로 팬에 짠다., 6. 반죽표면에 3번을 바르고 180℃ 오븐에 15분 간 굽는다.
