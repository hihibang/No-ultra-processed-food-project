# 요리명: 살레마이슈

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 기타
- 열량(칼로리): 73.8 kcal
- 나트륨 함량: 52.0 mg

## 필요한 재료
주재료 > 바나나 60g, 양파 24g, 양송이버섯 24g, 감자 24g, 검은콩두유 24g, 달걀 48g, 후추 3g, 다진 마늘 12g, 아몬드가루 36g, 베이킹파우더 3g, 강황가루 6g
토 핑 > 방울토마토 36g, 바질 6g

## 조리 순서
1. 바나나는 으깨고 양파, 양송이버섯, 감자, 바질은 작게 자른다. 방울토마토는 1/4 크기로 자른다., 2. 볼에 손질한 바나나, 양파, 양송이버섯, 감자, 바질을 넣고 검은콩두유, 달걀, 후추, 다진 마늘을 넣고 섞는다., 3. 볼에 아몬드가루, 베이킹파우더, 강황가루를 체 쳐서 넣고 섞어 반죽을 완성한다., 4. 머핀 틀에 반죽을 2/3 정도 넣고, 손질한 방울토마토 3~4토막을 올린다., 5. 170°C로 예열한 오븐에서 20분 동안 구운 후 꺼낸다., 6. 바질로 장식하여 마무리한다.
