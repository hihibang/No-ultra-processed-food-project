# 요리명: 사과 견과류 식빵

## 기본 정보
- 요리 분류: 기타
- 조리 방식: 기타
- 열량(칼로리): 269.0 kcal
- 나트륨 함량: 6.42 mg

## 필요한 재료
(반죽재료) 강력분 250g, 소금 5g, 드라이이스트 6g, 버터 25g, 달걀 22g, 우유 175g 
(속재료) 사과 500g (2개), 견과류 15g

## 조리 순서
1. (속재료) 사과 1개와 견과류는 다이스하고 사과 1개는 강판에 간 후 냄비에 졸인다. ★ 사과를 졸이면 단 맛이 농축되고, 갈변도 막을 수 있어요., 2. 강력분과 소금, 이스트, 우유, 물을 넣고 반죽하여 어느 정도 글루텐이 형성되면 버터를 넣어 반죽한다., 3. 반죽을 60분 정도 1차 발효하고 분할해 둥글리기 하여 중간 발효한다., 4. 중간발효가 끝난 반죽은 길게 밀어 편 후 졸인 사과와 견과류를 넣어 롤로 말아 30분간 2차 발효한다., 5. 2차 발효한 반죽 위에 계란물을 발라 아랫불160℃, 윗 불180℃의 오븐에 넣고 30분간 굽는다., 6. 5분정도 남았을 때 꺼내 계란물을 한 번 더 발라 아랫불 170℃, 윗불 180℃로 구워 윗면에 색을 내준다. ★ 굽는 중간에 틀을 돌려주면 골고루 구워져요.
