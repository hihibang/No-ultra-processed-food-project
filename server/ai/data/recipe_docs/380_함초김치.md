# 요리명: 함초김치

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 49.1 kcal
- 나트륨 함량: 176.1 mg

## 필요한 재료
함초 25g, 알배추 50g, 양파 50g, 무 100g, 간편 어간장 15g
국물 : 오렌지주스 50g, 유자청 30g, 식초 15g, 설탕 15g, 야채국물 800g

## 조리 순서
1. 함초는 먹기 좋게 썰어준다., 2. 알 배추, 무, 양파도 먹기 좋게 썬다., 3. 오렌지주스와 유자청을 넣어 국물을 만든다., 4. 볼에 함초, 알배추, 무를 넣어 섞고 어간장을 넣어 살짝 절여준다., 5. 절여진 재료에 국물을 부어준다., 6. 3시간 정도 후부터 먹을 수가 있다.
