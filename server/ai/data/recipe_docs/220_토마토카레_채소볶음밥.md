# 요리명: 토마토카레 채소볶음밥

## 기본 정보
- 요리 분류: 밥
- 조리 방식: 끓이기
- 열량(칼로리): 612.1 kcal
- 나트륨 함량: 435.2 mg

## 필요한 재료
재료 감자(20g), 양파(10g), 당근(10g), 피망(5g), 닭가슴살(20g)
밥(200g), 브로콜리(10g), 방울토마토(20g), 플레인 요구르트(15g)
양념 후춧가루(0.1g), 토마토페이스트(20g), 파프리카가루(3g), 카레가루(15g)

## 조리 순서
1. 감자, 양파, 당근, 피망은 볶음밥에 넣을 분량은 잘게 다지고, 카레에 넣을 분량은 한입 크기로 썬다., 2. 닭가슴살도 한입 크기로 잘라 후춧가루로 밑간한다., 3. 팬에 식용유(15g)를 두른 뒤 잘게 다진 감자, 양파, 당근, 피망을 넣고 볶다가 밥을 넣고 같이 볶는다., 4. 식용유(15g)를 두른 팬에 닭고기를 먼저 볶다가 한입 크기로 썬 감자, 당근, 양파, 피망, 브로콜리를 넣고 볶은 뒤 마지막에 방울토마토를 넣는다., 5. 토마토페이스트을 넣고 볶다가 파프리카가루를 넣어 향을 낸다., 6. 카레가루를 푼 물(300g)을 부어 끓이다가 플레인 요구르트를 넣고 농도를 맞춘 뒤 밥 위에 얹어 마무리한다.
