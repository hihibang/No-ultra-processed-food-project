# 요리명: 나박김치

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 39.6 kcal
- 나트륨 함량: 196.0 mg

## 필요한 재료
배추잎 50g, 무30g, 당근 10g, 실파 5g, 수삼 10g, 마늘 3g, 생강 5g, 고춧가루 2.5g, 미나리 10g, 홍고추 2g, 물 70g, 소금 0.5g

## 조리 순서
1. 배추, 무는 2x2cm로 나박썬다., 2. 썰어논 배추, 무는 소금에 살짝 절여둔다., 3. 당근은 모양을 내어 썰고 실파, 미나리도 2cm로 썰어둔다., 4. 마늘과 생강, 홍고추는 채썰고 수삼은 어슷하게 썬다., 5. 물을 끓여 식힌 후 소창에 고춧가루를 싸서 김치국물을 만든다., 6. 무와 배추가 절여지며 준비한 재료들에 김치국물을 부어 완성한다.
