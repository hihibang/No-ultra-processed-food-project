# 요리명: 아삭

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 96.5 kcal
- 나트륨 함량: 1016.3 mg

## 필요한 재료
아스파라거스(5개), 당근(100g), 무(100g), 식초(200g),
설탕(200g), 월계수잎(3장), 통후추(20알), 소금(0.5g)

## 조리 순서
1. 아스파라거스는 깨끗이 씻어 5cm 길이로 썬다., 2. 당근을 아스파라거스 크기로 썬다., 3. 무도 아스파라거스 크기로 썬다., 4. 식초, 설탕을 동량으로 섞는다., 5. 식초 설탕물이 끓으면 통에 뜨거울 때 붓고, 떠오르지 않도록 눌러 담는다., 6. 약 7일 정도 숙성한다.
