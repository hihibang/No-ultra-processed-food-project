# 요리명: 호박 고구마 스프

## 기본 정보
- 요리 분류: 일품
- 조리 방식: 끓이기
- 열량(칼로리): 165.0 kcal
- 나트륨 함량: 77.0 mg

## 필요한 재료
호박고구마스프
고구마 70g(1/2개), 단호박 30g(4×6cm), 우유 100ml(1/2컵), 설탕 2g(1/3작은술), 물 50ml(1/4컵)

## 조리 순서
1. 고구마와 단호박을 찜기에 10~20분 동안 익힌 후 껍질을 제거하고 으깨어 체에 거른 다., 2. 냄비에 고구마, 단호박, 우유, 설탕을 넣고 잘 저어주며 끓인다., 3. 스프의 농도를 보면서 물을 조금씩 넣어가며 걸쭉하게 끓여준다.
