# 요리명: 닭가슴살호두크로켓

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 튀기기
- 열량(칼로리): 623.5 kcal
- 나트륨 함량: 312.9 mg

## 필요한 재료
닭가슴살 80g, 두부 20g, 양파 12.5g, 대파 5g, 호두 5g, 땅콩 2.5g, 마늘 2g, 생강 0.5g, 후추 0.3g, 설탕 3.8g, 식초 2.5g, 계란 65g(1.5개), 쌀가루 7g, 빵가루 25g, 순무 24g, 두유 45ml, 홀그레인 2.5g, 땅콩버터 5g, 레몬 7g, 파슬리 0.5g

## 조리 순서
1. 양파, 대파, 호두, 닭가슴살은 잘게 다진다., 2. ①에 물기를 제거한 두부와 생강, 마늘, 후추를 섞어 반죽한다., 3. 반죽을 쌀가루, 계란물, 빵가루 순으로 묻히고 튀겨 크로켓을 만든다., 4. 믹서에 두부, 두유를 넣고 갈아 두부 마요네즈를 만든다., 5. 순무와 양파는 다지고, 계란은 삶아 다져 준비한다., 6. 두부 마요네즈에 ⑤의 재료와 설탕, 레몬, 식초, 땅콩버터, 후추, 홀그레인, 파슬리가루를 넣어 타르소스를 만든다.
