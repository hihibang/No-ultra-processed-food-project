# 요리명: 오소부코

## 기본 정보
- 요리 분류: 일품
- 조리 방식: 기타
- 열량(칼로리): 1033.4 kcal
- 나트륨 함량: 109.9 mg

## 필요한 재료
주재료 
현미 80g, 소고기(정강이살) 180g, 양파 60g, 당근 30g,
셀러리 20g, 다진 마늘 20g, 닭뼈육수 300g, 청주 30g, 깻잎 8g,
참나물 12g, 사과식초 10g, 레몬즙 10g

양념 
소금 1g, 후추 2g, 올리브유 60g, 파르미지아노 치즈 13g

## 조리 순서
1. 현미는 2시간 이상 물에 불린다. 소고기에 소금, 후추로 밑간하고 달군 팬에 올리브유(20g)를 두르고 소고기 겉면을 바싹 익힌다., 2. 양파, 셀러리, 당근을 잘게 다진다. 올리브유(10g)를 두른 팬에 손질한 양파(30g), 당근, 셀러리, 다진 마늘(10g)을 넣고 볶다가 익힌 소고기, 닭뼈육수(150g), 청주를 넣고 약한 불로 20분간 뭉근하게 조린다., 3. 깻잎, 참나물을 잘게 다진다. 볼에 손질한 깻잎, 참나물, 사과식초, 레몬즙, 올리브유(20g)를 넣고 섞어 그레몰라타 소스를 만든다., 4. 올리브유(10g)를 두른 팬에 손질한 양파(30g), 다진 마늘(10g)을 넣고 볶은 후 불린 현미, 닭뼈육수(150g)를 넣고 조려 리소토를 만든다., 5. 그릇에 리소토를 담고 파르미지아노 치즈를 갈아 올린다., 6. 리소토 위에 조린 소고기를 얹고 그레몰라타 소스를 곁들여 마무리한다.
