# PingPong 프로젝트 - 메인 랜딩 페이지 개발 작업계획

## 📋 프로젝트 개요
- **프로젝트명**: PingPong (건강한 식품 큐레이션 & AI 맞춤형 추천 플랫폼)
- **작업 범위**: 메인 랜딩 페이지 개발
- **기술 스택**: React, Tailwind CSS, JSX
- **작업 디렉토리**: `front/` 디렉토리 내부

---

## 🎯 작업 범위 및 제약사항

### 범위 제한
- ✅ `front/` 디렉토리 내부의 JSX 프론트엔드 파일만 작성/수정
- ✅ 메인 랜딩 페이지 컴포넌트(`front/src/pages/MainPage.jsx`)
- ✅ 관련 세부 컴포넌트 명확히 분리

### 핵심 제약
- ❌ 구매/장바구니 기능 제거
- ❌ '구매하기', '장바구니' 버튼 절대 미포함
- ✅ '비교함 담기' 중심 동작
- ✅ 공구는 외부 링크로만 제공

---

## 🏗️ 서비스 핵심 컨셉

### 비즈니스 모델
- 콘텐츠 & 상품 비교 & AI 레시피 & 공구 플랫폼
- 직접 결제/구매 기능 없음
- 사용자는 '비교함'에 상품을 담고 외부로 연결

### 주요 기능
1. **AI 챗봇**: 맞춤형 레시피 추천
2. **상품 비교**: 비교함에 담아 비교
3. **공동구매(공구)**: D-Day 카운트, 외부 링크
4. **크리에이터 콘텐츠**: 추천 레시피 & 생산자 이야기

---

## 📐 메인 화면 구조 (와이어프레임)

### 1️⃣ GNB (Global Navigation Bar)
```
┌─────────────────────────────────────────────┐
│ PingPong Logo | [검색창] | 메뉴 | 회원영역 │
└─────────────────────────────────────────────┘
```

**요소**:
- 좌측: PingPong 로고
- 중앙: 검색창 ("피하고 싶은 원재료나 식재료 검색")
- 내비게이션: [홈] [AI 챗봇] [공구] [카탈로그 비교]
- 우측 회원 영역:
  - 비로그인: [회원가입] [로그인] [위시리스트 ♡]
  - 로그인: [마이페이지] [로그아웃] [위시리스트 ♡]
  - 테스트용 토글 버튼 (개발환경)

---

### 2️⃣ Hero Banner (메인 배너)
```
┌─────────────────────────────────────────────┐
│  내 주방 환경에 딱 맞는                    │
│  맞춤형 AI 레시피 챗봇 출시!                │
│                                            │
│  [AI 레시피 체험하기 →]                    │
│  (클릭 시 `/ai-chat` 이동)                 │
└─────────────────────────────────────────────┘
```

**스타일**: 
- 배경색: 딥그린/에메랄드 톤 (`bg-emerald-900`)
- CTA 버튼: `/ai-chat` 이동

---

### 3️⃣ Creator & Group Buy Section (2x2 Grid)
```
┌──────────────────────────────────────────────┐
│ [크리에이터 추천 아티클 1] | [크리에이터 2]  │
│─────────────────────────────────────────────│
│ [진행중 공동구매 1 D-3]   | [공동구매 2]     │
└──────────────────────────────────────────────┘
```

**크리에이터 아티클 카드**:
- 추천 레시피, 생산자 이야기
- 클릭 시 상세 페이지 이동

**공동구매(공구) 카드**:
- D-Day 태그 표시 (예: D-3)
- 공구 특가 정보
- "공구 참여하기 🔗" 외부 링크 버튼

---

### 4️⃣ Category Navigation (3구역)
```
[전체] [베이커리] [음료/티] [디저트] [신선식품] [간편식] [유기농] [소스/양념]
```

**구성**:
- 총 8개 카테고리 (아이콘 그리드 또는 가로 스크롤)
- 클릭 시 해당 분야 상품 비교 카탈로그 페이지 이동

---

### 5️⃣ Product Compare Catalog (4구역)
```
┌─────────────────────────────────────────────┐
│ [상품 카드 1]    [상품 카드 2]             │
│ [+ 비교함 담기]  [유사 상품 비교]          │
│                                            │
│ [상품 카드 3]    [상품 카드 4]             │
│ [+ 비교함 담기]  [유사 상품 비교]          │
└─────────────────────────────────────────────┘
```

**상품 카드 UI**:
- ❌ 구매하기 버튼 제거
- ❌ 장바구니 버튼 제거
- ✅ [+ 비교함 담기] 버튼
- ✅ [유사 상품 비교] 버튼
- ✅ 클릭 시 토스트 알림 & State 수량 증가

## 📝 UI/UX 핵심 사항

### 색상 팔레트
- 주색: 딥그린/에메랄드 (`bg-emerald-900`, `bg-emerald-600`)
- 강조색: 상황에 맞게 지정
- 텍스트: 가독성 확보

### 반응형 디자인
- 모바일: 1개 컬럼 또는 스택 레이아웃
- 태블릿: 2컬럼
- 데스크톱: 2x2 그리드, 8개 카테고리 가로 배치

### 인터랙션
- 비교함 담기: 토스트 알림 + 수량 증가
- 카테고리 클릭: 페이지 이동
- 공구 링크: 외부 링크 (`target="_blank"`)
