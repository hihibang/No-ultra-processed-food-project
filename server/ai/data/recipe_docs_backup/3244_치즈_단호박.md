# 요리명: 치즈 단호박

## 기본 정보
- 요리 분류: 일품
- 조리 방식: 찌기
- 열량(칼로리): 379.3 kcal
- 나트륨 함량: 248.5 mg

## 필요한 재료
단호박(1개=800g), 달걀(1개), 맛술(1T), 우유(1T), 모차렐라치즈(30g), 그라나파다노치즈(1Ts), 아몬드 플레이크(2Ts), 꿀(1Ts), 파슬리가루(약간)

## 조리 순서
1. 단호박은 3mm 정도 윗부분을 도려내 씨를 제거한 뒤 전자레인지에 5분간 돌려 익힌다., 2. 단호박 씨를 제거한 뒤 속(50g)을 파서 덜어놓는다., 3. 달걀은 곱게 풀어 체에 내린 뒤 맛술, 우유, 모차렐라치즈(20g), 덜어 놓은 호박과 함께 믹서에 넣어 간다., 4. 속을 파낸 단호박에 간 재료를 넣은 뒤 뚜껑을 닫고 전자레인지에 8분간 돌려 익힌다., 5. 뚜껑을 열고 모차렐라치즈(10g)를 올려 전자레인지에 3분간 돌려 녹인다., 6. 단호박을 6~7등분해 그릇에 담고 꿀과 그라나파다노치즈, 아몬드 플레이크, 파슬리가루를 뿌린다.
