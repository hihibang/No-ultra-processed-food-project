# 요리명: 가지볶음

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 볶기
- 열량(칼로리): 37.6 kcal
- 나트륨 함량: 68.0 mg

## 필요한 재료
가지 70g, 생강 0.5g, 고추장 2g, 물엿 2g, 통깨 0.5g, 들기름 2g

## 조리 순서
1. 가지를 깨끗하게 씻어 1x1x4cm로 썬다., 2. 생강을 곱게 다진다., 3. 고추장, 물엿, 통깨와 섞어 양념장을 만든다., 4. 팬에 들기름을 넣고 센불에서 가지를 볶는다., 5. 가지가 다 볶아지면 양념장을 넣어 양념장이 섞일 정도로만 볶는다., 6. 접시에 담는다.
