# 요리명: 잣 호두 강정

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 기타
- 열량(칼로리): 94.0 kcal
- 나트륨 함량: 1.0 mg

## 필요한 재료
잣 3g, 호두 3g, 대추 3g, 통깨 5g [시럽] 물엿 3g, 설탕 2g

## 조리 순서
1. 잣은 고깔을 떼어낸 뒤 젖은 행주로 문질러 먼지를 닦는다., 2. 호두는 미지근한 물에 불려 껍질을 제거한다., 3. 대추는 얇게 돌려 깎아 곱게 다진다., 4. 물엿과 설탕을 냄비에 담고 물을 조금 넣은 뒤 약한불에서 투명한 시럽으로 만든다., 5. 잣, 호두, 통깨에 다진 대추와 시럽을 넣고 덩어리지게 섞는다., 6. 살짝 뜨거울 때 손으로 동그랗게 뭉쳐준다.
