# 요리명: 깐풍주먹밥

## 기본 정보
- 요리 분류: 밥
- 조리 방식: 볶기
- 열량(칼로리): 536.3 kcal
- 나트륨 함량: 111.0 mg

## 필요한 재료
재료 칵테일새우(10g), 다진 쇠고기(15g), 후춧가루(1g), 참기름(7g)
찹쌀현미밥(200g), 밀가루(30g), 파인애플(10g), 부추(10g)
소스 다진 마늘(4g), 다진 붉은 고추(7g), 다진 풋고추(7g), 식초(10g)
함초가루(10g), 설탕(15g)

## 조리 순서
1. 칵테일새우는 잘게 다진다., 2. 다진 쇠고기에 후춧가루와 참기름(3g)으로 밑간한 후 볶는다., 3. 찹쌀현미밥에 참기름(4g)을 넣어 밑간하고 식힌 후 새우와 쇠고기를 넣어 뭉쳐준다., 4. 마늘과 고추는 볶다가 식초와 함초가루, 설탕, 물(30g)을 넣고 졸여 소스를 만든다., 5. 밀가루는 반죽한 뒤 얇게 밀어 삼각형으로 잘라 튀긴 후 기름을 뺀다., 6. 위에 주먹밥을 올리고 파인애플을 올린 후 소스를 곁들여 마무리한다.
