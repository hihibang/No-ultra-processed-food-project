# 요리명: 단호박전

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 굽기
- 열량(칼로리): 310.4 kcal
- 나트륨 함량: 77.0 mg

## 필요한 재료
단호박 50g, 밀가루 50g, 소금 0.2g, 식용유 10g, 물 10g

## 조리 순서
1. 단호박은 껍질을 벗겨 속살은 그대로 두고 씨만 털어 낸다., 2. 속살은 숟가락으로 긁어내어 다진다., 3. 나머지 부분은 채썰어 2~3번 다진 후 소금을 조금 넣고 살짝 절인다., 4. 호박에 물기가 생기면 밀가루를 넣어 되직하게 반죽한다., 5. 팬이 가열되면 식용유를 넣고 한 숟가락씩 떠넣어 얇게 펴서 부친다., 6. 앞뒤로 노릇하게 부치고 접시에 담아 완성한다.
