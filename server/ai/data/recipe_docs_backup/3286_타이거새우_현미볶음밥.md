# 요리명: 타이거새우 현미볶음밥

## 기본 정보
- 요리 분류: 밥
- 조리 방식: 볶기
- 열량(칼로리): 536.9 kcal
- 나트륨 함량: 318.3 mg

## 필요한 재료
[ 2인분 ] 브로콜리(¼개), 양파(¼개), 파프리카(빨강, 노랑 각 ¼개), 쪽파(2대), 블랙타이거새우(8마리), 현미밥(2공기), 청양고추(2개), 레몬(½개), 다진 마늘(3Ts), 버터(3Ts)

## 조리 순서
1. 브로콜리는 윗동만 분리해 다지고, 양파, 파프리카, 청양고추는 잘게 다지고, 쪽파는 송송 썰고, 레몬은 2등분한다., 2. 블랙타이거새우는 깨끗하게 씻은 뒤 머리를 제거한다., 3. 약한 불로 달군 팬에 식용유를 두르고, 다진 마늘을 넣어 튀기듯 볶은 뒤 양파를 넣어 볶는다., 4. 손질한 블랙타이거새우와 버터를 넣은 뒤 새우의 색이 변할 때까지 볶고, 다진 파프리카, 청양고추, 브로콜리를 넣어 2분간 볶는다., 5. 그릇에 현미밥을 담고, 볶은 블랙타이거 새우와 국물을 골고루 뿌린다., 6. 송송 썬 쪽파와 레몬을 올려 마무리한다.
