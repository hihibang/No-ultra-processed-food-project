# 요리명: 건도토리묵버섯들깨국

## 기본 정보
- 요리 분류: 국&찌개
- 조리 방식: 끓이기
- 열량(칼로리): 89.1 kcal
- 나트륨 함량: 457.0 mg

## 필요한 재료
건도토리묵 30g(불린것 50g), 표고버섯 5g, 느타리버섯 5g, 들깨가루 5g, 국멸치 3g, 건다시마 3g, 파 2g, 다진 마늘 2.5g, 국간장 1g, 소금 0.5g, 물 300g

## 조리 순서
1. 물 1컵 반에 국멸치와 건다시마를 넣고 멸치다시마국물 1컵 정도를 내고 다시마는 미리 건져 채 썬다., 2. 건도토리묵은 물에 불려 5cm 길이로 썬다., 3. 표고버섯은 5cm 길이로 채 썰고 느타리버섯은 5cm 길이로 가늘게 찢는다., 4. 파는 씻어 어슷썰기 한다., 5. 멸치다시마국물 1컵에 도토리묵, 표고버섯, 느타리버섯을 넣고 한소끔 끓인다., 6. 5에 들깨가루, 파, 다진 마늘, 다시마를 넣고 국간장과 소금으로 간을 한다.
