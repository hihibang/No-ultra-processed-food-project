# 요리명: 퓨전떡갈비

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 굽기
- 열량(칼로리): 195.85 kcal
- 나트륨 함량: 265.63 mg

## 필요한 재료
소고기 40g, 돼지고기 6g, 양파 15g, 배 10g, 마늘 5g, 생강 2g, 저염간장 3g, 찹쌀가루 5g, 참기름 2g, 참깨 5g

## 조리 순서
1. 고기는 곱게 다지고 야채는 껍질을 제거한다., 2. 배는 갈아 즙을 만들고 양파는 다진 뒤 기름을 두르지 않은 팬에 살짝 볶는다., 3. 마늘과 생강을 곱게 다져 배즙과 섞은 뒤 다진 고기에 넣어 치댄다., 4. 떡갈비 반죽에 저염간장, 참기름을 이용해 밑간을 하고 찹쌀가루를 넣어 찰기를 준다., 5. 둥근 모양으로 빚은 뒤 중간을 살짝 눌러 기름을 두른 팬에 굽는다., 6. 170℃ 오븐에 3분 정도 구워 속까지 익힌다.
