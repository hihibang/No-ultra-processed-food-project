# 요리명: 새우 완자탕

## 기본 정보
- 요리 분류: 국&찌개
- 조리 방식: 끓이기
- 열량(칼로리): 87.0 kcal
- 나트륨 함량: 205.0 mg

## 필요한 재료
새우 살 40g, 달걀흰자 5g, 전분 4g, 당면불린것 10g, 팽이버섯 10g, 부추 5g, 홍고추 3g, 다시마육수 70g, 국간장 1g, 마늘다진것 2g, 소금적당량, 흰 후춧가루 적당량

## 조리 순서
1. 곱게 다진 새우살에 소금, 흰 후춧가루로 밑간한다., 2. 1에 달걀흰자, 전분을 넣어 치댄후 지름 2cm 정도의 완자를 만든다., 3. 불린 당면, 팽이버섯, 부추는 5cm 길이로 자르고 홍고추는 2cm 길이로 채썬다., 4. 냄비에 다시마 육수를 넣어 끓으면 2의 완자를 넣고 불을 줄인다., 5. 완자가 떠오르면 불린 당면, 팽이버섯, 부추, 홍고추 순으로 넣는다., 6. 다진마늘, 국간장, 소금으로 간한다.
