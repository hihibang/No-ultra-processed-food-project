# 요리명: 양파홍초절임

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 56.87 kcal
- 나트륨 함량: 30.64 mg

## 필요한 재료
양파 80g, 홍초 15g, 간장 0.1g, 설탕 1.5g, 홍고추 1g, 청양고추 1g

## 조리 순서
1. 양파는 깨끗이 씻어 한 입 크기로 자른다., 2. 홍고추와 청양고추는 깨끗이 씻어 어슷하게 썬다., 3. 저염간장과 설탕, 홍초를 넣고 끓여 초절임장을 만든다., 4. 초절임장을 뚜껑이 있는 용기에 옮겨 담는다., 5. 초절임장에 양파와 홍고추, 청양고추를 넣는다., 6. 양파홍초절임을 하루정도 숙성시킨다.
