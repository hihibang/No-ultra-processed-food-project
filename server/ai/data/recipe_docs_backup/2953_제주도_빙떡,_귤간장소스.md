# 요리명: 제주도 빙떡, 귤간장소스

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 94.02 kcal
- 나트륨 함량: 9.56 mg

## 필요한 재료
메밀가루 50g, 무 30g, 후추 2g, 다시마 2g, 다진 마늘 5g, 다진 파 5g, 저염간장 5g, 통깨 2g, 귤 즙 10g, 참기름 2g

## 조리 순서
1. 메밀가루에 물을 섞어 메밀 반죽을 만든다., 2. 무를 채 썰어 다시마 육수에 삶는다., 3. 다진 파, 마늘을 볶은 뒤 무와 통깨, 참기름과 섞어 버무린다., 4. 전병을 부친 뒤 무를 넣어 만다., 5. 귤 즙을 조린 뒤 저염간장을 넣고 섞는다., 6. 접시에 담는다.
