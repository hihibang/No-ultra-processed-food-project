# 요리명: 얼갈이 무침

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 끓이기
- 열량(칼로리): 71.7 kcal
- 나트륨 함량: 181.0 mg

## 필요한 재료
얼갈이 배추 60g, 홍고추 0.6g [소스소개저나트륨 무침양념:두부 30g, 된장 3.5g, 마늘 1.5g, 깨 2g, 참기름 1g, 사과 20g, 홍고추 5g,물 15g

## 조리 순서
1. 얼갈이 배추를 씻는다., 2. 씻은 배추는 끓는 물에 데친다., 3. 홍고추는 씨를 빼고 어슷하게 채썬다., 4. 데친 얼갈이 배추를 차가운 물에 씻어 꼭 짠다., 5. 저나트륨 무침양념 재료들을 믹서에 넣고 간다., 6. 4에 채썬 고추와 무침 양념을 넣고 버무린다.
