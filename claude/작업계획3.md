# 푸드 저널 & 식단 이야기 매거진형 기능 개발 작업계획

## 📋 프로젝트 개요
**목표**: 커머스 메인 화면에 건강한 식문화 스토리를 전달하는 매거진형 큐레이션 영역 신설  
**기술 스택**: React v18+, react-router-dom v6, styled-components  
**타겟**: 초가공식품(UPF) 저감 및 건강한 식문화 콘텐츠 큐레이션

---

#### 1-2. Mock 데이터 작성 (`journalMockData.js`)

**구성 요소**:
```javascript
- id: 고유 식별자
- title: 스토리 제목
- summary: 2줄 요약 프리뷰
- category: 카테고리 ('식재료 이야기', '오늘 루틴', '성분 탐구' 등)
- thumbnail: 썸네일 이미지 URL
- readTime: 읽는 시간 (예: "2분 읽기")
- content: 본문 내용 (상세 모달용)
- relatedProducts: 연관 추천 상품 배열 (예: [{name: "자연숙성 유기농 저염간장", id: 123}])
- createdAt: 작성일자 (ISO 8601 형식)
```

**최소 데이터 항목**: 8개 이상의 스토리  
**테마**: 초가공식품 줄이기, 유기농, 저염 식단 등 건강식 테마  
**데이터 소스**: img/이야기.png 참조하여 시각적 일관성 유지

**담당자**: 콘텐츠 담당 / 개발자  
**예상 시간**: 45분  
**완료 체크**: 데이터 구조 검증, 8개 이상 스토리 생성

### **Phase 4: 전체 저널 페이지 개발**

#### 4-1. `JournalPage.jsx` 작성

**기능**:
- 상단: 뒤로가기 버튼, 홈으로 가기 버튼 (또는 네비게이션 바)
- 검색창: 제목, 요약, 카테고리 전체 검색
- 카테고리 필터 탭: "전체", "식재료 이야기", "오늘 루틴", "성분 탐구" 등
- 그리드 카드 목록: 6~8개 이상 노출 (무한 스크롤 또는 페이지네이션 고려)
- 카드 클릭 시: 상세 모달 또는 상세 페이지로 이동

**State 관리**:
- `selectedCategory`: 현재 선택된 카테고리
- `searchTerm`: 검색 입력값
- `filteredData`: 필터링된 스토리 배열
- `selectedStory`: 모달용 선택된 스토리
- `showDetailModal`: 모달 표시 여부

**이벤트 핸들러**:
- `handleCategoryChange(category)`: 카테고리 탭 클릭
- `handleSearch(term)`: 검색 입력
- `handleCardClick(story)`: 카드 클릭 → 모달 노출
- `handleCloseModal()`: 모달 닫기
- `handleNavigateBack()`: 뒤로가기 → `-1`

**담당자**: 개발자  
**예상 시간**: 1.5시간  
**완료 체크**: 필터링 및 검색 정상 작동

### **Phase 5: 라우팅 설정**

#### 5-1. `App.jsx` 라우터 설정

**기존 구조**:
- HomePage: `/` (메인 페이지)
- 다른 기존 라우트...

**신규 추가**:
- JournalPage: `/journal` (전체 저널 페이지)
- JournalDetailPage (선택): `/journal/:id` (개별 상세 페이지, 모달 대신 사용 가능)

**Router 구성**:
```jsx
import { BrowserRouter, Routes, Route } from 'react-router-dom';
import HomePage from './pages/HomePage';
import JournalPage from './pages/JournalPage';

function App() {
  return (
    <BrowserRouter>
      <Routes>
        <Route path="/" element={<HomePage />} />
        <Route path="/journal" element={<JournalPage />} />
        {/* 기존 라우트들... */}
      </Routes>
    </BrowserRouter>
  );
}
```

**라우팅 테스트**:
- `/` → HomePage 렌더링 + FoodJournalSection 노출
- `/journal` → JournalPage 렌더링
- 네비게이션 링크 클릭 → 예상 페이지 이동

**담당자**: 개발자  
**예상 시간**: 30분  
**완료 체크**: 모든 라우트 정상 작동
