# 요리명: 삼색 브레드 스틱

## 기본 정보
- 요리 분류: 기타
- 조리 방식: 기타
- 열량(칼로리): 315.0 kcal
- 나트륨 함량: 1.61 mg

## 필요한 재료
강력분 300g, 소금 3g, 드라이이스트 12g, 버터 36g, 식용유 6g, 당근 50g, 참나물 50g, 연근 30g, 견과류 10g, 물 100ml

## 조리 순서
1. 강력분, 소금, 이스트, 물을 넣어 만든 반죽을 3등분 하여 각각 당근, 참나물, 연근을 다져 넣어 섞어준다., 2. 반죽에 글루텐이 형성되면 각각 식용유와 버터를 넣어 섞고, 연근을 넣은 반죽에는 마지막에 견과류를 넣어 섞는다. ★다른 반죽보다 향이 없는 연근 반죽에 견과류를 넣어 맛을 냈어요., 3. 반죽이 완료되면 3-40분 정도 1차 발효를 한다., 4. 1차 발효 후 30g씩 무게를 달아 둥글리기하고 중간 발효 후 길게 밀어 편다., 5. 20분 정도 2차 발효를 한다., 6. 아랫불 160, 윗불 180℃ 오븐에서 18분 동안 굽는다.
