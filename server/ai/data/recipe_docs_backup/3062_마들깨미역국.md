# 요리명: 마들깨미역국

## 기본 정보
- 요리 분류: 국&찌개
- 조리 방식: 끓이기
- 열량(칼로리): 161.9 kcal
- 나트륨 함량: 173.6 mg

## 필요한 재료
건미역 4g, 마 40g, 깐들깨가루 17g, 건다시마 1g, 참기름 2.5g, 마늘 2.5g, 물 300ml

## 조리 순서
1. 다시 육수를 만들어 준다., 2. 건미역은 불려 잘게 썰어준다., 3. 마는 껍질을 제거한 후 깍둑 썰기하여 준비한다., 4. 참기름을 두르고 미역과 마늘을 볶다가 육수를 부어 끓인다., 5. 끓어오른 미역국에 마를 넣어 익혀준다., 6. 들깨가루를 넣어 한소끔 끓여낸다.
