# 요리명: 굴 두부 국

## 기본 정보
- 요리 분류: 국&찌개
- 조리 방식: 끓이기
- 열량(칼로리): 49.5 kcal
- 나트륨 함량: 257.0 mg

## 필요한 재료
굴 20g, 두부 20g, 마늘다진것 1g, 실파 2g, 김 0.3g, 새우젓 0.5g, 소금 0.2g, 참기름 1g, 다시마 육수 100g, 홍고추 1g

## 조리 순서
1. 굴은 소금으로 깨끗이 씻어 물기를 뺀다., 2. 두부는 2x2x1cm 크기로 썰고, 실파는 2cm 길이로 자른다., 3. 김은 구워서 잘게 찢거나 가위로 자른다., 4. 고추는 채썰어 씨를 제거한다., 5. 다시마 육수를 끓이다가 두부와 굴을 넣고 뭉근히 끓인 뒤 새우젓과 다진 마늘을 넣고 한소끔 끓인다., 6. 실파와 홍고추를 넣고 마지막에 김과 참기름을 넣는다.
