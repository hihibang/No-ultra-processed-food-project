# 요리명: 초코타르트

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 기타
- 열량(칼로리): 154.5 kcal
- 나트륨 함량: 44.3 mg

## 필요한 재료
주재료 > 아몬드가루 90g, 무가당 코코아가루① 12g, 귀리 30g, 코코넛오일 20g, 알룰로스① 20g, 소금 1g
초코필링 > 무가당 코코아가루② 12g, 땅콩버터 12g, 알룰로스② 55g, 아몬드우유 60ml
그릭요거트 토핑 > 그릭요거트 42g, 알룰로스③ 2g

## 조리 순서
1. 볼에 아몬드가루, 무가당 코코아가루①을 체 쳐서 넣고 귀리, 코코넛오일, 알룰로스①, 소금을 넣고 섞어 반죽을 만든다., 2. 반죽은 냉장고에서 30분 동안 휴지한다., 3. 볼에 무가당 코코아가루②를 체 쳐서 넣고 땅콩버터, 알룰로스②를 넣는다. 완전히 섞이면 아몬드우유를 넣고 섞어 초코필링을 만든다., 4. 냉동실에서 30분 동안 굳힌 그릭요거트에 알룰로스③을 섞어 숟가락으로 모양을 잡아 그릭요거트 토핑을 만든다., 5. 머핀 틀에 코코넛오일을 바르고 반죽을 넣어 타르트지 모양을 잡는다. 170°C로 예열한 오븐에 20분 동안 구운 후 완전히 식힌다., 6. 초코필링을 채우고 그릭요거트 토핑을 올려 마무리한다.
