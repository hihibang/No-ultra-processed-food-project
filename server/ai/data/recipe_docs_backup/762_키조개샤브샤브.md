# 요리명: 키조개샤브샤브

## 기본 정보
- 요리 분류: 국&찌개
- 조리 방식: 끓이기
- 열량(칼로리): 85.4 kcal
- 나트륨 함량: 424.8 mg

## 필요한 재료
주재료: 키조개관자 60, 당근 10, 참나물 10, 애호박 10, 표고버섯 20, 느타리버섯 30, 팽이버섯 30, 다시마 국물 200(물 300, 다시마 1, 대파 5) 소스: 간장 4.5, 사과식초 2.5, 올리고당 3.5

## 조리 순서
1. 냄비에 물, 건다시마, 대파를 넣고 약불에서 30분간 맛이 우러나게 끓인다., 2. 체에 걸러 다시마 국물을 만든다., 3. 키조개 관자를 얇게 자른다., 4. 당근은 껍질을 벗기고 채소와 버섯은 깨끗이 씻어 한입 크기로 자른다., 5. 소스 재료를 냄비에 넣고 약불에서 5분간 끓여 양념장을 만든다., 6. 샤브샤브 냄비에 1을 넣고 끓으면 키조개 관자, 채소, 버섯을 넣고 살짝 익혀 소스에 찍어 먹는다.
