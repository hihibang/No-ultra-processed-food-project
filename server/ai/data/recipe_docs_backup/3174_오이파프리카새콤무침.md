# 요리명: 오이파프리카새콤무침

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 11.45 kcal
- 나트륨 함량: 1.05 mg

## 필요한 재료
오이 10g, 파프리카(빨강/노랑) 각 5g, 식초 2g, 설탕 2g

## 조리 순서
1. 오이는 굵은 소금으로 문질러 깨끗이 씻는다., 2. 오이를 적당한 두께로 썰고 4등분 한다., 3. 파프리카는 깨끗이 씻은 후 씨를 제거한다., 4. 파프리카를 적당한 크기로 썬다., 5. 식초, 설탕, 물을 섞어 단촛물을 만든다., 6. 단촛물에 오이, 파프리카를 버무린다.
