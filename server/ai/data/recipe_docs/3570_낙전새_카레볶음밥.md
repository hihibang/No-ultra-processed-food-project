# 요리명: 낙전새 카레볶음밥

## 기본 정보
- 요리 분류: 밥
- 조리 방식: 볶기
- 열량(칼로리): 568.5 kcal
- 나트륨 함량: 451.0 mg

## 필요한 재료
[주재료]백미 60g, 잡곡 15g, 콩 15g, 전복 15g, 낙지 15g, 칵테일 새우 15g,  양파 15g, 대파 15g, 마늘 10g, 브로콜리 30g
[양념]강황가루 15g, 올리브유 30g, 후추 3g, 굴소스 3g, 파슬리가루 3g

## 조리 순서
1. 밥솥에 백미, 잡곡, 콩을 넣어 잡곡밥을 만든다., 2. 양파, 대파, 마늘, 브로콜리를 잘게 다진다., 3. 낙지, 전복을 끓는 물에 데친다., 4. 낙지, 전복을 잘게 자른다., 5. 달군 팬에 올리브유를 두르고 마늘, 대파, 칵테일 새우, 낙지, 전복, 양파, 브로콜리 순으로 볶는다., 6. 재료가 익으면 잡곡밥을 넣고 굴소스, 강황가루, 후추를 넣고 볶은 후 파슬리가루를 뿌려 마무리한다.
