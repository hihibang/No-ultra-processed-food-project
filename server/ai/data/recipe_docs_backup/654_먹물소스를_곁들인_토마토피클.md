# 요리명: 먹물소스를 곁들인 토마토피클

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 140.9 kcal
- 나트륨 함량: 73.2 mg

## 필요한 재료
마(50g), 우엉(50g), 토마토(200g), 배(1/2개), 새싹(10g),
피클링스파이스(10g), 와인(20g), 먹물(10g), 설탕(50g),
식초(30g), 소금(0.2g)

## 조리 순서
1. 물 한 컵에 설탕, 식초, 소금, 피클링스파이스를 넣고 식촛물을 만든다., 2. 배는 스쿱으로 동그랗게 판다., 3. 토마토는 1/6등분으로 썬다., 4. 마와 우엉은 슬라이스 한다., 5. 썰어 놓은 마와 우엉을 식촛물에 담근다., 6. 와인에 먹물, 설탕을 넣고 섞어 식촛물에 넣고 배, 토마토, 새싹을 넣는다.
