# 요리명: 과일 피클 젤리

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 기타
- 열량(칼로리): 78.9 kcal
- 나트륨 함량: 169.5 mg

## 필요한 재료
방울토마토(50g), 바나나(80g), 청포도(50g), 젤라틴(7.5g), 한천가루(0.25g), 피클링 스파이스(5g), 사과식초(10g), 설탕(3g), 올리고당(5g), 소금(1g)

## 조리 순서
1. 과일은 한입 크기로 썬다., 2. 젤라틴은 찬물에 불린다., 3. 냄비에 물(100㎖), 양념을 넣어 끓인 뒤 피클링 스파이스를 체로 거른다., 4. ③에 불린 젤라틴과 한천가루를 넣어 녹인 뒤 한 김 식힌다., 5. 유리 용기에 손질한 과일을 담고 식힌 ④의 젤라틴 물을 붓는다., 6. 냉장실에서 1시간 30분간 굳혀 마무리한다.
