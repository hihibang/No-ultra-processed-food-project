# 요리명: 중국식 바비큐 폭립

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 굽기
- 열량(칼로리): 311.0 kcal
- 나트륨 함량: 352.0 mg

## 필요한 재료
돼지갈비(바비큐용) 120g [소스] 양파작게자른것 20g, 마늘다진것 4g, 식용유 1g, 레드와인식초 2g, 황설탕 2g, 꿀 5g, 데미글라스 10g, 토마토케첩 2g, 머스타드 2g, 우스터소스 2g, 케이엔페퍼약간, 소금적당량, 후추적당량

## 조리 순서
1. 소스재료를 볼에 넣고 잘 섞는다., 2. 소스를 돼지갈비에 골고루 바른 뒤 6시간 이상 재운다., 3. 재운 돼지갈비를 호일로 감싼다., 4. 3을 170℃의 오븐에서 30분간 굽는다., 5. 구운 돼지갈비의 호일을 벗긴다., 6. 5의 갈비가 부드러워 질 때까지 약 30분간 소스를 골고루 발라가며 굽는다.
