# 요리명: 콩국물소스를 곁들인 게살 냉채

## 기본 정보
- 요리 분류: 일품
- 조리 방식: 기타
- 열량(칼로리): 231.6 kcal
- 나트륨 함량: 475.4 mg

## 필요한 재료
게살(50g), 수박(70g), 가지(30g), 적채(20g), 브로콜리(20g), 두부(100g), 우유(100㎖), 꿀(5g), 소금(1g), 후춧가루(2g), 올리브유(5㎖)

## 조리 순서
1. 게살은 잘게 찢고, 수박, 가지, 적채, 브로콜리는 5cm 길이로 채 썬다., 2. 끓는 물(5컵)에 손질한 브로콜리를 1분간 데쳐 찬물에 담가 체에 밭친다., 3. 중간 불로 달군 팬에 올리브유(5㎖)를 두른 뒤 가지를 2분간 볶는다., 4. 믹서에 콩국물소스 재료를 넣고 갈아 콩국물소스를 만든다., 5. 그릇에 수박 → 가지 → 브로콜리 → 적채 → 게살 순으로 쌓는다., 6. 콩국물소스를 부어 마무리한다.
