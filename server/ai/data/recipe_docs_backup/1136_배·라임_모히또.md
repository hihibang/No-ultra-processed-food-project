# 요리명: 배·라임 모히또

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 기타
- 열량(칼로리): 102.7 kcal
- 나트륨 함량: 16.2 mg

## 필요한 재료
배(1개), 라임(1개), 탄산수(500g),
애플민트(5g), 스테비아(5g)

## 조리 순서
1. 라임을 반으로 잘라 즙을 짠다., 2. 라임즙과 배를 믹서에 넣고 간다., 3. 2번에 애플민트와 올리고당,탄산수를 넣고 믹서로 간다., 4. 냉동실에 3번을 넣고 얼린다., 5. 얼린 모히또를 믹서에 갈아 슬러시처럼 만든다., 6. 잔에 담고 애플민트로 장식한다.
