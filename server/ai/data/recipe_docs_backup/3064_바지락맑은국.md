# 요리명: 바지락맑은국

## 기본 정보
- 요리 분류: 국&찌개
- 조리 방식: 끓이기
- 열량(칼로리): 9.9 kcal
- 나트륨 함량: 82.7 mg

## 필요한 재료
•필수재료 : 바지락(60g), 팽이버섯(20g), 홍고추(5g), 쑥갓(2g)
•육수 : 다시마(5g), 청양고추(3g), 무(10g), 대파(5g), 물(300g)

## 조리 순서
1. 물에 다시마, 청양고추, 대파, 한 입 크기로 썬 무를 넣고 끓인다., 2. 육수가 끓으면 청양고추와 다시마를 건진다., 3. 해감한 바지락을 넣고 끓인다., 4. 팽이버섯은 밑동을 자른 뒤 적당히 가르고, 홍고추는 어슷 썰고, 쑥갓은 먹기 좋은 크기로 썬다., 5. 국에 팽이버섯을 넣고 끓인다., 6. 홍고추와 쑥갓을 넣고 마무리한다.
