# 요리명: 두릅부추 소고기말이

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 끓이기
- 열량(칼로리): 321.7 kcal
- 나트륨 함량: 347.3 mg

## 필요한 재료
소고기(홍두깨살, 100g), 부추(30g), 양파(30g), 두릅(50g),
대파(20g), 마늘(20g), 저염간장(30g), 후춧가루(0.01g)

## 조리 순서
1. 동량의 물과 저염간장에 대파, 양파, 마늘을 넣고 은근히 졸인다., 2. 마늘이 익을 정도로 끓으면 체에 거른다., 3. 부추는 길게 썰고, 양파는 채썬다, 4. 두릅은 데친 후 찬물에 헹군다., 5. 졸인 간장에 요리술을 넣고 다시 졸인다., 6. 고기를 구운 뒤 준비한 야채와 두릅을 넣고 돌돌 말아 간장에 졸인다.
