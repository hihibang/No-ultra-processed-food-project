# 요리명: 건강 마늘 꿀환

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 튀기기
- 열량(칼로리): 167.0 kcal
- 나트륨 함량: 13.0 mg

## 필요한 재료
마늘 50g, 잣 2g, 꿀 10g, 검은깨 5g, 카스텔라가루 10g

## 조리 순서
1. 마늘은 꼭지를 떼고 찜통에 무르도록 찐다., 2. 쪄 낸 마늘을 손절구에 곱게 으깬다, 3. 잣은 고깔을 떼고 겉면을 깨끗하게 닦은 뒤 가루를 만든다., 4. 2에 꿀, 검은깨, 잣가루를 넣고 잘 혼합한다., 5. 4에 카스텔라 가루를 넣어 농도를 맞춘다., 6. 반죽을 조금씩 떼어 동그랗게 굴려 꿀환을 만든다.
