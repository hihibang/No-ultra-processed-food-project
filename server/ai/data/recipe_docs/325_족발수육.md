# 요리명: 족발수육

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 끓이기
- 열량(칼로리): 282.2 kcal
- 나트륨 함량: 471.7 mg

## 필요한 재료
●주재료 : 양념족발 200g, 고구마 150g, 가지 150g, 맥주 400g, 백김치 50g
●백김치 무침양념 : 참기름 15g, 통깨 3g

## 조리 순서
1. 조미된 족발은 뜨거운 맥주에 데쳐내 기름기를 제거한다., 2. 고구마는 편으로 썰어 냉수에 헹궈 기름 없는 팬에 구워준다., 3. 가지는 편으로 썰어서 수분을 제거한다., 4. 가지는 편으로 썰어 살짝 구워준다., 5. 백김치는 물에 헹궈서 손으로 꼭 짠 후 송송 썰어서 양념을 해 무쳐준다., 6. 무쳐준 김치와 함께 구워진 채소와 족발수육을 담아 완성한다.
