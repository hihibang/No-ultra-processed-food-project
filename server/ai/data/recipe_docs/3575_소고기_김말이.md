# 요리명: 소고기 김말이

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 굽기
- 열량(칼로리): 255.8 kcal
- 나트륨 함량: 135.2 mg

## 필요한 재료
1인분 기준<br>
[주재료] 소고기(치맛살)(100g), 김(6g(3장)), 튀김가루(20g)
<br>[양념] 식용유(45g), 다진 쪽파(10g), 다진 마늘(12g), 저염간장(4g), 고춧가루(12g), 깨(20g), 후추(3g), 물(반죽용)(15ml), 물(양념장용)(4ml)

## 조리 순서
1. 소고기는 키친타월로 핏물을 제거한다., 2. 다진 쪽파, 다진 마늘, 저염간장, 고춧가루, 깨(18g), 물(4ml)을 섞어 양념장을 만든다., 3. 튀김가루와 물(15ml)을 섞어 반죽을 만든다, 4. 손질한 소고기는 후추로 밑간하여 한입 크기로 다지고 김 위에 올려 돌돌 말아 김말이를 만든다., 5. 김말이에 반죽을 묻히고 달군 팬에 식용유를 두르고 김말이를 앞뒤로 굽는다., 6. 접시에 담고 양념장, 깨를 올려 마무리한다.
