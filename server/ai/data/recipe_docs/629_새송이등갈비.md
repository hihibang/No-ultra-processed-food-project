# 요리명: 새송이등갈비

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 끓이기
- 열량(칼로리): 382.3 kcal
- 나트륨 함량: 1554.7 mg

## 필요한 재료
돼지고기(등갈비, 200g), 새송이버섯(1개), 당근(30g),
대파(20g), 양파(30g), 저염간장(30g), 후춧가루(0.01g),
올리고당(20g), 마늘(20g)

## 조리 순서
1. 등갈비는 찬물에 담궈 핏물을 빼고 끓는 물에 데친다., 2. 새송이버섯은 길쭉하게 슬라이스로 썰어둔다., 3. 당근, 양파, 대파는 큼직하게 썰어, 뜨거운 물에 담군다., 4. 담궈 놓은 야채를 걸러 야채물을 만든다., 5. 냄비에 야채물을 넣고 저염간장과 올리고당, 다진마늘, 후춧가루를 섞는다., 6. 야채간장에 등갈비를 넣고 은근히 졸이다가, 썰어놓은 야채와 새송이버섯을 넣고 윤기나게 졸인다.
