# 요리명: 바비큐리조또

## 기본 정보
- 요리 분류: 밥
- 조리 방식: 끓이기
- 열량(칼로리): 301.0 kcal
- 나트륨 함량: 269.9 mg

## 필요한 재료
통삼겹 200g
조림장 : 맛간장 30g, 통후추 2g, 발사믹식초 30g, 흰후추 1g
청국장리조뜨 : 밥 150g, 청국장가루 15g, 야채육수 200g, 감자 30g
올리브오일 15g, 영양부추 20g
곁들이채소 : 적양배추 30g, 사과 70g, 마늘 25g, 올리브오일 10g

## 조리 순서
1. 사과와 적양배추는 먹기 좋은 크기로 잘라준다., 2. 감자를 작은 깍두기 모양으로 자르고 영양부추는 송송 잘라주어 청국장 리조또를 만들어준다., 3. 준비된 곁들이 채소를 올리브오일에 볶아준다., 4. 준비된 통삼겹은 물에 한번 80% 이상 데쳐준 후 조림장 재료에 물 200g을 넣고 은근히 졸여서 익혀준다., 5. 조림장에 졸여지는 통삼겹에 장이 한 큰술 남을 정도까지 졸여준다., 6. 접시에 곁들이 채소와 청국장 리조또를 함께 올려 셋팅한다.
