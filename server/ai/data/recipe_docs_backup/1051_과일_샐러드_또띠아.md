# 요리명: 과일 샐러드 또띠아

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 기타
- 열량(칼로리): 277.0 kcal
- 나트륨 함량: 84.0 mg

## 필요한 재료
자몽 30g, 오렌지 30g, 키위 30g, 사과 30g, 플레인 요구르트 30g, 꿀 5g, 또띠아 45g

## 조리 순서
1. 자몽은 껍질을 벗겨내고 과육만 0.5cm 주사위모양으로 자른다., 2. 오렌지는 껍질을 벗겨내고 과육만 자몽과 같은 크기로 자른다., 3. 키위도 껍질을 벗겨내고 자몽과 같은 크기로 자른다., 4. 썰어 둔 과일에 플레인 요거트, 꿀을 넣고 버무린다., 5. 또띠아를 반으로 자른다., 6. 버무린 과일을 넣고 말아준다.
