# 식품 쇼핑몰 좌측 사이드바 필터 컴포넌트 작업계획

## 📋 프로젝트 개요
식품 쇼핑몰 카탈로그의 **좌측 사이드바 필터 컴포넌트** 구현  
UI 레이아웃 기준: `검색창.png` 참고  
주요 초점: NOVA 가공 등급 필터 + 인터랙티브 팝오버 기능

---

## 🎯 핵심 요구사항

### 1️⃣ 사이드바 구조 (Layout)

#### 📂 상단: 카테고리 섹션
- 식품 카테고리 목록 표시
- 각 카테고리 선택 시 동적 변경 반영
- UI: 메뉴 아이콘(☰) + "카테고리" 텍스트

#### 🏷️ 중단: NOVA 가공 등급 필터 (다중 선택 체크박스)
```
NOVA 가공 등급 [?]  ← 정보 아이콘 (팝오버 트리거)

☐ NOVA 1 (자연/최소 가공)       🟢 #10B981
☐ NOVA 2 (가공 식재료)          🟡 #F59E0B
☐ NOVA 3 (가공식품)             🟠 #F97316
☐ NOVA 4 (초가공식품)           🔴 #EF4444
```

**디자인 상세:**
- 각 항목 앞에 해당 색상의 원형 도트(●) 배치
- 텍스트와 도트 정렬 (좌측 정렬)
- 체크박스 선택 시 상태 변경 및 콜백 발동

#### 💊 하단 1: 영양성분 필터
```
영양성분 필터

☐ 저당 (100g당 5g 미만)
☐ 저염/저나트륨
☐ 무트랜스지방
```

#### ⚠️ 하단 2: 제외할 첨가물 필터
```
제외할 첨가물 필터

☐ 합성감미료 제외
☐ 합성향료 제외
☐ 보존료 제외
```

#### 🔄 최하단: 필터 초기화 버튼
- 모든 체크박스 선택 해제
- 텍스트: "선택 필터 초기화"
- 버튼 스타일: 아웃라인 또는 세컨더리 스타일

### 팝오버 동작
- **트리거:** 클릭 또는 마우스 호버
- **애니메이션:** 부드러운 페이드인 트랜지션
- **종료:** 외부 영역 클릭 시 닫기 (Click Outside)

### 팝오버 콘텐츠

**제목:**
```
NOVA 식품 분류 체계란?
```

**설명:**
```
브라질 상파울루 대학에서 개발한 가공 정도에 따른 
4단계 국제 공인 식품 분류 기준입니다.

🟢 1등급 (자연/최소 가공)
   - 가공되지 않거나 최소 가공된 자연 식품
   - 예: 신선한 과일, 채소, 곡물, 견과류

🟡 2등급 (가공 식재료)
   - 조리에 사용되는 가공 식재료
   - 예: 기름, 소금, 설탕, 벌꿀

🟠 3등급 (가공식품)
   - 1등급 + 2등급 결합 가공식품
   - 예: 통조림, 단순 치즈, 잼

🔴 4등급 (초가공식품 - UPF)
   - 공업적 공정을 거친 초가공식품
   - 착향료, 감미료, 유화제, 증점제 등 포함
   - 예: 스낵, 과자, 음료수, 즉석식품
```

## 💾 상태 관리 (State Management)

### onFilterChange 콜백 구현
필터 변경 시 상위 컴포넌트에 데이터 전달

**전달 객체 구조:**
```javascript
{
  categories: ['카테고리1', '카테고리2'],           // 선택된 카테고리
  novaGrades: [1, 3, 4],                          // 선택된 NOVA 등급
  nutritionFilters: ['lowSugar', 'lowSodium'],    // 영양성분 필터
  excludedAdditives: ['artificial-sweetener'],     // 제외 첨가물 필터
}
```
