# 요리명: 단호박닭꼬치

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 굽기
- 열량(칼로리): 441.5 kcal
- 나트륨 함량: 645.9 mg

## 필요한 재료
닭다리살(120g), 우유(20g), 소금(0.3g), 후춧가루(0.05g)
떡볶이떡(30g), 단호박(50g), 양파(20g), 대파(20g), 꼬치(3개)
- 소스 : 고추장(20g), 다진마늘(20g), 다진양파(20g), 케첩(20g)
올리고당(20g)

## 조리 순서
1. 닭다리살은 뼈를 발라 일정 크기로 자른 뒤 우유에 재워둔다., 2. 재워둔 닭다리살에 소금과 후춧가루를 뿌려놓는다., 3. 단호박은 속을 파서 잘라 삶아 준비한다., 4. 떡볶이떡은 뜨거운 물에 살짝 불리고, 대파는 단호박 크기로 잘라 준비한다., 5. 고추장과 다진마늘, 다진양파, 케첩, 올리고당을 넣고, 골고루 섞어 양념장을 만들어 놓는다., 6. 꼬치에 준비한 닭다리살과 단호박, 양파, 떡볶이떡, 대파를 꽂아 은근히 초벌로 굽고, 다시 만들어 놓은 양념장을 발라 구워 완성한다.
