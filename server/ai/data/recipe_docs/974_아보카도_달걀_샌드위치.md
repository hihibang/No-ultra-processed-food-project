# 요리명: 아보카도 달걀 샌드위치

## 기본 정보
- 요리 분류: 일품
- 조리 방식: 굽기
- 열량(칼로리): 153.0 kcal
- 나트륨 함량: 272.0 mg

## 필요한 재료
달걀 20g, 마요네즈 1g, 디존 머스타드 1g, 레몬주스 2g, 식빵 35g, 아보카도 6g, 워터크레스 1g, 소금 약간, 후추 약간

## 조리 순서
1. 달걀을 완숙으로 삶아 찬물에 담궈 식혀 껍질을 벗긴 뒤 볼에 넣어 포크로 거칠게 으깬다., 2. 으깬 달걀에 머스타드, 레몬주스, 소금, 후춧가루, 마요네즈를 섞는다., 3. 아보카도는 껍질을 제거하고 얇게 슬라이스 한다., 4. 식빵은 노릇하게 양면을 굽는다., 5. 4에 아보카도를 얹고 그 위에 달걀 샐러드를 얹어 식빵으로 덮는다., 6. 샌드위치의 가장자리 부분은 잘라내고 원하는 적당한 크기로 자른다.
