# 요리명: 포두부채소잡채

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 볶기
- 열량(칼로리): 289.0 kcal
- 나트륨 함량: 308.2 mg

## 필요한 재료
•필수 재료 : 포두부(100g), 참느타리버섯(45g), 양파(45g), 게맛살(15g), 청피망(15g), 홍피망(15g), 파(10g), 생강(3g), 식용유(3g)
•양념 : 다진마늘(10g), 설탕(15g), 노두유(3g)

## 조리 순서
1. 포두부, 양파, 피망, 파, 생강은 가늘게 채 썬다., 2. 참느타리버섯, 게맛살은 가늘게 찢는다., 3. 냄비에 물을 끓이고 포두부는 미리 데쳐 체에 밭쳐 물기를 뺀다., 4. 팬에 식용유를 두른 뒤 파, 다진 마늘, 생강을 볶는다., 5. 손질한 채소와 참느타리버섯, 게맛살을 넣어 볶는다., 6. 채소가 익으면 데쳐 놓은 포두부를 넣고 볶다가 노두유와 설탕으로 간을 해 마무리한다.
