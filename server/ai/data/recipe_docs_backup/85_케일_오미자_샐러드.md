# 요리명: 케일 오미자 샐러드

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 60.0 kcal
- 나트륨 함량: 80.0 mg

## 필요한 재료
케일 샐러드
보라로즈케일 15g(3장), 흰로즈케일 15g(3장), 케일 15g(3장)
오미자 드레싱
오미자물 100g(1/2컵), 요리당 15g(1큰술), 식초 2g(1/2작은술)

1. 케일은 깨끗이 씻어 잎은한입 크기로 자르고 줄기는 잘게 다진다.a, 2. 오미자물, 요리당, 식초를 섞는다.b, 3. (1)의 케일의 다진 줄기를 넣어 드레싱을 만든다.c, 4. 그릇에 케일을 담고 오미자 드레싱을 끼얹는다.d
