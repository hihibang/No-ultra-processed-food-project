# 요리명: 양배추 쌈말이

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 찌기
- 열량(칼로리): 125.8 kcal
- 나트륨 함량: 85.2 mg

## 필요한 재료
양배추(120g), 돼지고기(100g), 깻잎(5장), 사과(1/2개),
파프리카(50g), 당근(20g), 다시마(10g), 마늘(10g),
저염간장(20g), 후춧가루(0.01g), 가쓰오부시(10g)

## 조리 순서
1. 물에 다시마를 넣고 끓인다., 2. 끓여 놓은 다시마 육수에 마늘, 저염간장, 가쓰오부시를 넣고 살짝 끓인 뒤 걸러서 소스를 만든다., 3. 양배추는 찜통에 찐다., 4. 돼지고기는 저염간장과 후춧가루를 뿌려 볶고 식힌다, 5. 파프리카, 사과, 당근은 굵게 채썬다., 6. 쪄낸 양배추에 깻잎과 썰어놓은 야채를 올려 둥그렇게 말아 준비한 소스에 살짝 적신다.
