# 요리명: 콜라비물김치

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 24.1 kcal
- 나트륨 함량: 1178.3 mg

## 필요한 재료
콜라비 10g, 당근 3g, 오이 6g, 청고추 2g, 홍고추 1g, 실파 0.5g, 소금 0.5g, 물 60g, 찹쌀가루 10g, 배 10g, 적양파 10g, 소금 1g

## 조리 순서
1. 콜라비, 당근, 오이는 나박 썬다., 2. 고추는 둥글게 썰고 실파는 3cm 길이로 썬다., 3. 콜라비를 소금에 살짝 절인다., 4. 물에 찹쌀을 풀어 찹쌀풀을 쑤어 식힌다., 5. 찹쌀풀에 배와 적양파를 갈아 넣어 국물을 만든다., 6. 국물에 소금을 넣어 간을 맞추고 썰어놓은 채소에 부어 용기에 담아 익혀 먹는다.
