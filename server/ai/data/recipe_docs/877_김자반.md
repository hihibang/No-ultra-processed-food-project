# 요리명: 김자반

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 45.2 kcal
- 나트륨 함량: 232.0 mg

## 필요한 재료
김 10g, 마늘 8g, 생강 5g, 통깨 1.3g [소스소개]양념간장:물 30g, 간장 2g, 설탕 2g, 물엿 1g, 식초 1g, 홍고추 1g

## 조리 순서
1. 김은 티를 골라낸다., 2. 홍고추, 마늘, 생강은 곱게 채썬다., 3. 간장소스의 양념들은 모두 합하여 20분 가량 낮은 불에서 끓여서 식힌다., 4. 김은 먹기 좋은 크기로 12~18등분으로 자른다., 5. 양념간장에 마늘, 생강, 홍고추채를 섞는다., 6. 김을 차곡차곡 쌓은 뒤 양념간장을 위에 부어준다.
