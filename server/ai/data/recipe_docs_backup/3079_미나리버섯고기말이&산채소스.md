# 요리명: 미나리버섯고기말이&산채소스

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 굽기
- 열량(칼로리): 287.6 kcal
- 나트륨 함량: 83.6 mg

## 필요한 재료
돈등심 80g, 새송이버섯 24g, 미나리 18g, 후추 0.3g, 찹쌀가루 15g, 참나물 5g, 취나물 5g, 올리브오일 10g, 땅콩 2g, 파마산치즈 1g, 마늘 1g

## 조리 순서
1. 돈등심은 널찍하게 성형한다., 2. 새송이 버섯은 길게 채썰고, 미나리도 비슷한 사이즈로 썰어 준다., 3. 고기에 미나리, 새송이를 감싸 말아 찹쌀가루를 묻혀 굽는다., 4. 참나물, 취나물, 올리브오일, 땅콩, 마늘, 후추를 믹서에 갈아 소스를 만든다., 5. 소스에 파마산 치즈를 섞어준다., 6. 구워진 고기에 소스를 곁들여 낸다.
