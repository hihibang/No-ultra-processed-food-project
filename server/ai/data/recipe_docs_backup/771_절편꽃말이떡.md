# 요리명: 절편꽃말이떡

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 찌기
- 열량(칼로리): 115.6 kcal
- 나트륨 함량: 132.5 mg

## 필요한 재료
절편 35, 거피녹두 12.5, 물 200, 다진 호두 2, 진달래꽃 2.5, 설탕 2, 소금 0.2

## 조리 순서
1. 거피녹두를 깨끗이 씻는다., 2. 씻은 녹두에 물을 넣고 푹 삶아낸다., 3. 삶아 낸 녹두를 체에 밭쳐 물기를 제거하고 으깬다., 4. 마른 팬에 녹두 소를 넣어 살짝 볶아 수분을 날린 다음 설탕, 소금으로 간한다., 5. 절편을 5cm 길이로 잘라 밀대로 얇게 민다., 6. 절편에 녹두소와 호두를 넣고 돌돌 말아 진달래를 붙인다.
