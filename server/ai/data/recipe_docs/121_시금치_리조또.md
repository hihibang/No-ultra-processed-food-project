# 요리명: 시금치 리조또

## 기본 정보
- 요리 분류: 밥
- 조리 방식: 끓이기
- 열량(칼로리): 121.3 kcal
- 나트륨 함량: 197.1 mg

## 필요한 재료
밥 180g(1컵), 시금치 50g(1/2개), 마 10g(5cm), 두유 150g(3/4컵), 소금 1g, 버터 8g(1½작은술), 후춧가루 1g

## 조리 순서
1. 시금치는 뚜껑을 열고 데친 후, 물기를 뺀다., 2. 마, 시금치, 두유를 함께 갈아 체에 거른다., 3. 가열된 팬에 버터를 두르고 약불에서 2와 밥을 넣어 밥의 색을 입히고 소금, 후추가루로 간을 한다.
