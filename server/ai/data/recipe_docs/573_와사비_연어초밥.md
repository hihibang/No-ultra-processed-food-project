# 요리명: 와사비 연어초밥

## 기본 정보
- 요리 분류: 밥
- 조리 방식: 기타
- 열량(칼로리): 417.6 kcal
- 나트륨 함량: 76.0 mg

## 필요한 재료
연어(100g), 쌀(150g), 당근(20g), 표고버섯(3장),
겨자가루(10g), 새싹(10g), 파슬리(5g), 식초(10g), 설탕(20g),
소금(0.2g)

## 조리 순서
1. 연어는 끝을 뾰족하게 살려 슬라이스한다., 2. 쌀은 깨끗이 씻어 30분 이상 불려 밥을 지어 식힌다., 3. 냄비에 식초, 설탕, 소금 약간과 물을 동량으로 넣고 끓인 뒤 식혀 촛물을 만들어 밥에 넣고 골고루 섞는다., 4. 당근과 표고버섯은 입자있게 다져 살짝 볶아 식혀놓은 초밥에 넣고 잘 섞어준다., 5. 와사비 가루에 30℃정도의 물을 넣고 섞은 뒤 발효 시키고, 초밥 형태를 만들어 그 위에 와사비를 바르고 연어를 올린 후 접시에 담는다, 6. 새싹과 파슬리는 찬물에 담았다 건져 물기를 빼고, 연어 초밥 옆에 올린다.
