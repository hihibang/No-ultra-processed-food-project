# 요리명: 주꾸미연포탕

## 기본 정보
- 요리 분류: 국&찌개
- 조리 방식: 끓이기
- 열량(칼로리): 90.3 kcal
- 나트륨 함량: 280.6 mg

## 필요한 재료
주꾸미 200g, 무 30g, 양파 50g, 대파 20g, 미나리 20g, 단호박 25g, 청고추 25g
국물 : 해물육수 400g, 청양고추 20g, 마늘 10g, 흰후추 1g

## 조리 순서
1. 주꾸미는 세척해 물기를 빼준다., 2. 무와 단호박은 먹기 좋게 썰어준다., 3. 청고추, 미나리, 양파를 먹기 좋게 썰어준다., 4. 청양 고추를 어슷하게 썰고 마늘은 편으로 썰어 국물을 끓여준다., 5. 국물이 만들어지면 무, 단호박을 넣고 끓여준다., 6. 국물에 대파를 넣어주고 모든 재료를 넣어 완성한다.
