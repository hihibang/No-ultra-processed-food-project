# 요리명: 양배추 깻잎 피클

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 14.1 kcal
- 나트륨 함량: 337.0 mg

## 필요한 재료
양배추 16g, 깻잎 6g, 설탕 2g, 청고추 1g, 홍고추 1g [소스소개]피클소스:물 35g, 식초 2g. 소금 1g, 통후추 0.5g

## 조리 순서
1. 물, 식초, 설탕, 소금, 통후추를 살짝 끓인 후 식혀 준비한다., 2. 양배추와 깻잎을 한장씩 켜켜이 쌓는다., 3. 깻잎 크기에 맞추어 썬다., 4. 청, 홍고추는 어슷썰어 씨를 털어낸다., 5. 그릇에 양배추, 깻잎, 청·홍고추를 무거운 것으로 눌러놓아 뜨지 않게 한 다음 준비한 피클국물을 붓는다., 6. 뚜껑을 닫아 밀봉하여 냉장고에 보관한다.
