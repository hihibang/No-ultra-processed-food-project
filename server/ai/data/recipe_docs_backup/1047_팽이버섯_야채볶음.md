# 요리명: 팽이버섯 야채볶음

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 볶기
- 열량(칼로리): 83.0 kcal
- 나트륨 함량: 14.0 mg

## 필요한 재료
팽이버섯 70g, 청경채 50g, 참기름 2g, 식용유 2g, 물전분 6g, 소금 적당량

## 조리 순서
1. 팽이버섯은 밑동을 제거하고 4cm 길이로 자른다., 2. 청경채는 겉잎을 떼어낸 뒤 반으로 가른 뒤 팽이버섯과 같은 길이로 자른다., 3. 썰어 놓은 팽이버섯과 청경채를 끓는 물에 데친다., 4. 기름을 두른 팬에 팽이버섯과 청경채를 볶는다., 5. 물 전분을 넣어 농도를 맞춘다., 6. 참기름을 뿌려 완성한다.
