# 요리명: L..A갈비구이

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 굽기
- 열량(칼로리): 310.8 kcal
- 나트륨 함량: 301.7 mg

## 필요한 재료
L.A갈비(200g), 배(20g), 양파(20g)
- 양념 : 저염간장(20g), 월계수잎(5g), 통후추(5g)
올리고당(20g), 정종(10g), 설탕(10g), 매실액(10g)
대파 다진것(20g), 다진 마늘(20g), 참기름(3g)
통깨(5g)

## 조리 순서
1. L.A 갈비는 물에 담그어 핏물과 갈비 톱밥을 제거시켜 놓는다., 2. 강판에 배와 양파를 곱게 갈아 준비 한다., 3. 핏물을 제거한 갈비에 배즙과 양파즙을 넣어 숙성시킨다., 4. 냄비에 저염간장과 월계수잎, 통후추, 올리고당, 정종, 설탕, 물, 매실액을 넣어 은근히 약 30분 정도 끓여 식힌다., 5. 끓여 식힌 간장에 파, 마늘, 참기름, 통깨를 넣는다., 6. 숙성시킨 L.A 갈비에 만들어 놓은 양념을 넣고 다시 하루 정도 더 숙성 후 팬에 구워 완성한다.
