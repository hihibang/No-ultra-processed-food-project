# 요리명: 콜라비 깍두기

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 14.0 kcal
- 나트륨 함량: 40.5 mg

## 필요한 재료
•필수재료 : 콜라비(80g), 쪽파(5g), 홍고추(0.5g), 생강(0.1g), 양파(0.1g), 마늘(1g)
•양념장 : 고춧가루(4g), 액젓(1g), 매실청(0.2g)
•양념 : 천일염(0.1g)

## 조리 순서
1. 콜라비는 껍질을 벗긴 뒤 깍둑 썬다., 2. 손질한 콜라비에 천일염을 뿌려 1시간 동안 절인다., 3. 홍고추, 양파, 생강, 마늘을 믹서에 곱게 간다., 4. 갈아 낸 채소에 양념장 재료를 넣어 양념장을 만든다., 5. 절여 놓은 콜라비는 물기를 제거하고, 쪽파는 적당한 길이로 썬다., 6. 콜라비에 쪽파, 양념장을 넣고 버무려 하루 동안 숙성해 마무리한다.
