# 요리명: 저염 동치미

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 57.2 kcal
- 나트륨 함량: 52.2 mg

## 필요한 재료
함초 25g, 사과 100g, 양파 25g, 무 100g, 쪽파 10g, 청고추 20g
홍고추 15g, 마늘 10g, 함초소금 2g, 찹쌀가루 15g, 매실청 30g

## 조리 순서
1. 함초와 쪽파는 1cm 길이로 자른다. 청고추, 홍고추, 무는 한입 크기로 잘라주고 마늘은 편으로 썰어준다., 2. 물 1컵에 찹쌀가루를 풀어서 풀을 쑨다., 3. 물 2컵에 함초, 편마늘을 넣고 국물을 만든다., 4. 이 물로 무를 절여준다. 이때 무를 절였던 물을 버리지 말고 찹쌀 풀과 섞어 국물을 만들어 준다., 5. 만들어진 국물과 찹쌀 풀을 섞어 체에 내려 준다., 6. 모든 재료를 한데 섞어서 저염 동치미를 완성한다.
