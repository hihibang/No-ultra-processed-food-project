# 요리명: 태국식 불고기 샐러드

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 89.0 kcal
- 나트륨 함량: 242.0 mg

## 필요한 재료
쇠고기 30g, 애호박 20g, 토마토 25g, 가지 15g, 양파 8g, 새송이버섯 15g, 그린 샐러드적당량[불고기 드래싱] 풋고추 3g, 홍고추 3g, 마늘 1g, 고춧가루 1g, 레몬주스 3g, 타바스코 1g[카레오일]올리브오일 1g, 로즈마리 1g, 민트 1g, 카레가루 2g

## 조리 순서
1. 소고기는 불고기용으로 손질하여 소금, 후추로 밑간한다., 2. 애호박, 토마토, 가지, 양파, 새송이버섯을 채 썬 뒤 볶는다., 3. 밑간해 둔 소고기를 굽는다., 4. 접시에 밥을 깔고 그 위에 그린샐러드를 올린 뒤 익혀놓은 고기와 볶아놓은 야채들을 올린다., 5. 마지막으로 드래싱을 뿌린다.
