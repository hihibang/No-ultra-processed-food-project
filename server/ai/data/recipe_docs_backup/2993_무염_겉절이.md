# 요리명: 무염 겉절이

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 11.96 kcal
- 나트륨 함량: 1.67 mg

## 필요한 재료
알배추 50g, 적양파 15g, 대파 5g, 풋고추 3g, 마늘 5g, 무청 3g, 고춧가루 5g, 매실액 2g, 식초 5g, 사과 10g

## 조리 순서
1. 알배추는 세척 후 먹기 좋은 크기로 잘라 물에 담군다., 2. 대파와 풋고추는 어슷썰고 양파는 굵게 채 썬다., 3. 마늘은 곱게 다지고 사과는 믹서에 간다., 4. 사과즙, 다진마늘, 고춧가루, 매실액, 식초를 섞어 겉절이 양념을 만든다., 5. 물에 담궈뒀던 알배추를 건져 물기를 뺀 뒤 넓은 볼에 담는다., 6. 알배추와 양파, 대파, 풋고추, 무청을 겉절이 양념에 골고루 버무린다.
