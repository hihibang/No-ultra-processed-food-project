# 요리명: 고등어 강정

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 튀기기
- 열량(칼로리): 154.6 kcal
- 나트륨 함량: 207.0 mg

## 필요한 재료
고등어 35g, 전분 5g, 땅콩 1g, 튀김기름 5g [고등어 밑 양념]생강즙 1g, 청주 2g, 소금적당량, 후춧가루 적당량[조림장]간장 1g, 고추장 3g, 토마토케첩 3g, 설탕 1g, 물엿 3g, 물 5g

## 조리 순서
1. 고등어는 머리를 자른 뒤 내장을 빼고 잘 씻어 물기를 제거한다., 2. 1의 살만 포를 떠서 한입 크기로 자른 뒤 청주, 생강즙, 소금, 후춧가루를 뿌려 밑간 한다., 3. 전분을 앞, 뒤로 묻혀 170℃ 튀김 기름에 2번 바삭하게 튀긴다., 4. 땅콩은 껍질을 벗긴 뒤 비닐봉지에 담아 밀대로 찧어 굵게 다진다., 5. 냄비에 간장, 고추장, 설탕, 물엿을 넣고 끓여 조림장을 만든다., 6. 조림장이 반으로 졸아들면 튀긴 고등어와 땅콩을 넣고 살살 뒤집어가며 윤기나게 버무린다.
