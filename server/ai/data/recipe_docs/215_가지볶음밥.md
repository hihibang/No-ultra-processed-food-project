# 요리명: 가지볶음밥

## 기본 정보
- 요리 분류: 밥
- 조리 방식: 볶기
- 열량(칼로리): 644.9 kcal
- 나트륨 함량: 505.1 mg

## 필요한 재료
재료 단호박(100g), 양파(30g), 석박지(35g), 파프리카(40g), 가지(90g)
두부(50g), 밥(180g), 세발나물(10g)
양념 다진 마늘(5g), 저염된장(12g), 후춧가루(0.3g), 들기름(4g)

## 조리 순서
1. 단호박은 삶아 으깬다., 2. 양파, 석박지, 파프리카, 가지는 깍둑 썰고, 두부는 으깬다., 3. 팬에 다진 마늘, 양파, 석박지를 넣어 볶다가 두부를 넣고 수분이 없어질 때까지 볶다가 가지, 파프리카도 넣어 볶는다, 4. 밥과 저염된장, 후춧가루를 넣고 볶다가 들기름을 넣어 한 번 더 볶는다., 5. 그릇에 담고 으깬 단호박과 세발나물을 곁들여 마무리한다.
