# 요리명: 고추 장떡

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 굽기
- 열량(칼로리): 250.4 kcal
- 나트륨 함량: 111.0 mg

## 필요한 재료
청고추 10g, 깻잎 10g, 애호박 20g, 홍고추 5g, 밀가루 50g, 고추자 3g, 식용유 5g

## 조리 순서
1. 애호박은 다진다., 2. 깻잎은 송송 썰어 굵게 다진다., 3. 풋고추와 홍고추는 반을 갈라 얇게 썬다., 4. 밀가루에 물을 넣어 되게 반죽한 후 고추장을 풀어준다., 5. 반죽에 채소를 넣어 섞은 후 기름 두른 팬에 장떡을 두껍지 않게 부친다., 6. 썰어놓은 청고추와 홍고추로 장떡을 장식한다.
