# 요리명: 양배추말이 김치

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 33.2 kcal
- 나트륨 함량: 200.2 mg

## 필요한 재료
양배추(2장), 시금치(20g), 오이(60g), 당근(20g), 고춧가루(1t), 간장(1t), 사과식초(1t), 사과즙(1t)

## 조리 순서
1. 끓는 물(800㎖)에 양배추와 시금치를 넣어 데친 뒤 찬물에 헹궈 체에 밭쳐 물기를 제거한다., 2. 데친 시금치와 오이, 당근은 얇게 채 썬다., 3. 데친 양배추를 깔고 위에 채 썬 재료를 올려 돌돌 말아준다., 4. 양념장을 만든다., 5. 양배추말이를 한입 크기로 썰어 그릇에 담은 뒤 양념장을 곁들인다.
