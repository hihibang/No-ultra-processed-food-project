# 요리명: 연어비트 절임샐러드

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 327.9 kcal
- 나트륨 함량: 152.6 mg

## 필요한 재료
연어(150g), 비트(100g), 오렌지(1개), 양파(50g), 새싹(20g),
식용꽃(20g), 올리브오일(10g), 설탕(10g), 식초(10g),
소금(0.3g)

## 조리 순서
1. 비트는 껍질을 벗겨 채 썬다., 2. 양파를 얇게 채 썬 후 물에 담근 뒤 건져 물기를 뺀다., 3. 비트와 오렌지에 절여진 연어를 얇게 슬라이스한다., 4. 식용꽃과 새싹은 물에 담궈 싱싱함을 살리고 건져 물기를 뺀다., 5. 새싹과 양파를 접시에 깔고 그 위에 연어를 올린다., 6. 올리브오일, 식초, 소금 및 설탕을 잘 섞어서 만든 드레싱을 올리고 식용꽃으로 장식한다
