# 요리명: 고기완두조림

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 끓이기
- 열량(칼로리): 183.0 kcal
- 나트륨 함량: 45.0 mg

## 필요한 재료
돼지고기살코기 40g, 완두콩 30g, 물 5g, 육수 10g, 설탕 7g, 소금적당량, 전분 5g, 식용유 3g

## 조리 순서
1. 돼지고기는 손질한 뒤 완두콩 크기로 썬다., 2. 완두콩을 믹서에 곱게 간다., 3. 기름을 두른 팬에 1을 넣고 달라붙지 않게 볶는다., 4. 2에 3과 설탕을 넣고 끓인다., 5. 4에 소금으로 간을 한다., 6. 물전분으로 소스의 농도를 맞춘다.
