## 🧩 컴포넌트 분할 전략

### 1️⃣ Layout Components
| 컴포넌트 | 담당 역할 | 상태 | Props |
|---------|---------|------|-------|
| **Header** | 헤더 전체 관리 | viewMode(home/catalog), isLoggedIn | onViewChange, onSearch |
| **TopBanner** | 상단 공지사항 배너 | isVisible | onClose, onCouponClick |
| **Footer** | 페이지 하단 | - | - |
| **MainContainer** | 메인 콘텐츠 래퍼 | viewMode | children |

### 2️⃣ Common Components
| 컴포넌트 | 설명 | Props |
|---------|------|-------|
| **Toast** | 알림 토스트 | message, type(success/error), duration |
| **SearchBox** | 검색 바 | onSearch, hints[], placeholder |
| **CategoryCard** | 카테고리 카드 | icon, title, onClick |
| **ProductCard** | 상품 카드 | product, onAddCart, onToggleWishlist |
| **Button** | 기본 버튼 | variant, size, children, onClick |
| **Badge** | 뱃지 컴포넌트 | label, type(welcome/ai/user) |

### 3️⃣ Feature Components
| 컴포넌트 | 담당 역할 | Props |
|---------|---------|-------|
| **HeroSection** | 메인 배너 영역 | onPopupOpen, onCatalogClick |
| **CategoriesSection** | 10개 카테고리 그리드 | categories[], onCategoryClick |
| **TimeDealSection** | 타임딜 섹션 | deals[], onViewAll |
| **BottomFeaturesSection** | 하단 특징 섹션 | features[] |

## 🔄 상태관리 구조

### Contexts
1. **ToastContext**: 전역 알림 관리
   - showToast(message, type, duration)
   - hideToast()

2. **AuthContext**: 인증 상태
   - isLoggedIn, userName
   - login(), logout(), signup()

3. **CartContext**: 장바구니 관리
   - cart[], cartCount
   - addToCart(), removeFromCart()

4. **ViewModeContext**: 홈/카탈로그 뷰
   - viewMode (home | catalog)
   - switchView(mode)

## 🔑 핵심 구현 포인트

### 1. 스타일 관리
- 모든 CSS는 Styled-Components로 관리
- theme.js에서 색상, spacing, breakpoints 중앙화
- 재사용 가능한 mixins 작성 (예: flexCenter, truncateText)

### 2. 컴포넌트 재사용성
- 공통 컴포넌트는 props으로 최대한 제어
- 조건부 렌더링은 컴포넌트 자체에서 처리
- 비즈니스 로직은 hooks와 contexts 분리

### 3. 상태 관리
- 전역 필요 상태만 Context 사용
- 로컬 상태는 useState 사용
- Context는 변경 함수 제공 (dispatch pattern)

### 4. 네비게이션
- React Router로 Home/Catalog 페이지 분리
- 헤더의 뷰 스위칭 버튼은 라우팅과 동기화

### 5. 모달/팝업
- Hero 팝업은 별도 Modal 컴포넌트
- Coupon 팝업은 Context로 관리
