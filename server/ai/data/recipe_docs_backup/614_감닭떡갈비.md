# 요리명: 감닭떡갈비

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 굽기
- 열량(칼로리): 348.3 kcal
- 나트륨 함량: 128.8 mg

## 필요한 재료
재료 : 닭고기(120g), 감자(200g), 양파(50g), 달걀(1개),
마늘(10g), 찹쌀가루(50g), 매실청(5g), 소금(0.3g),
후춧가루(0.5g), 식용유(20g)

## 조리 순서
1. 닭 살을 곱게 다진다., 2. 다진 닭살에 소금, 후춧가루, 매실청 및 다진 마늘을 넣고 골고루 양념한다., 3. 믹서에 양파, 마늘, 감자, 찹쌀가루를 넣고 간다., 4. 갈아 놓은 감자에 양념된 닭살과 달걀을 섞는다., 5. 4번을 잘 치대 떡갈비 모양으로 만든다., 6. 팬에 기름을 살짝 두르고 떡갈비를 앞뒤로 구워 익힌다.
