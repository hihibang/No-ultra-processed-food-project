# 요리명: 포니언 스프

## 기본 정보
- 요리 분류: 일품
- 조리 방식: 끓이기
- 열량(칼로리): 187.8 kcal
- 나트륨 함량: 109.1 mg

## 필요한 재료
•필수재료 : 감자(100g), 양파(40g), 우유(30g), 시판 크루통(7g), 파슬리가루(1g)
•양념 : 버터(5g), 소금(0.3g), 후춧가루(0.3g)

## 조리 순서
1. 감자는 슬라이스하고, 양파는 채 썬다., 2. 끓는 물(5컵)에 감자를 넣어 7분간 삶아 건진다., 3. 중간 불로 달군 팬에 버터를 두른 뒤 양파를 넣어 3~5분간 볶아 꺼낸다., 4. 믹서에 삶은 감자와 양파, 우유를 넣어 곱게 간다., 5. 냄비에 믹서에 간 재료들을 넣어 약한 불로 3분간 끓여 농도를 맞춘다., 6. 소금과 후춧가루로 간을 맞춘 뒤 시판 크루통과 파슬리가루를 올린다.
