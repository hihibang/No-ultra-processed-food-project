4개 수정사항 중 '1. 상품 목록: 유사 상품 비교' 기능을 고도화해줘.
현재는 기준 상품과 점수가 비슷한 제품만 가져와서 더 건강한 대안(업그레이드)이 잘 안 보이고, 찜 목록도 단순 나열 수준이라 탐색 재미가 떨어지는 문제가 있어.

백엔드 비교 추천 API 및 서비스 로직과 프론트엔드 상품 비교 모달/페이지 컴포넌트를 아래 요구사항에 맞춰 수정해줘.

### 1. 백엔드 수정 요구사항
1. **상위 호환(건강 점수 업그레이드) 상품 위주 추천**
   - 기준 상품과 동일한 카테고리/식품유형(또는 핵심 품목명 유사군) 내에서, **기준 상품보다 건강 점수(NOVA/영양점수)가 더 높거나 당류/나트륨/첨가물 지표가 더 우수한 '상위 호환 제품'**을 우선 추천해줘.
   - 기준 상품이 이미 최상위 점수권이라 상위 호환 후보가 부족한 경우에만, 가장 유사한 건강 점수의 대안 상품을 보조로 채워줘.
   - 각 비교 후보마다 기준 상품 대비 개선 포인트를 담은 요약 태그(`upgrade_reasons`: 예 `["건강점수 +12점", "당류 감소", "NOVA 등급 개선"]`)를 내려줘.

2. **유사 취향 유저들의 찜 리스트(유저별 찜/장바구니 구경하기)**
   - 비교 대상 상품군(기준 상품 + 비교 대안 상품들) 중 **1개 이상을 찜한 다른 유저들**을 조회해줘.
   - 유저 단위 카드 데이터(`user_label` 등 마스킹된 표시명, `matched_product_name` 어떤 비교 상품을 찜했는지, `wished_items` 해당 유저가 찜한 다른 상품 리스트 최대 3~4개)를 함께 반환해줘.
   - 찜 데이터가 없는 경우에는 빈 배열(`[]`)을 반환하고 에러 없이 처리해줘.

### 2. 프론트엔드 수정 요구사항
1. **상위 호환 대안 강조**
   - 비교 영역에서 기준 상품 대비 더 건강한 대안 상품에 `✨ 상위 호환` 또는 `더 건강한 대안` 배지와 `upgrade_reasons` 태그를 표시해줘.
2. **유사 취향 유저 찜 리스트 구경하기 섹션**
   - 비교 영역 하단에 해당 비교 상품군을 1개 이상 찜한 유저들의 찜 리스트 카드를 렌더링해줘.
   - 유저가 찜한 다른 상품을 클릭하면 해당 상품 상세로 이동하거나 바로 찜할 수 있게 연결하고, 데이터가 없을 때는 섹션 전체를 숨김 처리해줘.

### [추가] 찜 데이터 부족/미존재 시 Fallback 처리
- 비교 상품군에 대한 실제 유저 찜 데이터가 부족하거나(예: 2명 미만) 없는 경우에는 에러를 내지 말고, 같은 카테고리/유형 내 다른 찜 유저로 범위를 넓히거나, 그래도 없으면 유사 유저 찜 목록 영역을 숨김 처리해줘.
- 허위/가짜 유저 찜 데이터는 임의로 생성하지 말아줘.

수정 후 기존 비교 버튼 동작과 상위 호환 추천·유사 유저 찜 리스트 응답/렌더링이 정상 동작하는지 확인해줘.
