# 요리명: 낫토 시래기 라이스전

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 굽기
- 열량(칼로리): 138.0 kcal
- 나트륨 함량: 163.0 mg

## 필요한 재료
밥 40g, 양파다진것 10g, 당근다진것 5g, 낫토 15g, 시래기불린것 10g, 카레가루 3g, 파다진것 2g, 밀가루 5g, 달걀 10g, 식용유 적당량, 소금 적당량, 후춧가루 적당량

## 조리 순서
1. 양파와 당근은 잘게 다진다., 2. 시래기는 불려 물기를 꼭 짜낸다., 3. 2번의 시래기를 곱게 다진다., 4. 뜨거운 밥에 1, 3을 넣는다., 5. 4에 낫토, 카레가루, 다진 파를 넣고 골고루 섞는다., 6. 5에 소금, 후춧가루로 간한다.
