# 요리명: 저염보쌈김치

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 튀기기
- 열량(칼로리): 9.97 kcal
- 나트륨 함량: 112.95 mg

## 필요한 재료
"배추 17g, 배 3.0g, 대추슬라이스 0.2g, 깐밤 1.1g, 당근 1.0g 
(저염양념) 조선무 1.1g, 미나리 1.0g, 깐양파 1.1g,  파프리카 1.1g, 황설탕 0.1g, 잣 0.2g,  깐마늘 1.1g, 깐생강 0.2g, 멸치액젓 0.1g, 고춧가루 0.8g, 굵은소금 0.5g, 건표고버섯 0.1g, 국멸치 0.3g , 물 50ml"

## 조리 순서
1. 배추는 손질하여 심심하게 절인다., 2. 국멸치, 건표고버섯으로 육수를 낸다., 3. 파프리카는 갈아서 즙을 짜서 준비한다., 4. 식힌 육수에 파프리카 즙과 무, 미나리, 양파를 채쳐서 넣고 저염 양념을 만든다., 5. 배, 대추, 밤, 당근은 마지막에 채쳐 섞는다., 6. 저염 양념에 ⑤를 섞어서 절인 배추에 켜켜로 바른다.
