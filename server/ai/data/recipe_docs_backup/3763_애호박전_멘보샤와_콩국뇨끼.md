# 요리명: 애호박전 멘보샤와 콩국뇨끼

## 기본 정보
- 요리 분류: 일품
- 조리 방식: 기타
- 열량(칼로리): 368.3 kcal
- 나트륨 함량: 617.3 mg

## 필요한 재료
주재료 애호박 150g, 새우 100g, 전분 35g, 튀김가루 200g, 오이 20g,
양파 15g, 토마토 50g, 감자 60g, 콩물 100g
양념 식용유 180g, 사과식초 20g, 알룰로스 20g, 소금 1g, 후추 1g

## 조리 순서
1. 애호박은 둥글게 썰고 키친타월에 올려 수분을 제거한다. 새우는 칼로 다진 뒤 전분(15g)을 섞어 애호박에 올린다., 2. 애호박 사이에 다진 새우를 넣고 튀김가루를 묻힌다. 식용유를 넣고 160°C로 예열한 팬에서 튀겨 멘보샤를 만든다., 3. 볼에 잘게 다진 오이(15g), 양파, 토마토를 넣고 사과식초, 알룰로스(10g)로 간하여 샐러드를 만든다., 4. 감자를 잘게 썰어 10분간 찐다. 찐 감자를 볼에 담고 소금(0.5g), 후추로 간하고 전분(20g)을 섞어 뇨끼 반죽을 만든다., 5. 뇨끼 반죽을 한입 크기로 떼어 동그랗게 만들고 포크로 모양을 낸 뒤 끓는 물에 데쳐 뇨끼를 만든다. 볼에 콩물을 담고 알룰로스(10g), 소금(0.5g)으로 간하고 뇨끼를 넣는다., 6. 그릇에 멘보샤, 샐러드, 콩국뇨끼를 담고 채 썬 오이(5g)를 뇨끼에 고명으로 올려 마무리한다.
