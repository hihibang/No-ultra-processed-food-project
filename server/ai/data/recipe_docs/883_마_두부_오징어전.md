# 요리명: 마 두부 오징어전

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 굽기
- 열량(칼로리): 173.3 kcal
- 나트륨 함량: 159.0 mg

## 필요한 재료
두부 60g, 마 60g, 표고버섯마른것 3.5g, 오징어 6g, 소금 0.2g, 후춧가루 0.1g, 녹말 0.8g, 식용유 4.8g, 홍고추 0.5g[소스소개] 양념장:간장 1.5g, 조미술 1.5g, 설탕 0.5g, 식초 0.5g

## 조리 순서
1. 두부는 소창에 싸서 으깬다., 2. 마는 껍질을 벗기고 강판에 간다., 3. 홍고추는 다지고 표고버섯은 물에 불린 후 잘게 다진다. 오징어도 손질하여 잘게 다진다., 4. 두부와 마, 다진 재료들을 모두 섞어 소금, 후춧가루로 간한다., 5. 반죽을 한 스푼씩 떠 식용유를 넣은 팬에 노릇하게 구워낸다., 6. 재료를 섞어 양념장을 만들어 함께 낸다
