# 요리명: 단구마 무스 샌드 케이크

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 굽기
- 열량(칼로리): 512.3 kcal
- 나트륨 함량: 40.6 mg

## 필요한 재료
고구마(30g), 단호박(30g), 생크림(60g),
달걀(2개), 박력분(30g), 우유(15g),
설탕(10g), 버터(3g), 레몬즙(1g),
크랜베리(15g)

## 조리 순서
1. 달걀 노른자를 휘핑하고 박력분을 넣은 뒤 우유와 녹인 버터를 넣고 섞는다., 2. 달걀 흰자는 레몬즙과 설탕을 3번에 나누어 넣으면서 머랭을 만든다., 3. 머랭과 크랜베리를 노른자 반죽에 넣고 부드럽게 섞는다., 4. 180℃ 오븐에서 15분 정도 구워 시트를 만든 뒤 컵모양으로 자른다., 5. 고구마와 단호박은 삶은 뒤 껍질을 벗기고 각각 체에 내려 생크림을 섞는다., 6. 시트, 단호박무스, 고구마무스 순서로 여러겹 쌓아 올린다.
