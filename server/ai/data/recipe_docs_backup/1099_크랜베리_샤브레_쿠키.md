# 요리명: 크랜베리 샤브레 쿠키

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 굽기
- 열량(칼로리): 367.2 kcal
- 나트륨 함량: 18.7 mg

## 필요한 재료
크랜베리(8g), 슈가파우더(10g),
박력분(30g), 아몬드가루(10g),
백년초가루(2g), 우유(3g), 버터(25g)

## 조리 순서
1. 실온에 둔 버터를 휘핑기로 풀어준 뒤 슈가파우더를 넣고 섞는다., 2. 박력분, 아몬드가루,  백년초가루를 넣고 섞는다., 3. 크랜베리를 넣고 섞는다., 4. 우유를 넣고 섞는다., 5. 동그란 원기둥 모양으로 만들어 냉동실에서 1시간 정도 굳힌다., 6. 굳은 반죽을 1cm 두께로 잘라 180℃ 오븐에서 15분 간 굽는다.
