# 요리명: 과일무스 테린

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 끓이기
- 열량(칼로리): 67.5 kcal
- 나트륨 함량: 12.4 mg

## 필요한 재료
●주재료 : 딸기 100g(5개), 키위 100g(1개), 매실원액 15g(1큰술), 젤라틴 20g
●소스 : 망고 20g(1/5개), 우유 45g(3큰술)

## 조리 순서
1. 망고와 우유를 섞어 믹서에 갈아 팬에 넣고 끓인다., 2. 딸기와 키위는 0.5×0.5×0.5cm로 썰고 젤라틴은 녹여서 매실원액과 섞는다., 3. 딸기, 키위를 젤라틴과 섞어서 틀에 넣어 굳히고 위에 망고소스를 뿌려 완성한다.
