# 요리명: 완두콩 롤

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 기타
- 열량(칼로리): 310.8 kcal
- 나트륨 함량: 4.3 mg

## 필요한 재료
완두콩(50g), 식빵(50g), 찹쌀가루(20g),
우유(25g), 올리고당(2g)

## 조리 순서
1. 완두콩은 삶은 뒤 믹서에 간다., 2. 간 완두콩에 올리고당, 우유를 넣고 졸인다., 3. 찹쌀가루는 익반죽하여전자레인지에 3분 가열 후 숟가락으로 젓고 2분 간 더 돌려떡을 만든다., 4. 식빵은 밀대로 밀어 납작하게 한 뒤 가장자리를 자른다., 5. 식빵위에 찹쌀떡을 넓게 펴 바르고 그 위에 졸인 완두콩을 올린다., 6. 5번을 돌돌 말아 고정시킨 뒤 먹기 좋은 크기로 자른다.
