# 요리명: 참외지 리코타버무리

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 기타
- 열량(칼로리): 203.9 kcal
- 나트륨 함량: 100.3 mg

## 필요한 재료
참외(110g), 아몬드(5g), 소금(1g), 설탕(2g), 레몬즙(15g), 올리브유(2g), 유자청(5g), 리코타치즈(15g)

## 조리 순서
1. 참외는 껍질을 벗기고 반 갈라 속을 파내고, 파낸 속은 면포에 감싸 즙을 짠다., 2. 과육은 필러로 얇게 저민 뒤 손으로 즙을 꼭 짠다., 3. 참외즙에 끓는 물(50㎖)과 양념을 넣어 고루 섞는다., 4. 양념을 섞은 참외즙에 얇게 저민 참외 과육을 넣어 냉장실에서 20분간 절인다., 5. 소스를 만든다., 6. 절인 참외 과육을 찬물에 헹궈 물기를 꼭 짠 뒤 그릇에 담고 소스와 아몬드를 곁들인다.
