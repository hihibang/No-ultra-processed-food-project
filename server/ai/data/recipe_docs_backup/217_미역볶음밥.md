# 요리명: 미역볶음밥

## 기본 정보
- 요리 분류: 밥
- 조리 방식: 볶기
- 열량(칼로리): 515.2 kcal
- 나트륨 함량: 488.5 mg

## 필요한 재료
재료 쌀(80g), 완두콩(10g), 닭고기(100g), 대추(10g), 수삼(20g)
양파(20g), 당근(10g)
양념 강황가루(3g), 맛술(15g)

## 조리 순서
1. 쌀과 다시마를 넣고 쌀과 동량의 물을 부어 밥을 고슬고슬하게 짓는다., 2. 양파는 굵게 다지고, 쪽파와 고추는 송송 썰고, 오징어와 주꾸미는 먹기 좋은 크기로 썬다., 3. 달군 팬에 들기름을 두르고 다진 마늘을 볶아 향을 낸다., 4. 미역을 넣고 볶다가 손질해둔 오징어, 주꾸미, 새우살, 양파를 넣어 볶는다., 5. 밥을 넣고 소금을 넣어 볶다가 들깻가루를 넣어 볶는다., 6. 송송 썬 쪽파와 청양고추, 붉은 고추를 넣어 조금 더 볶아 마무리한다.
