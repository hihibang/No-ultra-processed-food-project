# 요리명: 비타 오이 물김치

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 13.46 kcal
- 나트륨 함량: 30.88 mg

## 필요한 재료
오이 30g, 무 50g, 홍고추 10g, 파프리카 20g, 당근 20g, 미나리 10g, 식초 30g, 배 30g, 고춧가루 10g, 설탕 5g

## 조리 순서
1. 오이와 무를 필러로 길게 슬라이스 한다., 2. 설탕물을 만들어 무가 잘 구부러질 때 까지 재운 뒤 씻어낸다., 3. 당근과 홍고추, 파프리카는 5cm 길이로 채 썬다., 4. 미나리를 데쳐 식힌 뒤 한 줄씩 찢는다., 5. 오이, 무를 겹쳐 채 썬 재료를 넣고 말아준 뒤 데친 미나리로 묶는다., 6. 배를 갈아 물, 식초, 고춧가루와 섞어 양념장을 만든 뒤 5를 넣고 재운다.
