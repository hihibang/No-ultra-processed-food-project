# 요리명: 퀴노아 팥수프

## 기본 정보
- 요리 분류: 기타
- 조리 방식: 끓이기
- 열량(칼로리): 432.26 kcal
- 나트륨 함량: 319.2 mg

## 필요한 재료
퀴노아 3g, 팥 10g, 무가당 휘핑크림 25g, 무염 버터 10g, 우유 15g, 닭뼈 20g, 밀가루 10g, 양파 10g, 세발나물 10g, 설탕 3g

## 조리 순서
1. 세발나물을 살짝 데쳐 말린 뒤 가루를 내고 닭뼈를 이용해 육수를 만든다., 2. 퀴노아를 볶아 쓴맛을 제거하고 삶은 팥과 믹서에 곱게 간다., 3. 팬에 버터 일부를 녹인 뒤 밀가루를 넣어 루를 만든다., 4. 양파를 갈아 버터 녹인 냄비에 볶은 뒤 닭육수와 2를 넣어 끓인다., 5. 세발나물가루로 간을 맞추고 향을 낸 뒤 루를 넣어 농도를 맞춘다., 6. 우유와 휘핑을 넣어 고소함을 더하고 설탕을 소량 넣어 간을 한다.
