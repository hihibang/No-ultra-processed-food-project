# 요리명: 무말랭이김치

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 10.86 kcal
- 나트륨 함량: 1.85 mg

## 필요한 재료
무말랭이 10g, 식초 30g, 설탕 25g, 레몬 8g, 당근 5g, 오이 5g, 피클링스파이스 5g, 물 100g

## 조리 순서
1. 무말랭이를 물에 불린다., 2. 식초, 설탕, 피클링스파이스, 물을 넣고 끓인다., 3. 끓인 물을 식힌다., 4. 레몬, 당근, 오이를 적당한 크기로 자른다., 5. 4를 3에 넣어 하루 이상 숙성시킨다., 6. 보기 좋게 담는다.
