# 요리명: 불고기 소스를 곁들인 두부구이

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 굽기
- 열량(칼로리): 200.0 kcal
- 나트륨 함량: 481.0 mg

## 필요한 재료
●두부구이 : 두부 70g(1/5모), 전분 10g(2작은술), 흑임자 2g(1/3작은술), 식용유 5g(1작은술), 후추약간
●불고기 양념 : 간장 3g(2/3작은술), 올리고당 3g(2/3작은술), 생강즙 3g(2/3작은술), 물 30ml(2큰술)

## 조리 순서
1. 두부를 2.5×2.5×1cm 정도로 잘라 물기를 빼고 후추를 뿌린 후 전분가루를 골고루 묻혀 식용유를 둘러 프라이팬에 갈색이 나도록 양면을 굽는다., 2. 프라이팬에 간장, 올리고당, 생강즙, 물을 넣어 끓여 불고기 양념을 만든 후 양념을 구운 두부에 넣고 졸인다., 3. 그릇에 두부를 담고 위에 흑임자를 뿌린다.
