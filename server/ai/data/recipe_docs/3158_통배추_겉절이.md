# 요리명: 통배추 겉절이

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 22.0 kcal
- 나트륨 함량: 110.2 mg

## 필요한 재료
•필수 재료 : 통배추(25g), 쪽파(1g), 마늘(1g), 생강(0.5g)
•양념 : 소금(0.1g), 홍시(1g), 고춧가루(1g), 젓갈(1g), 통깨(1g), 참기름(0.5g)

## 조리 순서
1. 배추는 연한 잎으로 골라 한 장씩 떼어 길게 갈라놓는다., 2. 배추에 소금을 뿌려 절인다., 3. 쪽파는 4cm 길이로 썰고, 마늘과 생강은 다진다., 4. 고춧가루에 홍시를 으깨서 나머지 양념을 섞는다., 5. 물기를 제거한 배추에 고춧가루 양념을 넣고 무친다., 6. 쪽파, 통깨, 참기름을 넣고 마무리한다.
