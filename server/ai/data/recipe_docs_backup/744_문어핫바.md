# 요리명: 문어핫바

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 굽기
- 열량(칼로리): 191.5 kcal
- 나트륨 함량: 324.6 mg

## 필요한 재료
문어 50g, 톳 5g, 감자 20g, 당근 5g, 양파 5g, 우리밀가루 20g, 다진 마늘 2g, 후춧가루 0.1g, 토마토케첩 5g, 허니머스터드소스 5g, 현미유 5g

## 조리 순서
1. 손질한 문어를 데친다., 2. 양파와 감자를 적당한 크기로 자르고 톳과 당근은 잘게 다진다., 3. 데친 문어와 양파, 감자를 믹서기에 넣고 간다., 4. 2와 3에 우리밀가루, 다진 마늘, 후춧가루를 넣고 반죽을 치대 직사각형 모양을 만든다., 5. 팬에 현미유를 두르고 4의 문어를 넣고 지진 후 꼬치에 끼운다., 6. 토마토케첩과 허니머스터드소스를 곁들인다.
