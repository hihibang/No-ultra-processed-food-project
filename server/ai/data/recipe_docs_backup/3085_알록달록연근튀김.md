# 요리명: 알록달록연근튀김

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 튀기기
- 열량(칼로리): 66.9 kcal
- 나트륨 함량: 103.4 mg

## 필요한 재료
깐연근 22.18g, 비트 2.12g, 시금치 2.12g, 카레가루 1.52g, 건새우 0.3g, 전분 2.25g, 튀김가루 4.25g, 소금 0.05g, 식물성기름 500ml

## 조리 순서
1. 연근은 얇게 썰어 찬물에 담가 전분기를 제거한다., 2. 건새우는 곱게 갈아준다., 3. 시금치, 비트는 각각 믹서기에 갈아 즙을 준비한다., 4. 튀김가루에 새우가루와 물을 넣어 반죽을 한다., 5. 반죽에 시금치, 카레, 비트를 각각 넣어 3가지 색의 반죽을 만든다., 6. 연근에 전분가루를 묻히고 튀김옷을 입혀 바삭하게 튀겨낸다.
