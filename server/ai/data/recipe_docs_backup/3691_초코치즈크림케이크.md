# 요리명: 초코치즈크림케이크

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 기타
- 열량(칼로리): 219.8 kcal
- 나트륨 함량: 89.6 mg

## 필요한 재료
크림치즈 > 우유 875ml, 식초 20ml, 알룰로스① 56g, 소금 1g, 초코크림 > 아몬드가루 85g, 무가당 코코아가루① 20g, 알룰로스② 70g, 두유① 25ml
반 죽 > 바나나 175g, 달걀 105g, 두유② 25ml, 무가당 코코아가루② 45g, 땅콩버터 18g

## 조리 순서
1. 냄비에 우유를 넣고 중불로 끓이다 약한 불에서 식초를 넣어 젓는다. 면보로 유청을 거른 덩어리를 믹서에 넣고 알룰로스①, 소금을 넣고 곱게 갈아 크림치즈를 만든다., 2. 볼에 아몬드가루, 무가당 코코아가루①을 체 쳐서 넣고 알룰로스②, 두유①을 섞어 초코크림을 만든다., 3. 믹서에 바나나, 달걀, 두유②, 무가당 코코아가루②, 땅콩버터를 넣고 갈아 반죽을 만들어 종이컵 높이의 50% 정도 채운다., 4. 전자레인지에서 4~5분 동안 구워 시트를 만든다. 구운 시트는 가로로 3등분한다., 5. 크림치즈와 초코크림을 섞어 시트 위에 올린다., 6. 시트를 겹쳐 케이크를 만들고 무가당 코코아가루를 뿌려 마무리한다
