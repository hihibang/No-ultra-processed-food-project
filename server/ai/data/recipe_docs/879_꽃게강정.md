# 요리명: 꽃게강정

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 튀기기
- 열량(칼로리): 261.0 kcal
- 나트륨 함량: 470.0 mg

## 필요한 재료
꽃게 120g, 후춧가루 0.3g, 청고추 1g, 홍고추 1g, 토마토케첩 4g, 마늘 1.3g, 생강 0.5g, 생강즙 4g, 찹쌀가루 8g, 식용유 10g [소스소개] 매운고추소스:매운 고춧가루 1.3g, 맛술 8g, 간장 2g, 물엿 10g

## 조리 순서
1. 꽃게를 잘 손질한다., 2. 손질한 꽃게에 생강즙과 후춧가루로 간을 한다., 3. 청·홍고추는 사방 0.7cm로 썰고 생강은 다진다., 4. 매운 고추소스의 재료들을 모두 섞고 냄비에 넣어 끓이다가 준비해둔 채소들을 넣고 한소큼 끓여준다., 5. 꽃게에 찹쌀가루를 묻혀 튀긴다., 6. 4의 소스에 넣고 섞는다.
