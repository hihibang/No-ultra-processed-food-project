# 요리명: 두부티라미수

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 굽기
- 열량(칼로리): 693.0 kcal
- 나트륨 함량: 34.4 mg

## 필요한 재료
두부(80g), 고구마(120g),
마스카포네치즈(12g), 크랜베리(2g),
두유(5g), 호두(15g), 아몬드(8g),
박력분(2g), 아몬드가루(3g), 버터(2g)

## 조리 순서
1. 고구마는 껍질을 벗기고 삶아 으깬 뒤 체에 내린다., 2. 두부, 크랜베리, 마스카포네치즈, 두유를 믹서에 넣고 갈아 두부크림을 만든다., 3. 두부크림에 다진 호두, 아몬드를 섞는다., 4. 실온의 말랑한 버터에 박력분과 아몬드가루를 넣고 보슬보슬하게 섞어 소보루 반죽을 만든다., 5. 4번을 170℃ 오븐에서 15분 간 굽는다., 6. 투명한 컵에 으깬 고구마와 두부크림을 켜켜이 쌓고 마지막에 소보루를 올린다.
