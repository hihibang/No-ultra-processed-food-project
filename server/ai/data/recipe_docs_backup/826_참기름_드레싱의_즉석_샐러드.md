# 요리명: 참기름 드레싱의 즉석 샐러드

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 77.7 kcal
- 나트륨 함량: 110.0 mg

## 필요한 재료
상추 10g, 오이 10g, 당근 5g, 비타민 5g, 방울토마토 10g, 쑥갓 2g, 견과류 : 아몬드,호두 2g [소스소개] 참기름드래싱:간장2g, 마늘 2g, 레몬즙 2g, 식초 15g, 참기름 4g, 고운고춧가루 1g, 통깨 0.5g, 설탕 2.5g

## 조리 순서
1. 샐러드 재료들을 잘 씻는다., 2. 체에 받쳐 물기를 제거한다., 3. 채소들을 한입 크기로 썰어둔다., 4. 드레싱 재료를 섞어 참기름 드레싱을 만든다., 5. 유리병에 모든 재료를 넣고, 참기름 드레싱을 넣고 섞은 후 접시에 담아 낸다., 6. 샐러드 위에 견과류를 뿌려 마무리 한다.
