# 요리명: 멜론스프

## 기본 정보
- 요리 분류: 일품
- 조리 방식: 기타
- 열량(칼로리): 86.0 kcal
- 나트륨 함량: 22.0 mg

## 필요한 재료
멜론 110g, 오렌지 30g, 레몬 5g, 탄산수 30g, 레몬껍질 2g, 전분 3g, 설탕 5g[장식재료선택] 멜론,자두,생크림,민트

## 조리 순서
1. 메론은 적당한 크기로 잘라 믹서에 간다., 2. 오렌지와 레몬은 과육만 잘라내 믹서에 각각 갈아 주스형태로 만든다., 3. 2에 탄산수, 오렌지껍질, 레몬껍질을 넣어 향이 우러나도록 끓인다., 4. 3에 전분을 넣어 농도를 맞춘 뒤 덩어리지지 않게 체에 걸러 차갑게 식힌다., 5. 1에 4를 넣고 잘 섞은 뒤 설탕으로 맛을 낸다., 6. 생크림을 휘핑해 올리고 자두, 메론, 민트로 장식한다.
