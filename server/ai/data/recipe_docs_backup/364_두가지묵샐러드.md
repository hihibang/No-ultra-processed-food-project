# 요리명: 두가지묵샐러드

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 53.6 kcal
- 나트륨 함량: 109.2 mg

## 필요한 재료
두가지 묵(올방개묵, 검정깨묵) 각 25g씩, 당귀잎 10g
양파 40g, 노란 파프리카 25g, 알배추 20g
소스 : 저염간장 15g, 유자청 30g, 다진청고추 7g, 다진홍고추 7g, 다진대파 7g

## 조리 순서
1. 당귀는 잎만 떼어 먹기 좋게 잘라서 물에 담가준다., 2. 두가지묵은 먹기 좋게 길이로 잘라준다., 3. 양파, 파프리카, 알배추는 가늘게 채 썰어준다., 4. 소스를 만들어준다., 5. 모든 재료를 담고 소스에 통깨를 섞은 뒤 샐러드에 뿌려 완성한다.
