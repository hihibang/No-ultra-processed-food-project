# 요리명: 연근샐러드, 흑임자소스

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 28.76 kcal
- 나트륨 함량: 4.9 mg

## 필요한 재료
흑임자 30g, 연근 80g, 레몬 20g, 마요네즈 15g, 플레인요거트 15g, 식초 5g

## 조리 순서
1. 연근은 세척 후 껍질을 벗긴다., 2. 연근을 슬라이스 한다., 3. 물에 식초를 넣고 끓으면 연근을 데친다., 4. 레몬즙을 짠다., 5. 흑임자, 마요네즈, 플레인요거트를 믹서 하여 흑임자 소스를 만든다., 6. 연근에 흑임자소스를 곁들여 담는다.
