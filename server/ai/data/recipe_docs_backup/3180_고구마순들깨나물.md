# 요리명: 고구마순들깨나물

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 118.41 kcal
- 나트륨 함량: 341.91 mg

## 필요한 재료
고구마순 60g, 들깨가루 20g, 다시마 2g, 소금 1g, 참기름 2g

## 조리 순서
1. 고구마순을 끓는 물에 삶아 씻어둔다., 2. 물과 다시마를 약불에 10분정도 우려 다시물을 낸다., 3. 고구마순을 팬으로 옮기고 다시물을 넣어 삶는다., 4. 다시물이 반쯤 줄어들면 소금과 들깻가루를 넣는다., 5. 물기가 없게 볶아준 후 참기름을 넣는다., 6. 접시에 담아서 완성한다.
