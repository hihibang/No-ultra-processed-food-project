# 요리명: 시금치 배 미음

## 기본 정보
- 요리 분류: 밥
- 조리 방식: 끓이기
- 열량(칼로리): 137.0 kcal
- 나트륨 함량: 12.0 mg

## 필요한 재료
불린쌀 30g, 물 90g, 배 25g, 시금치 20g, 꿀 5g

## 조리 순서
1. 쌀은 깨끗하게 씻어 불린다., 2. 2를 믹서나 절구로 곱게 갈아 냄비에 물과 함께 넣고 끓인다., 3. 배는 껍질과 씨를 제거하고 강판에 간다., 4. 시금치는 끓는 물에 데친 후 물기를 꼭 짜서 곱게 다진다., 5. 2가 끓어오르면 3,4를 넣고 끓인다., 6. 입맛에 맞게 꿀로 간한다.
