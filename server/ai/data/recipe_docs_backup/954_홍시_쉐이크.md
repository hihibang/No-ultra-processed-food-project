# 요리명: 홍시 쉐이크

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 기타
- 열량(칼로리): 70.0 kcal
- 나트륨 함량: 5.0 mg

## 필요한 재료
냉동홍시 70g, 오미자 5g, 물 35g, 레몬즙 4g, 꿀 5g, 민트 1g

## 조리 순서
1. 냉동 홍시의 껍질을 벗기고 씨를 뺀다., 2. 1을 잘게 자른다., 3. 오미자를 7배의 물에 8시간 이상 우려 맛과 색이 우러나오도록 한다., 4. 믹서에 홍시, 오미자물, 꿀, 레몬즙을 넣어 함께 갈아준다., 5. 4를 컵에 담는다., 6. 민트로 장식한다.
