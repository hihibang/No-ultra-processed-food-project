# 요리명: 스마일오이피클

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 52.15 kcal
- 나트륨 함량: 9.69 mg

## 필요한 재료
오이 80g, 배 50g, 홍피망 5g, 청피망 5g, 노랑파프리카 5g, 식초 3g, 설탕 6g, 물 100ml, 피클링스파이스 1g

## 조리 순서
1. 오이를 3등분하여 속을 파낸다., 2. 피망 및 파프리카는 U모양으로 휘어지게 썰어준다., 3. 배를 채 썰어 준다., 4. 오이 중앙에 파프리카와 배를 채워 넣는다., 5. 물, 식초, 설탕, 피클링 스파이스를 넣어 피클물을 만든다., 6. ④에 피클물을 넣고 30분 정도 숙성시킨다.
