# 요리명: 시래기닭조림

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 210.1 kcal
- 나트륨 함량: 198.3 mg

## 필요한 재료
•필수재료 : 닭고기(120g), 무(30g), 당근(20g), 양파(10g), 홍고추(1g), 청고추(1g), 무청시래기(삶은 것, 80g)
•양념 : 다진마늘(2g), 후추(1g), 저염간장(5g), 설탕(3g), 물엿(5g)

## 조리 순서
1. 닭고기는 부위별로 토막 내어 끓는 물에 살짝 데친다., 2. 데친 닭고기에 양념 재료를 섞어 30분 이상 재운다., 3. 무, 당근, 양파는 사각 썰고, 고추는 송송 썬다., 4. 무청시래기는 끓는 물에 한 번 더 살짝 데치고, 6cm 길이로 썬다., 5. 냄비에 물(30g)과 닭고기, 시래기를 넣고, 청홍고추를 제외한 손질한 채소를 넣어 조린다., 6. 홍고추와 청고추를 올려 마무리한다.
