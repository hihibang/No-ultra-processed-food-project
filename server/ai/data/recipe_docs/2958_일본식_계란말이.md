# 요리명: 일본식 계란말이

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 굽기
- 열량(칼로리): 138.34 kcal
- 나트륨 함량: 141.1 mg

## 필요한 재료
계란 150g, 가츠오부시 10g, 다시마 10g, 설탕 5g, 미림 5g

## 조리 순서
1. 물에 다시마를 넣고 끓인다., 2. 물이 끓어 오르면 다시마를 건진다., 3. 불을 끈 뒤 가츠오부시를 넣고 체에 걸러 육수를 완성한다., 4. 계란을 풀어 채에 내린 뒤 육수와 미림, 설탕을 넣는다., 5. 팬에 기름을 둘러 계란물을 한겹 한겹 만다., 6. 완성된 계란말이는 모양을 잡고 한입크기로 자른다.
