# 요리명: 섭산삼

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 튀기기
- 열량(칼로리): 233.0 kcal
- 나트륨 함량: 4.0 mg

## 필요한 재료
더덕 40g, 젖은 찹쌀가루 30g, 가루녹차 2g, 백년초 가루 2g, 설탕 1g, 꿀 5g, 소금 적당량, 튀김기름 8g

## 조리 순서
1. 더덕은 껍질을 벗기고 0.3cm 두께로 편 썰어 소금물에 담궈 쓴 맛을 뺀 뒤 면보에 옮겨 밀대로 밀거나 두들겨 얇게 편다., 2. 찹쌀가루는 소금을 넣고 혼합하여 체에 내린다., 3. 2를 3등분 하여 가루녹차와 백년초가루를 각각 섞는다., 4. 3에 더덕을 각각 넣고 앞, 뒤로 꼭꼭 눌러 찹쌀가루를 묻힌다., 5. 170℃의 기름에 2번 튀긴 뒤 기름을 빼고 뜨거울 때 설탕을 약간 뿌린다., 6. 꿀을 곁들여 찍어 먹는다.
