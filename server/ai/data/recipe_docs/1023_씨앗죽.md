# 요리명: 씨앗죽

## 기본 정보
- 요리 분류: 밥
- 조리 방식: 끓이기
- 열량(칼로리): 198.0 kcal
- 나트륨 함량: 20.0 mg

## 필요한 재료
쌀 30g, 참깨 3g, 통아몬드 4g, 땅콩 4g, 호박씨 4g, 물 90g, 소금 적당량

## 조리 순서
1. 쌀을 깨끗이 씻어 5시간 정도 불린다., 2. 불린 쌀을 절구에 넣어 쌀알이 반 정도 부서지도록 간다., 3. 참깨, 아몬드, 땅콩, 호박씨를 믹서기에 간다., 4. 냄비에 쌀과 물을 넣고 끓인다., 5. 쌀알이 익으면 3의 씨앗가루를 넣고 끓인다., 6. 소금간을 하고 준비한 그릇에 담아낸다.
