# 요리명: 양송이크림볶음밥

## 기본 정보
- 요리 분류: 밥
- 조리 방식: 볶기
- 열량(칼로리): 346.1 kcal
- 나트륨 함량: 197.1 mg

## 필요한 재료
닭고기살(50g), 양송이(60g), 떡볶이떡(20g), 양파(20g)
당근(30g), 소금(0.2g), 버터(10g), 밥(100g), 육수(50g)
우유(50g), 생크림(10g), 치즈(10g)

## 조리 순서
1. 닭살은 삶아 입자있게 썰고, 양송이도 껍질을 벗겨 입자있게 썰어 준비한다., 2. 떡볶이떡과 양파도 입자있게 썰어 놓는다., 3. 당근은 소금을 넣고 삶아 꼬마 당근을 만들어 장식을 준비한다., 4. 냄비에 버터를 두르고 양파를 먼저 볶는다., 5. 볶아지는 냄비에 닭살과 떡볶이떡, 양파를 넣어 다시 볶는다., 6. ⑤번에 밥을 넣고 육수와 우유, 생크림을 넣어 볶으면서 치즈를 넣고 한 번 더 고실 하게 볶아 완성하고 삶은 당근은 꼬마 당근을 만들어 장식으로 올려 준다.
