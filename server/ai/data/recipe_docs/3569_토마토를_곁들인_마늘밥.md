# 요리명: 토마토를 곁들인 마늘밥

## 기본 정보
- 요리 분류: 밥
- 조리 방식: 찌기
- 열량(칼로리): 427.8 kcal
- 나트륨 함량: 3.6 mg

## 필요한 재료
1인분 기준<br>
[주재료]현미(60g), 백미(30g), 마늘(30g), 토마토(60g)<br>
[양념] 올리브유(24g), 후추(1g), 파슬리가루(1g)

## 조리 순서
1. 현미는 1시간, 백미는 30분 동안 불린다., 2. 마늘의 절반은 편으로 썰고, 나머지는 통으로 준비한다., 3. 냄비에 불린 쌀, 마늘을 넣고 물을 맞춰 센 불에서 끓어오르면 중약 불로 줄이고 15분 동안 끓인다., 4. 약한 불로 줄이고 뜸을 들여 마늘밥을 만든다., 5. 칼집을 낸 토마토를 뜨거운 물에 살짝 데쳐 껍질과 씨를 제거하고, 잘게 다진다., 6. 접시에 마늘밥을 담고 손질한 토마토를 올린 후 올리브유, 후추, 파슬리가루를 뿌려 마무리한다.
