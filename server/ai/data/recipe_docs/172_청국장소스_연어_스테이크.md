# 요리명: 청국장소스 연어 스테이크

## 기본 정보
- 요리 분류: 일품
- 조리 방식: 굽기
- 열량(칼로리): 209.3 kcal
- 나트륨 함량: 56.6 mg

## 필요한 재료
●주재료 : 마늘종 60g(10개), 연어 200g, 식용유 5g(1/2작은술)
●소스 : 검정깨 5g(1작은술), 청국장가루 5g(1작은술), 마요네즈 20g(4작은술)
●장식 : 대추 5g(1개)

## 조리 순서
1. 검정깨, 마요네즈, 청국장 가루를 섞어 소스를 만든다., 2. 팬에 식용유를 둘러 연어와 마늘종을 굽는다., 3. 마늘종을 접시에 깔고 연어를 올린 뒤 소스를 뿌리고 채썬 대추채를 얹어 장식한다. 대추채를 얹어 장식한다.
