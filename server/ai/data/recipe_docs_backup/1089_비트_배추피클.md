# 요리명: 비트 배추피클

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 48.4 kcal
- 나트륨 함량: 9.3 mg

## 필요한 재료
비트(10g), 배추(20g), 무(50g), 사과(50g),
당근(10g), 식초(25g), 설탕(10g),
월계수잎(2장), 통후추(2g), 물(100g)

## 조리 순서
1. 무와 배추를 1x4x1cm 크기로  자른다., 2. 비트는 2x4x0.3cm로 자른다., 3. 당근은 모양내어 자른다., 4. 껍질 벗긴 사과와 물을 1:1 비율로 넣고 갈아 체에 내려 건더기를 제거한다., 5. 4번에 식초를 2:1 비율로 넣고 월계수잎, 통후추를 넣고 끓여준다., 6. 손질한 무, 배추, 비트, 당근을 넣고 식혀준다.
