# 요리명: 치킨완자스프

## 기본 정보
- 요리 분류: 일품
- 조리 방식: 끓이기
- 열량(칼로리): 236.7 kcal
- 나트륨 함량: 199.1 mg

## 필요한 재료
버터(20g), 밀가루(20g), 육수(100g), 생크림(20g)
브로컬리(30g), 우유(100g), 닭고기살(100g), 대추(20g)
표고버섯(20g), 당근(20g), 마늘(10g), 양파(20g)
소금(0.3g), 후춧가루(0.05g), 참기름(5g)

## 조리 순서
1. 닭고기살은 곱게 다져 준비한다., 2. 대추는 씨를 빼고 다진다., 3. 당근과 양파, 표고버섯, 마늘은 다진다., 4. 삶은 브로컬리는 우유와 함께 갈아 놓는다., 5. 닭고기살에 대추(②)와 채소(③), 소금, 후춧가루, 참기름을 넣어 골고루 섞는다., 6. 섞여진 닭고기살(⑤)을 동글동글 하게 완자를 지어 살짝 데쳐내고, 냄비에 버터와 밀가루를 넣어 볶다가, 육수를 넣고 끓인 뒤 우유와 브로컬리 갈은 것 (④)과 생크림을 넣어 한 소큼 끓여 완성 한다.
