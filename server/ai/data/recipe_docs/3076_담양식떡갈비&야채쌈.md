# 요리명: 담양식떡갈비&야채쌈

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 굽기
- 열량(칼로리): 200.4 kcal
- 나트륨 함량: 197.1 mg

## 필요한 재료
우육(분쇄육) 60g, 돈육(분쇄육) 30g, 두부 30g, 양파 5g, 대파 5g, 상추 30g, 깻잎 10g, 해바라기씨 2g, 간장 0.5g, 설탕 5g, 쌈장 5g

## 조리 순서
1. 분쇄 우육과 돈육은 해동 후 핏물을 제거한다., 2. 두부는 끓는 물에 데쳐낸 후 으깬다., 3. 우육, 돈육, 다진양파, 다진대파, 으깬 두부(15g)에 간장과 설탕으로 간을 한 후 여러번 치댄다., 4. 점성이 생긴 고기를 동그랗게 성형한 후 팬에 구워낸다., 5. 쌈장에 으깬 두부(15g)와 해바라기 씨를 넣어 섞는다., 6. 떡갈비와 양념장, 야채쌈을 함께 제공한다.
