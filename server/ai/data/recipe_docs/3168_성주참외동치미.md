# 요리명: 성주참외동치미

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 37.47 kcal
- 나트륨 함량: 80.06 mg

## 필요한 재료
참외 20g, 양파 10g, 배 5g, 대파 3g, 마늘 3g, 홍고추 1g, 생강 1g, 식초 4g, 설탕 3g, , 누룩소금 0.5g, 물 150ml

## 조리 순서
1. 참외는 껍질과 속을 제거하고 먹기 좋은 크기로 썬다., 2. 배와 마늘은 편 썰기, 양파와 대파는 채썰기, 홍고추와 생강은 다진다., 3. 물에 식초, 설탕, 누룩소금을 넣어 국물을 만든다., 4. 만들어 놓은 국물에 참외, 배, 양파를 넣어 잘 섞어 준다., 5. 마지막으로 마늘, 홍고추, 생강을 넣어 섞어 준다., 6. 동치미를 그릇에 담아 완성한다.
