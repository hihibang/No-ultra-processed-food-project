# 요리명: 브로콜리스프

## 기본 정보
- 요리 분류: 일품
- 조리 방식: 끓이기
- 열량(칼로리): 134.5 kcal
- 나트륨 함량: 112.9 mg

## 필요한 재료
닭육수 200g, 양송이버섯 30g, 브로콜리 50g, 생크림 50g, 함초소금 1g
고명 : 바케트 20g
청양고추버터 : 청양고추 1개, 버터 15g, 방울토마토 20g, 설탕 15g

## 조리 순서
1. 닭육수에 브로콜리, 양송이를 넣고 끓인다., 2. 생크림을 넣고 갈아준 후 함초소금으로 간을 해준다., 3. 다진 청양고추와 버터를 섞어 청양고추버터를 만들어준다., 4. 토마토를 믹서에 갈아 설탕과 팬에 섞어서 토마토 시럽을 만들어준다., 5. 바게트에 토마토시럽을 발라주고 청양고추 버터를 발라 140도 오븐에서 2분간 구워준다., 6. 그릇에 브로콜리스프를 담아주고 청양고추 버터 바게트를 곁들여 완성한다.
