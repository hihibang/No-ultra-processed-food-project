# 요리명: 함박스테이크&토마토카레소스

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 84.01 kcal
- 나트륨 함량: 106.88 mg

## 필요한 재료
소고기(다짐육) 50g, 양송이버섯 5g, 양파 40g, 빵가루 25g, 다진 마늘 5g, 카레가루 15g, 토마토 25g, 당근 15g, 감자 15g, 계란노른자 5g

## 조리 순서
1. 양파, 양송이버섯, 당근, 감자, 토마토를 잘게 다진다., 2. 다진 소고기와 다진 양파, 다진 양송이버섯, 다진 마늘, 빵가루, 계란노른자를 넣고 치댄다., 3. 반죽을 70g씩 나눠 스테이크 모양을 만들어 굽는다., 4. 다진 당근, 감자, 양파, 토마토, 마늘과 카레가루를 물에 넣고 끓인다., 5. 카레 소스가 농도가 날 때 까지 끓인다., 6. 스테이크와 카레소스를 곁들여 담는다.
