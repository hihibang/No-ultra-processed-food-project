# 요리명: 아보카도 수란샐러드

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 172.1 kcal
- 나트륨 함량: 88.2 mg

## 필요한 재료
[ 2인분 ] 상추(3장), 레몬(½개), 아보카도(1개), 토마토(1개), 달걀(1개), 파프리카(빨강, 노랑 각 ½개), 소금(0.2ts), 식초(0.5ts), 소금(0.3ts), 후춧가루(약간), 바질가루(0.5t), 오레가노가루(0.5t), 올리브유(1Ts), 레몬즙(1Ts)

## 조리 순서
1. 상추는 깨끗하게 씻어 한입 크기로 뜯고, 레몬은 모양대로 얇게 썰고, 아보카도는 씨와 껍질을 제거한 뒤 한입 크기로 썬다., 2. 파프리카는 씨를 제거한 뒤 한입 크기로 썰고, 토마토는 한입 크기로 썬다., 3. 끓는 소금물(물4컵+소금0.2ts)에 식초를 넣은 뒤 달걀을 넣고 수란을 만든다., 4. 드레싱을 만든다., 5. 그릇에 손질한 채소를 담고 수란과 얇게 썬 레몬을 올려 마무리한다.
