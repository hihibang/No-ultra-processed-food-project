# 요리명: 산마드래싱과 실곤약 샐러드

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 97.0 kcal
- 나트륨 함량: 36.0 mg

## 필요한 재료
그린비타민 8g, 치커리 8g, 배 15g, 포도주스 10g, 훈제오리가슴살 30g, 실곤약 20g [산마드래싱] 산마 10g, 우유 10g, 레몬주스 3g, 오렌지주스 3g, 호두 3g, 소금 적당량

## 조리 순서
1. 비타민과 치커리는 한입 크기로 적당히 뜯어 찬물에 담궈 두었다가 먹기 전에 물기를 제거한다., 2. 믹서에 산마와 우유, 레몬주스, 오렌지주스, 호두, 소금을 넣고 곱게 갈아 드래싱을 만든다., 3. 배는 껍질을 제거하고 4등분 한 뒤 씨를 제거하고 4~5mm 정도의 두께로 슬라이스한다., 4. 팬에 포도주스를 붓고 슬라이스한 배를 넣어 배가 포도색이 되도록 졸인다., 5. 훈제오리가슴살을 얇게 슬라이스 한다., 6. 접시에 5와 4, 실곤약, 야채들을 보기 좋게 담고 드래싱을 끼얹는다.
