# 요리명: 배추겉절이

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 2.0 kcal
- 나트륨 함량: 85.0 mg

## 필요한 재료
1인분 기준<br>
[주재료] 알배추(23g), 쪽파(5g),통깨(2g), 겉절이 양념(15g)<br>
[겉절이 양념(124g분량)] 찐 감자(20g), 고춧가루(25g), 매실청(5g), 까나리액젓(10g), 새우젓(3g), 무(20g), 양파(30g),생강(1g), 마늘(10g)

## 조리 순서
1. 알배추는 한입 크기로 자른다., 2. 쪽파는 3cm 길이로 썰고, 찐 감자는 한입 크기로 자른다, 3. 마늘, 생강, 무, 양파는 깨끗이 씻어 한입 크기로 자른다., 4. 믹서에 찐 감자, 고춧가루, 매실청, 까나리액젓, 새우젓, 무, 양파, 생강, 마늘을 넣고 갈아 겉절이 양념을 만든다., 5. 손질한 알배추, 쪽파, 겉절이 양념(15g)을 버무린다., 6. 접시에 담고 통깨를 뿌려 마무리한다.
