# 요리명: 마감자전

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 굽기
- 열량(칼로리): 165.4 kcal
- 나트륨 함량: 156.4 mg

## 필요한 재료
마감자전 : 감자 40g, 마 40g, 찹쌀가루 15g, 양파 5g, 현미유 5g 간장양념장 : 간장 3g, 파 2g, 식초 2g, 통깨 0.5g

## 조리 순서
1. 양파와 파는 씻어 곱게 다진다., 2. 감자와 마는 껍질을 벗긴 후 씻는다., 3. 2를 강판에 간다., 4. 1과 3을 섞은 후 찹쌀가루를 넣어 반죽한다., 5. 현미유를 두른 팬에 반죽을 떠서 지름 8cm 크기로 동그랗게 부친다., 6. 간장, 파, 식초, 통깨를 넣고 간장양념장을 만들어 곁들인다.
