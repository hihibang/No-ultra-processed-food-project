# 요리명: 곤약백김치말이

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 46.99 kcal
- 나트륨 함량: 171.08 mg

## 필요한 재료
판곤약 60g, 부추 2g, 파프리카(빨강, 노랑, 청색) 각 7g, 대왕오징어채 30g, 백김치 30g, 양조식초 3g

## 조리 순서
1. 곤약은 얇게 편으로 썰어 데친 뒤, 백김치 국물에 절인다., 2. 끓는 물에 식초를 넣고 오징어를 질기지 않게 살짝 삶는다., 3. 파프리카는 채썰어 준다., 4. 백김치는 물기를 제거한다., 5. 곤약을 깔고 오징어, 파프리카를 얹어 백김치로 말아준다., 6. 데쳐낸 부추로 풀어지지 않게 매듭을 짓는다.
