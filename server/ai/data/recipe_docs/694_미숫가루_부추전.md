# 요리명: 미숫가루 부추전

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 굽기
- 열량(칼로리): 212.8 kcal
- 나트륨 함량: 228.7 mg

## 필요한 재료
부침가루 30g, 미숫가루 10g, 오징어 20g, 부추 20g, 감자 15g, 당근 5g, 양파 5g, 현미유 4g, 소금 0.5g, 물 60g

## 조리 순서
1. 오징어는 내장을 제거하고 깨끗하고 씻어낸다., 2. 부추, 감자, 당근, 양파는 2cm 가량으로 곱게 채 썬다., 3. 부침가루와 미숫가루를 3 : 1의 비율로 섞는다., 4.  1, 2, 3에 물을 넣어 반죽하고 소금으로 간을 한다., 5. 팬에 현미유를 두르고 3의 반죽을 둥글게 떠 넣어 노릇노릇하게 지진다., 6. 그릇에 담아 완성한다.
