# 요리명: 리코타치즈 카프레제

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 기타
- 열량(칼로리): 222.7 kcal
- 나트륨 함량: 13.9 mg

## 필요한 재료
방울토마토(100g), 우유(370㎖), 레몬즙(20g), 발사믹식초(10g), 레몬즙(1g), 올리브유(10g)

## 조리 순서
1. 냄비에 우유(370㎖)를 넣어 센 불로 올린 뒤 가장자리가 끓어오르면 레몬즙(20g)을 넣어 몽글해질 때까지 젓는다., 2. 물에 적신 면포에 끓인 우유를 넣고 물기를 제거해 리코타치즈를 만든다., 3. 냄비에 발사믹식초(10g), 레몬즙(1g)을 넣어 2분간 끓이다가 올리브유(10g)를 넣어 섞은 뒤 불을 꺼 발사믹 드레싱을 만든다., 4. 방울토마토는 반으로 썰고, 굳힌 리코타치즈는 한입 크기로 만든다., 5. 그릇에 방울토마토와 리코타치즈를 올리고 발사믹 드레싱을 뿌린다.
