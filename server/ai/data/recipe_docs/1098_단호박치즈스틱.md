# 요리명: 단호박치즈스틱

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 튀기기
- 열량(칼로리): 526.8 kcal
- 나트륨 함량: 9.2 mg

## 필요한 재료
단호박(200g), 새우살(120g),
삼색파프리카(80g), 양파(40g),
옥수수(20g), 모짜렐라치즈(20g),
춘권피(10장), 생크림(15g), 식용유(40g)

## 조리 순서
1. 단호박은 찜통에 찐 뒤 껍질을 제거하고 으깨 생크림을 넣고 섞는다., 2. 새우살, 파프리카, 양파는 잘게 다진 뒤 팬에 식용유를 두르고 볶는다., 3. 볼에 1번과 2번, 옥수수, 소금을 넣고 잘 섞는다., 4. 춘권피에 3번을 넓게 펴준 뒤   모짜렐라 치즈를 올린다., 5. 춘권피를 잘 말아 모양을 만든다., 6. 180℃ 기름에 튀긴다.
