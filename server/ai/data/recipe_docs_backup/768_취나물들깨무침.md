# 요리명: 취나물들깨무침

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 83.4 kcal
- 나트륨 함량: 256.1 mg

## 필요한 재료
참취 70g, 간장 1.5g, 소금 0.5g, 다진 파 2.25g, 다진 마늘 1g, 들기름 3g, 거피들깨가루 6g

## 조리 순서
1. 취나물을 끓는 물에 살짝 데친다., 2. 데친 취나물은 찬물에 헹군다., 3. 취나물을 가볍게 짜서 물기를 제거하고 5cm 길이로 자른다., 4. 나머지 재료를 모두 섞어 양념장을 준비한다., 5. 볼에 취나물을 담고 양념장을 넣어 조물조물 무쳐낸다., 6. 무쳐낸 나물을 그릇에 담아 마무리한다.
