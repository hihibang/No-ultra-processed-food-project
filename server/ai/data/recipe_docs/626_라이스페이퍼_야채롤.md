# 요리명: 라이스페이퍼 야채롤

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 229.2 kcal
- 나트륨 함량: 270.3 mg

## 필요한 재료
새우(3마리), 양파(30g), 파프리카(50g), 베이컨(20g),
아스파라거스(2개), 라이스페이퍼(3장), 깻잎(5장), 땅콩(20g),
블루베리(20g)

## 조리 순서
1. 새우는 껍질을 제거하고 데쳐 편썬다., 2. 양파, 파프리카는 채썬다., 3. 땅콩은 갈아서 블루베리와 섞어 소스를 만든다., 4. 라이스페이퍼는 물에 적신 뒤 건진다., 5. 라이스페이퍼에 깻잎을 올린다., 6. ?위에 새우, 파프리카, 양파, 베이컨, 아스파라거스를 넣고 돌돌 말아 땅콩소 스를 곁들인다.
