# 요리명: 열무곤약국수

## 기본 정보
- 요리 분류: 일품
- 조리 방식: 기타
- 열량(칼로리): 62.2 kcal
- 나트륨 함량: 477.8 mg

## 필요한 재료
열무김치 100g, 실곤약 150g, 오이 25g, 레몬 20g
양파 60g, 계란 60g, 당근 20g, 통깨 3g

## 조리 순서
1. 실곤약은 세척해 레몬즙을 뿌려 물기를 빼준다., 2. 오이는 채 썰어준다., 3. 당근, 양파를 채 썰어서 냉수에 담가준다., 4. 열무김치국물과 물200g에 섞어서 국물을 만들어준다, 5. 달걀은 쪄서 반만 잘라 준비해준다., 6. 그릇에 곤약. 열무, 준비된 채소를 넣고 마지막에 국물을 넣어 완성한다
