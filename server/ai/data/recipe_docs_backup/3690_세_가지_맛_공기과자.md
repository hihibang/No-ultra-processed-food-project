# 요리명: 세 가지 맛 공기과자

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 기타
- 열량(칼로리): 41.2 kcal
- 나트륨 함량: 14.6 mg

## 필요한 재료
주재료 > 검은콩 20g, 단호박 70g, 비트 70g, 달걀흰자 120g, 설탕 10g, 달걀노른자 20g, 박력 밀가루 24g, 허브가루 약간

## 조리 순서
1. 냄비에 검은콩을 넣고 20분 동안 삶아 체에 거르고 으깨어 검은콩 퓨레를 만든다., 2. 달걀흰자에 설탕을 넣으며 단단한 머랭을 만든다. 달걀노른자, 박력 밀가루를 머랭에 넣고 자르듯이 섞어 머랭 반죽을 만든다., 3. 퓨레에 머랭 반죽을 나누어 섞어 3가지 반죽을 만든다., 4. 종이컵에 각각의 반죽을 2/3 정도 넣고, 전자레인지에 50~55초 동안 굽는다., 5. 10분 동안 식혀 종이컵에서 분리한다, 6. 모양을 내어 자른 후 허브가루를 뿌리고 접시에 담아 마무리한다.
