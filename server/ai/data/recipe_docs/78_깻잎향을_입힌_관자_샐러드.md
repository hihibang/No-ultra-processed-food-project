# 요리명: 깻잎향을 입힌 관자 샐러드

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 굽기
- 열량(칼로리): 155.0 kcal
- 나트륨 함량: 168.0 mg

## 필요한 재료
돌나물(10g), 깻잎(3장), 관자(5개) , 식용 꽃(약간) , 올리브유(60g), 석류 원액(3g), 레시틴가루(0.5), 후춧가루(약간)

## 조리 순서
1. 돌나물은 손질하여 찬물에 담갔다가 물기를 빼고, 깻잎은 씻어 한 장씩 앞뒤로 물기를 닦고, 식용 꽃은 찬물에 담가 놓는다., 2. 튀김 팬에 올리브유(50g)를 붓고 예열해 깻잎을 넣어 바삭하고 투명하게 튀긴 뒤 건지고 팬에 남은 깻잎 기름은 따로 둔다., 3. 석류 원액에 물(100ml)과 레시틴가루를 넣어 블렌더로 섞어 석류 거품을 만든다., 4. 관자는 막을 제거한 뒤 찬물에 씻고, 잘게 칼집을 내 후춧가루를 뿌린다., 5. 달군 팬에 올리브유(10g)를 두르고 관자를 넣어 겉은 노릇하게 굽는다., 6. 접시에 튀긴 깻잎, 돌나물, 구운 관자, 깻잎 기름을 순서대로 담고, 석류 거품을 올려 마무리한다.
