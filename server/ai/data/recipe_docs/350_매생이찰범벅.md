# 요리명: 매생이찰범벅

## 기본 정보
- 요리 분류: 밥
- 조리 방식: 끓이기
- 열량(칼로리): 122.3 kcal
- 나트륨 함량: 64.3 mg

## 필요한 재료
우유100g, 매생이 20g, 찹쌀 15g, 단호박 50g
밤 30g, 녹차소금 1g, 멸치육수 150g

## 조리 순서
1. 찹쌀은 미리 불려준다., 2. 매생이는 물에 담가 짠기와 이물질을 빼준다., 3. 단호박은 작은 사각형으로 잘라 멸치육수에 데쳐준다., 4. 밤은 곱게 다져주어 고명으로 사용한다., 5. 우유와 육수를 섞은 뒤 찹쌀을 끓여준다., 6. 죽이 어느 정도 완성되면 데쳐낸 호박과 매생이를 넣어 범벅을 만들어준다.
