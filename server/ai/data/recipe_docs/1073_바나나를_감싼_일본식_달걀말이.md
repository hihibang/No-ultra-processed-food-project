# 요리명: 바나나를 감싼 일본식 달걀말이

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 굽기
- 열량(칼로리): 362.3 kcal
- 나트륨 함량: 25.2 mg

## 필요한 재료
달걀(3개), 바나나(1개), 전분(5g),
소금(0.2g)

## 조리 순서
1. 달걀을 흰자와 노른자로 분리한다., 2. 흰자와 노른자를 각각 풀어 전분과 소금을 넣는다., 3. 팬에 식용유를 두르고 노른자를 부어 반정도 익힌다., 4. 바나나를 넣고 말아준다., 5. 흰자를 부어 4번을 감싸  말아준다., 6. 먹기 좋은 크기로 자른다.
