# 요리명: 잡곡강정밥

## 기본 정보
- 요리 분류: 밥
- 조리 방식: 기타
- 열량(칼로리): 594.3 kcal
- 나트륨 함량: 1.3 mg

## 필요한 재료
잡곡(50g), 찹쌀(50g), 호두(20g),
은행(20g), 밤(20g), 대추고(60g), 꿀(5g),
간장(15g), 소금(2g)

## 조리 순서
1. 잡곡과 찹쌀은 물에 씻어 불린 뒤 소금을 넣고 밥을 짓는다., 2. 호두는 껍질을 제거하고 굵게 부숴 마른 팬에 볶는다., 3. 은행은 기름에 볶아 껍질을 제거하고 4등분 한다, 4. 생밤은 껍질을 벗기고 작은 주사위 모양으로 자른 뒤 기름에 굽는다., 5. 물 40g에 간장, 대추고, 꿀을 넣고 끓인 뒤 2,3,4번을 넣고 잘 섞는다., 6. 잡곡밥을 넓게 펼친 뒤 5번을 넣고 돌돌 만다.
