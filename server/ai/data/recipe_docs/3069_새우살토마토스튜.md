# 요리명: 새우살토마토스튜

## 기본 정보
- 요리 분류: 국&찌개
- 조리 방식: 끓이기
- 열량(칼로리): 67.1 kcal
- 나트륨 함량: 280.4 mg

## 필요한 재료
새우살 30g, 토마토 20g, 양파 15g, 당근 10g, 애호박 15g, 건다시마 3g, 버터 3g, 케찹 5g,10g, 후추 0.1g, 소금 0.2g, 물 300ml

## 조리 순서
1. 다시마로 육수를 낸다., 2. 새우살은 데치고 토마토는 칼집을 내어 데친 후 껍질을 벗긴다., 3. 토마토, 양파, 당근, 호박은 먹기 좋은 크기로 썬다., 4. 새우살과 당근, 호박을 버터에 볶아 준다., 5. 기름을 두른 팬에 토마토와 양파를 넣고 조린다., 6. ⑤에 ④와 육수, 케첩을 넣고 끓인 후 후추를 넣고 소금으로 간을 하여 마무리한다.
