# 요리명: 버섯 참치 무른밥

## 기본 정보
- 요리 분류: 밥
- 조리 방식: 끓이기
- 열량(칼로리): 145.0 kcal
- 나트륨 함량: 1.0 mg

## 필요한 재료
불린 쌀 30g, 물 92g, 참치살 10g, 표고버섯 5g, 무 5g, 양파 5g, 참기름 2g, 통깨 1g, 소금적당량

## 조리 순서
1. 불린 쌀은 믹서나 절구를 이용하여 간다., 2. 참치 살, 표고버섯, 무, 양파는 곱게 다진다., 3. 팬에 참기름을 두르고 1과 다진 표고버섯, 무, 양파를 볶는다., 4. 3에 물을 넣어 무른 밥을 짓는다., 5. 4의 밥이 끓어오르면 다진 참치 살을 넣고 저어가며 끓인다., 6. 참치 살이 다 익으면 통깨를 뿌린다.
