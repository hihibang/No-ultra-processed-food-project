# 요리명: 토마토 비빔국수

## 기본 정보
- 요리 분류: 일품
- 조리 방식: 기타
- 열량(칼로리): 346.0 kcal
- 나트륨 함량: 128.7 mg

## 필요한 재료
양파(20g), 바질(10g), 삶은 달걀(1개), 쌀국수(100g), 토마토(200g), 고추장(½Ts), 고춧가루(½Ts), 꿀(1Ts)

## 조리 순서
1. 양파, 바질은 채 썰고, 삶은 달걀은 반으로 자른다., 2. 채 썬 양파는 찬물에 담가 체에 밭쳐 물기를 제거한다., 3. 믹서에 비빔소스 재료를 넣고 갈아 비빔소스를 만든다., 4. 끓는 물(8컵)에 쌀국수를 넣어 2분 삶아 찬물에 헹궈 체에 밭친다., 5. 그릇에 쌀국수 → 비빔소스 → 양파, 바질 → 달걀 순으로 얹고 마무리한다.
