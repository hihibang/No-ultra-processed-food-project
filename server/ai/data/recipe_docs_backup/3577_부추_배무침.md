# 요리명: 부추 배무침

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 32.1 kcal
- 나트륨 함량: 305.1 mg

## 필요한 재료
1인분 기준<br>
[주재료]부추(30g), 양파(10g), 배(15g)<br>
[양념]다진 마늘(8g), 고춧가루(8g), 멸치액젓(6g), 저염간장(3g), 레몬즙(10g), 통깨(4g)

## 조리 순서
1. 부추는 다듬어 5~6cm 크기로 썰고, 양파는 뿌리와 껍질을 제거해 얇게 채 썬다., 2. 배는 껍질을 제거해 여덟 등분하고 씨를 제거하여 편 썰기를 한다., 3. 다진 마늘, 고춧가루, 멸치액젓, 저염간장, 레몬즙, 통깨(2g)를 섞어 양념장을 만든다, 4. 부추, 양파, 배의 물기를 제거한다., 5. 볼에 담고 양념장을 넣어 버무린다., 6. 접시에 담고 통깨(2g)를 뿌려 마무리한다.
