# 요리명: 풋마늘오징어김치

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 39.2 kcal
- 나트륨 함량: 220.8 mg

## 필요한 재료
주재료: 풋마늘 20, 물 200, 건오징어 5 양념: 밀가루 1.25, 물 20, 소금 0.25, 고춧가루 0.6, 새우젓 0.75, 멸치액젓 0.2g, 설탕 1, 통깨 0.5, 생강즙 0.25

## 조리 순서
1. 풋마늘을 깨끗이 씻어 5cm 길이로 썬다., 2. 물에 풋마늘을 30분 정도 담가 매운맛을 뺀다., 3. 오징어를 1cm x 5cm 크기로 썬다., 4. 밀가루와 물을 섞어 약불에서 풀을 쑤어 차게 식힌다., 5. 풀에 나머지 양념장 재료를 모두 넣어 섞는다., 6. 풋마늘과 오징어에 양념장을 넣고 버무려 즉석에서 먹거나 살짝 익혀 먹는다.
