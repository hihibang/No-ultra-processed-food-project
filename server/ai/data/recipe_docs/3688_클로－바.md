# 요리명: 클로－바

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 기타
- 열량(칼로리): 143.7 kcal
- 나트륨 함량: 3.3 mg

## 필요한 재료
주재료 > 귀리 100g, 아몬드슬라이스 25g, 피칸 25g, 땅콩버터 25g, 클로렐라가루 7.5g, 알룰로스 50g, 코코넛우유 45ml, 아몬드우유 80ml, 대추채 12.5g, 카카오닙스 25g, 건크랜베리 12.5g
초콜릿 > 카카오매스 40g, 다크초콜릿 25g

## 조리 순서
1. 프라이팬에 물에 불린 귀리, 아몬드슬라이스, 피칸을 넣고 살짝 볶는다., 2. 볼에 땅콩버터, 클로렐라가루, 알룰로스를 넣고 섞다가 코코넛우유, 아몬드우유를 넣어 고루 섞는다., 3. 볶은 귀리, 아몬드슬라이스, 피칸과 대추채, 카카오닙스, 건크랜베리를 넣고 섞어 크런치 토핑을 만든다., 4. 볼에 카카오매스, 다크초콜릿을 넣고 전자레인지에서 20~25초 동안 녹인다., 5. 팬에 유산지를 깔고 크런치 토핑을 넣고 평평하게 편 후 녹인 초콜릿을 코팅하듯 바른다., 6. 냉동실에 20분 동안 넣어 굳히고 먹기 좋은 크기로 썰어 마무리한다.
