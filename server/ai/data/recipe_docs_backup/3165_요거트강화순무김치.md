# 요리명: 요거트강화순무김치

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 15.87 kcal
- 나트륨 함량: 29.8 mg

## 필요한 재료
순무 40g, 쪽파 0.2g, 고운 고춧가루 1g, 굵은 고춧가루 1g, 다진마늘 1g, 플레인요거트 2g, 소금 0.2g

## 조리 순서
1. 순무는 2.5*2.5*0.3 cm 크기로 나박 모양으로 썬다., 2. 고운 고춧가루, 굵은 고춧가루, 다진마늘, 소금, 요거트를 섞어 양념장을 만든다., 3. 쪽파는 0.2cm 크기로 송송 썰어 준비한다., 4. 순무에 양념장을 넣고 버무려 준다., 5. 양념된 순무를 하루 정도 냉장보관하여 숙성시킨다., 6. 숙성된 순무김치에 쪽파를 고명으로 얹어 제공한다.
