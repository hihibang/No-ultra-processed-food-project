# 요리명: 콩감태유자 스콘

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 기타
- 열량(칼로리): 228.3 kcal
- 나트륨 함량: 29.7 mg

## 필요한 재료
주재료 > 삶은 병아리콩① 175g, 두유 210g, 코코넛오일 70g, 유자필 56g, 쌀가루 280g, 아몬드가루 105g, 감태가루 3.5g
앙 금 > 유자앙금 105g, 삶은 병아리콩② 50g

## 조리 순서
1. 믹서에 삶은 병아리콩①, 두유, 코코넛오일을 넣고 곱게 간다., 2. 볼에 담고 유자필을 넣어 섞는다., 3. 쌀가루, 아몬드가루, 감태가루를 체 쳐서 넣고 섞어 반죽을 만든다., 4. 반죽은 10~12cm 크기의 원형으로 성형하고, 유자앙금과 삶은 병아리콩②를 섞어 반죽 위에 올린다, 5. 4~5등분으로 자르고 오븐 팬에 올린다., 6. 175°C로 예열한 오븐에 170°C에서 20분 동안 구워 마무리한다.
