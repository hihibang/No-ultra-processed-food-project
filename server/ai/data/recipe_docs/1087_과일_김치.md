# 요리명: 과일 김치

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 98.3 kcal
- 나트륨 함량: 14.6 mg

## 필요한 재료
사과(30g), 배(10g), 복숭아(15g),
토마토(25g), 치커리(3g), 고춧가루(2g),
마늘(3g), 깨(2g), 참기름(2g), 소금(0.5g)

## 조리 순서
1. 토마토는 십자로 칼집을 내고 끓는 물에 살짝 데쳐 껍질을 벗긴다., 2. 사과, 복숭아는 깍둑썰고 소금에  10분 정도 절인다., 3. 배를 강판에 갈고, 마늘은 다진다., 4. 갈아둔 배에 고춧가루, 다진 마늘, 깨, 참기름을 섞어 양념을 만든다., 5.  절여둔 과일을 양념과 섞는다., 6. 치커리를 넣고 섞는다.
