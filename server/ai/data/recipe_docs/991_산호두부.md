# 요리명: 산호두부

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 끓이기
- 열량(칼로리): 89.4 kcal
- 나트륨 함량: 55.0 mg

## 필요한 재료
두부 35g, 돼지고기다진것 15g, 당근다진것 10g, 고추기름 2g, 완두콩 10g, 파 5g, 생강 3g, 물전분 10g, 소금 적당량

## 조리 순서
1. 두부를 1cm 주사위모양으로 자른다., 2. 1을 뜨거운 물에 넣었다가 꺼내 물기를 제거한다., 3. 당근과 돼지고기를 잘게 다진다., 4. 팬에 고추기름을 두른 뒤 3을 넣고 볶는다., 5. 파, 다진생강, 물, 완두콩, 소금, 두부를 넣고 간이 들도록 졸인다., 6. 물 전분을 넣어 소스의 농도를 맞춘다.
