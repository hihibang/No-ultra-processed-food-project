# 요리명: 된장 두부찌개

## 기본 정보
- 요리 분류: 국&찌개
- 조리 방식: 끓이기
- 열량(칼로리): 77.3 kcal
- 나트륨 함량: 124.6 mg

## 필요한 재료
두부 320g(1모), 쌀뜨물 300g(1½컵), 돼지고기 100g, 김치 140g, 된장 20g(1½큰술), 청양고추 10g(1/2개), 홍고추 5g(1/4개),
대파 10g(2cm), 고춧가루 5g(1작은술)

## 조리 순서
1. 두부에 쌀뜨물을 넣고 갈아준다., 2. 돼지고기는 썰고 김치는 물에 씻어 양념을 제거하고 3×3cm로 썬다., 3. 냄비에 돼지고기와 김치를 함께 볶은 후, 망에 거른 된장과 1의 두부, 고춧가루, 청양고추, 홍고추를 넣어 끓이다가 대파를 넣어 완성한다.
