# 요리명: 고등어 묵말랭이 냉소바

## 기본 정보
- 요리 분류: 일품
- 조리 방식: 기타
- 열량(칼로리): 176.1 kcal
- 나트륨 함량: 207.6 mg

## 필요한 재료
주재료 
묵말랭이 20g, 양배추 15g, 당근 15g, 쪽파 10g, 고등어 40g

소바육수 재료 
간장 27.5g, 맛술 5g, 식초 0.25g, 유자청 10g,
가다랑어포 4g, 다시마 3g

양념 
올리브유 5g, 맛술 5g, 유자청 5g

## 조리 순서
1. 묵말랭이는 따뜻한 물에 5시간 정도 불린 후, 끓는 물에 15분간 삶아 식힌다., 2. 양배추, 당근은 채 썰고, 쪽파는 잘게 자른다., 3. 냄비에 물(180ml), 소바육수 재료를 모두 넣고 끓인다., 4. 끓인 육수를 체에 거르고 냉동실에서 차갑게 식혀 소바육수를 만든다., 5. 올리브유를 두른 팬에 고등어를 구운 뒤, 소바육수(5g), 맛술(5g), 유자청(5g), 물(30ml)을 넣고 조린다., 6. 그릇에 불린 묵말랭이를 담고 차가운 소바육수를 넣는다. 조린 고등어, 손질한 채소를 올려 마무리한다.
