# 요리명: 고구마란

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 기타
- 열량(칼로리): 166.0 kcal
- 나트륨 함량: 13.0 mg

## 필요한 재료
고구마 70g, 꿀 10g, 계피가루 2g, 대추 5g, 호박씨 5g

## 조리 순서
1. 고구마는 껍질을 벗긴 후 큼직하게 썰어 찜통에 찐다., 2. 다 쪄진 고구마를 체에 곱게 내린다., 3. 2에 꿀과 계피가루를 넣어 섞는다., 4. 대추는 씨를 제거한 뒤 0.5mm  마름모꼴로 자른다., 5. 고구마를 조금씩 떼어 둥글게 빚는다., 6. 호박씨와 썰어둔 대추로 꼭지를 만든다.
