# 요리명: 약밥 닮은 호떡

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 굽기
- 열량(칼로리): 401.4 kcal
- 나트륨 함량: 12.4 mg

## 필요한 재료
호떡반죽(200g), 밤(30g), 고구마(30g),
곶감(50g), 호두(10g), 호박씨(10g),
잣(5g), 대추(1알), 계피가루(8g),
식용유(15g), 물(80g)

## 조리 순서
1. 호떡반죽에 물을 넣고 반죽한 뒤 발효시킨다., 2. 밤, 고구마, 대추, 곶감, 호두를 다진다., 3. 2번에 잣, 호박씨, 계피가루, 홍시를 섞는다., 4. 발효시킨 반죽에 3번을 채우고 동그랗게 빚는다., 5. 팬에 식용유를 두른다., 6. 가열된 팬에 반죽을 올린 뒤 납작하게 눌러 굽는다.
