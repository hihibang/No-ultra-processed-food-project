# 요리명: 과일 젤리

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 기타
- 열량(칼로리): 143.4 kcal
- 나트륨 함량: 25.3 mg

## 필요한 재료
젤라틴 5g, 자몽주수 100g, 귤통조림 20g, 파인애플통조림 5g, 체리 15g, 설탕 15g

## 조리 순서
1. 젤라틴을 물에 불려 놓는다., 2. 자몽주스에 설탕을 넣고 가열한다., 3. 불린 젤라틴을 넣어 약한 불에서 젤라틴을 녹인다., 4. 틀에 귤과 파인애플, 체리를 넣는다., 5. 틀에 젤라틴을 녹인 자몽주스를 넣는다., 6. 냉장고에서 식혀 완성한다.
