# 요리명: 잔멸치땅콩볶음

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 볶기
- 열량(칼로리): 145.6 kcal
- 나트륨 함량: 352.7 mg

## 필요한 재료
땅콩 10, 잔멸치 10, 맛술 2.5, 올리브유 2, 건홍고추 1, 참기름 1, 콩기름 1, 다진 마늘 1, 굴소스 0.3, 두반장 1, 물엿 6, 통깨 0.5

## 조리 순서
1. 멸치를 마른팬에 넣고 볶는다., 2. 살짝 볶아낸 멸치에 올리브유와 맛술을 넣고 부드러워질 때까지 볶는다., 3. 땅콩을 찬물에 20분 담갔다 체에 건져 물기를 뺀다., 4. 건고추는 송송 썬다., 5. 팬에 올리브유, 참기름, 콩기름을 섞어 두르고 다진 마늘을 넣어 향을 낸 후 땅콩과 고추를 넣어 볶는다., 6. 볶은 멸치와 굴소스, 두반장, 물엿을 넣고 고루 섞은 다음 통깨를 뿌려낸다.
