# 요리명: 해산물 옥수수 오븐구이

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 굽기
- 열량(칼로리): 112.0 kcal
- 나트륨 함량: 211.0 mg

## 필요한 재료
달걀 30g, 새우 5g, 바지락 3g, 도미살 5g, 슬라이스 햄 3g, 실파 2g, 토마토 10g, 애호박 25g, 캔 옥수수 20g, 슬라이스 치즈 8g, 홍고추 1g, 바질 1g, 올리브오일 1g, 마늘다진것 1g, 소금적당량, 후춧가루 적당량

## 조리 순서
1. 새우는 껍질과 내장을 제거하고 바지락은 살짝 데쳐 입이 열리면 살을 발라낸다., 2. 해산물은 0.5cm 크기로 썰고 실파는 송송 썬다., 3. 토마토는 껍질을 벗겨 햄과 비슷한 크기로 썰고 바질은 굵게 채썬다., 4. 팬에 올리브오일은 두르고 햄, 옥수수를 넣어 볶다가 풀어둔 달걀을 넣고 스크램블을 만든다., 5. 4가 반 정도 익었을 때 해산물, 토마토, 바질을 넣고 홍고추로 장식하고 다 익으면 오븐용 용기에 담는다., 6. 5에 치즈를 0.5cm 넓이로 잘라 격자로 올리고 오븐에서 굽는다.
