# 요리명: 오징어 가라아게&칠리소스

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 튀기기
- 열량(칼로리): 595.1 kcal
- 나트륨 함량: 307.7 mg

## 필요한 재료
•필수 재료 : 오징어(80g), 대파(20g), 마늘(10g), 달걀노른자(25g), 밀가루(20g), 식용유(3g)
•양념 : 토마토(20g), 고춧가루(15g), 식초(50g), 설탕(15g), 전분(10g)

## 조리 순서
1. 오징어는 채 썰고, 마늘과 대파는 곱게 다진다., 2. 오징어, 대파, 마늘, 달걀노른자, 밀가루, 물(10g)을 섞어 반죽한 뒤 동그랗게 빚는다., 3. 가라아게를 180℃ 온도의 기름에서 튀긴다., 4. 토마토는 껍질을 제거한 뒤 잘게 다진다., 5. 냄비에 다진 토마토, 식초, 설탕, 물(50g), 고춧가루, 전분을 넣고 끓여 칠리소스를 만든다., 6. 오징어 가라아게에 칠리소스를 곁들여 마무리한다.
