# 요리명: 나스와 샐러드

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 92.0 kcal
- 나트륨 함량: 79.0 mg

## 필요한 재료
달걀 20g, 완두콩 5g, 오이 10g, 토마토 20g, 레드어니언 10g, 로메인 10g, 홍고추 2g, 블랙올리브 2g, 바질 1g, 캔참치 20g<strong>[드래싱]</strong> 올리브오일 2g, 레드와인식초 2g, 디존 머스타드 1g, 마늘 1g, 설탕적당량

## 조리 순서
1. 달걀은 완숙으로 삶아 껍질을 벗긴 뒤 세로로 4등분하고 완두콩은 끓는 물에 삶아 찬물에 헹군 뒤 물기를 제거한다., 2. 오이는 1cm 주사위모양으로 썰고 양파는 링으로 슬라이스 하고 로메인은 먹기 좋게 뜯어 찬물에 담군다., 3. 토마토는 달걀과 같은 모양으로 자르고 홍고추는 어슷하게 썰고 참치는 덩어리가 있게 기름기를 뺀다., 4. 바질은 슬라이스하고 마늘은 다진다., 5. 볼에 올리브오일과 레드와인식초, 머스타드, 설탕, 다진마늘을 섞어 드레싱을 만든다., 6. 다른 볼에 준비해둔 야채들과 달걀, 참치를 넣고 드래싱을 끼얹어 버무린다.
