# 요리명: 송이 미역국

## 기본 정보
- 요리 분류: 국&찌개
- 조리 방식: 끓이기
- 열량(칼로리): 136.0 kcal
- 나트륨 함량: 309.0 mg

## 필요한 재료
불린 쌀 30g, 양송이버섯 10g, 당근 10g, 양파 3g, 마른미역 5g, 참기름 2g, 물 90g

## 조리 순서
1. 쌀은 깨끗하게 씻어 불린다., 2. 1을 분쇄기로 살짝 간다., 3. 양송이버섯과 채소를 잘게 다진다., 4. 마른 미역은 30분 정도 불렸다가 잘게 다진다., 5. 냄비에 참기름을 두르고 2를 볶다가 3, 4를 넣고 한번 더 볶는다., 6. 5에 물을 넣은 뒤 쌀알이 퍼지도록 끓인다.
