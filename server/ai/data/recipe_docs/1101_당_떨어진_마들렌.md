# 요리명: 당 떨어진 마들렌

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 굽기
- 열량(칼로리): 661.8 kcal
- 나트륨 함량: 44.0 mg

## 필요한 재료
대추고(5g), 대추(2알), 당근퓨레(5g),
녹차가루(5g), 팥앙금(5g), 박력분(150g),
꿀(15g), 버터(150g), 달걀(2개),
베이킹파우더(3g), 소금(0.8g)

## 조리 순서
1. 박력분, 베이킹파우더, 소금을 체친 뒤 달걀을 2~3회 나누어 넣는다., 2. 1번을 3등분 하여 대추고, 채썬대추/당근퓨레/녹차가루, 팥앙금을 각각 섞는다., 3. 각각에 녹인 버터(50g)를 넣고 부드럽게 섞은 뒤 비닐을 덮어 실온에서 30분 간 휴지시킨다., 4. 마들렌 팬을 깨끗이 닦고 버터를 바른 뒤 밀가루를 뿌린다., 5. 짤주머니에 원형 깍지를 끼우고  반죽을 채운 뒤 팬에 80~90% 정도 짜 넣는다., 6. 175℃ 오븐에서 20분 간 굽는다.
