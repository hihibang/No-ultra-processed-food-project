# 요리명: 홍시잼 식빵

## 기본 정보
- 요리 분류: 기타
- 조리 방식: 기타
- 열량(칼로리): 239.0 kcal
- 나트륨 함량: 12.37 mg

## 필요한 재료
(반죽재료) 강력분 500g, 인스턴트 이스트 5g, 소금 7g, 달걀 50g(1개), 우유 250g, 포도씨유 50g 
(속재료) 홍시 1000g,  레몬즙 3g

## 조리 순서
1. (속재료) 홍시는 껍질을 제거하고 체에 거른 다음 냄비에 레몬즙을 넣고 졸여서 잼을 만든다., 2. 강력분, 소금, 인스던트 이스트를 먼저 섞다가 달걀, 포도씨유, 미지근하게 데운 우유를 넣어 가며 반죽한다. ★ 액체 온도가 60℃가 넘어가면 이스트가 죽을 수 있어 조심해 주세요., 3. 완성된 반죽을 1~2시간동안 실온에서 1차 발효 시킨 후, 세 덩어리로 나누어 15분 정도 2차 발효한다., 4. 반죽을 60g씩 8개의 덩어리로 만들어 밀대를 사용하여 피자도우처럼 얇게 편다., 5. 얇게 핀 반죽 위에 홍시 잼을 바르고 그 위에 핀 반죽을 올리는 걸 반복한 후 맨 위에 홍시 잼을 바르지 않은 반죽을 올리고 소량의 포도씨유를 바른 큐브식빵 틀에 담는다., 6. "180도로 예열한 오븐에 식빵 틀을 넣고 40분정도 굽는다. ★ 윗 면의 색이 많이 나면 종이 호일을 덮고 속까지 익혀요."
