# 요리명: 롤 삼계탕

## 기본 정보
- 요리 분류: 국&찌개
- 조리 방식: 끓이기
- 열량(칼로리): 103.4 kcal
- 나트륨 함량: 50.2 mg

## 필요한 재료
●주재료: 마 30g(1/3개), 대추20g(10개), 은행35g(25개), 단호박 40g(1/8개), 아스파라거스 15g(1/3개), 영콘 20g(1개), 마늘 10g(2개), 쌀 200g(1컴)
●육수 : 닭 550g(1마리), 파 15g(1큰술), 마늘 15(3개)

## 조리 순서
1. 닭은 살을 발라낸다., 2. 남은 뼈는 파, 마늘을 넣고 육수를 만든다., 3. 마와 단호박은 1x1x5cm로 썬다., 4. 마늘, 아스파라거스, 영콘은 굽는다., 5. 닭에 마, 대추, 쌀, 단호박, 은행을 넣고 랩으로 감싸 만다., 6. 곁들일 단호박과 찜통에 찐다.
