# 요리명: 와인배숙

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 기타
- 열량(칼로리): 107.5 kcal
- 나트륨 함량: 16.4 mg

## 필요한 재료
배(1/2개), 사과(1/2개), 레드와인(200g),
계피(5g), 통후추(6알)

## 조리 순서
1. 배와 사과는 스쿠퍼로 동그랗게 모양을 만든다., 2. 냄비에 와인을 넣고 계피, 통후추와 함께 약불에서 끓인다., 3. 와인이 끓기 시작하면 배와 사과를 넣고 양이 반이 될 때까지 졸인다., 4. 차갑게 식힌다., 5. 4번을 용기에 담는다., 6. 졸여진 배와 사과를 과일꼬지에 꽂아 곁들인다.
