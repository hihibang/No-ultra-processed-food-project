# 요리명: 감자미역국

## 기본 정보
- 요리 분류: 국&찌개
- 조리 방식: 끓이기
- 열량(칼로리): 35.4 kcal
- 나트륨 함량: 174.6 mg

## 필요한 재료
건미역 1.5g, 감자 40g, 다진마늘 1g, 참기름 1g, 국간장 2g, 물 300ml

## 조리 순서
1. 미역을 물에 불리고 건져내 물기를 제거한다., 2. 감자는 껍질을 제거하고 한입 크기로 자른다., 3. 냄비에 참기름을 두르고 미역을 볶다가 물을 부어 끓인다., 4. 국물이 우러나면 감자를 넣고 익을 때까지 끓인다., 5. 국간장을 넣어 간을 맞춘다., 6. 다진마늘을 넣고 한소끔 더 끓여서 완성한다.
