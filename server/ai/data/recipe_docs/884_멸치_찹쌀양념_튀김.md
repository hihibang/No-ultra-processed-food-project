# 요리명: 멸치 찹쌀양념 튀김

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 튀기기
- 열량(칼로리): 212.9 kcal
- 나트륨 함량: 181.0 mg

## 필요한 재료
멸치중간것 10g, 찹쌀가루 5g, 식용유 2g, 땅콩 13g [소스소개]고추장소스:고추장 2g, 간장 0.5g, 양파즙 10g, 마늘즙 1g, 생강즙 0.5g, 맛술 5g, 설탕 3g, 물엿 3g, 식용유 2g, 참기름 0.3g, 흑임자 4g, 실파 5g

## 조리 순서
1. 멸치는 티를 골라내어 선별해 두고 실파는 썬다., 2. 팬에 식용유를 두르고 소스의 양념들을 넣어 최대한 낮은 불에서 서서히 졸여 농도를 낸다., 3. 찹쌀가루 중 1/3분량만 묽게 풀을 쑤어 식힌다., 4. 멸치에 풀을 가볍게 익히고 남은 찹쌀가루를 묻힌다., 5. 튀김기름의 온도를 170~180℃에 맞추어 4의 멸치를 재빨리 튀겨낸다., 6. 식은 후에 (2)의 소스에 버무리거나 끼얹어 낸다.
