# 요리명: 효도강정

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 끓이기
- 열량(칼로리): 370.0 kcal
- 나트륨 함량: 45.5 mg

## 필요한 재료
볶은현미 25g, 볶은율무 25g, 볶은수수 25g, 혼합견과 50g, 흑임자 10g
소스 : 올리고당 25g, 설탕 25g, 기름 10g

## 조리 순서
1. 모든 재료를 한데 섞어준다., 2. 소스를 만들어준다., 3. 준비된 틀에 비닐을 깔고 기름을 발라준다., 4. 소스가 끓어오르면 모든 재료를 넣어 버무려 준다., 5. 준비된 용기에 만들어진 재료를 쏟아 다져준다., 6. 식으면 잘라서 완성한다.
