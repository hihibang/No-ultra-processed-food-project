# 요리명: 포도청 보리 수단

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 기타
- 열량(칼로리): 88.3 kcal
- 나트륨 함량: 11.1 mg

## 필요한 재료
포도(150g), 보리(10g), 전분(30g),
녹차(티백, 1개), 설탕(10g)

## 조리 순서
1. 포도는 껍질과 씨를 제거한 뒤  설탕을 넣고 포도청을 만든다., 2. 찬물에 녹차를 우려낸다., 3. 보리를 깨끗이 씻은 뒤 푹 삶는다., 4. 삶은 보리에 전분을 묻혀 끓는 물에 삶아 건지는 것을 반복한다., 5. 포도청에 우려낸 녹차를 10:1 비율로 넣는다., 6. 보리수단을 넣는다.
