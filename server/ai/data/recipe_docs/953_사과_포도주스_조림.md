# 요리명: 사과 포도주스 조림

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 끓이기
- 열량(칼로리): 135.0 kcal
- 나트륨 함량: 25.0 mg

## 필요한 재료
사과 60g, 포도주스 60g, 계피가루 2g, 아이스크림 30g

## 조리 순서
1. 사과씨를 통째로 제거한다., 2. 1을 2cm 두께로 썬다., 3. 냄비에 사과와 포도주스를 넣고 중불에서 서서히 졸인다., 4. 졸여진 사과를 냉장고에 넣어 시원하게 한다., 5. 접시에 사과를 담고 계피가루를 뿌린다., 6. 5에 아이스크림을 떠서 위에 얹는다.
