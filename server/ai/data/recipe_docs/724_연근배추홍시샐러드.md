# 요리명: 연근배추홍시샐러드

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 171.5 kcal
- 나트륨 함량: 112.2 mg

## 필요한 재료
연근배추샐러드 : 연근 20g, 배추 20g, 사과 20g, 배 20g, 땅콩 3g, 호두 3g, 현미유 5g, 물 100g 홍시드레싱 : 홍시 30g, 호상요구르트 30g, 3배 식초 0.5g, 소금 0.3g

## 조리 순서
1. 연근은 껍질을 벗겨 0.2 cm 길이로 얇게 썰어 물 반컵에 식초를 넣은 후 10분정도 담갔다가 물기를 제거한다., 2. 배추, 사과, 배는 씻어 4~5cm 길이로 채썬다., 3. 땅콩과 호두는 칼로 굵게 다진다., 4. 연근은 팬에 현미유를 두르고 노릇노릇하게 구어 연근칩을 만든다., 5. 홍시, 호상요구르트, 3배 식초, 소금을 섞어 홍시드레싱을 만든다., 6. 그릇에 배추, 사과, 배, 연근칩, 땅콩, 호두를 넣고 버무린 뒤 홍시드레싱을 곁들인다.
