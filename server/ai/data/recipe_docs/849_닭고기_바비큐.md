# 요리명: 닭고기 바비큐

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 굽기
- 열량(칼로리): 174.7 kcal
- 나트륨 함량: 73.0 mg

## 필요한 재료
닭가슴살 60g, 홍피망 24g, 양파 30g, 노랑파프리카 24g, 양송이버섯 9g [소스소개] 소스:양파다진것 6g, 마늘다진것 1.2g, 케첩 9g, 홍토마토 12g, 설탕 3g, 물 18g<br /> 이탈리안시즈닝:타임 0.9g, 로즈마리 0.9g, 바질 1.2g, 오레가노 1.2g

## 조리 순서
1. 닭가슴살은 3cm 주사위모양으로 썰고 식용유와 이탈리안 시즈닝으로 양념한다., 2. 홍피망, 노랑파프리카, 양파는 3cm 크기로 썰고 양송이버섯은 반으로 썬다., 3. 소스 재료를 넣고 끓인다., 4. 닭가슴살은 구워서 반만 익히고 꼬치에 채소와 함께 꽂는다., 5. 그릴에서 완전히 굽는다., 6. 소스를 끼얹어 낸다.
