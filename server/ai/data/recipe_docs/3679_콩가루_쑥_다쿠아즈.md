# 요리명: 콩가루 쑥 다쿠아즈

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 기타
- 열량(칼로리): 152.8 kcal
- 나트륨 함량: 43.2 mg

## 필요한 재료
주재료 > 달걀흰자 180g, 설탕① 50g, 아몬드가루 160g, 박력 밀가루 15g,슈가파우더 40g, 콩가루 40g
쑥크림 > 생크림 150g, 설탕② 20g, 쑥가루 24g

## 조리 순서
1. 달걀흰자에 설탕①을 조금씩 넣으며, 단단한 머랭을 만든다. 아몬드가루, 박력 밀가루를 체 쳐서 머랭에 넣고 자르듯이 섞어 반죽을 만든다., 2. 오븐 팬에 테프론 시트를 깔고, 다쿠아즈 틀을 올린 후 반죽을 팬닝한다. 다쿠아즈 틀을 제거하고, 슈가파우더를 두 번에 나누어서 뿌린다., 3. 180°C로 예열한 오븐에서 15분 동안 구운 후 꺼내 식혀 다쿠아즈를 만든다., 4. 생크림에 설탕②를 넣고 휘핑하여 생크림이 약간 단단해지면 쑥가루를 섞어 쑥크림을 만든다., 5. 다쿠아즈에 쑥크림을 바르고, 다른 다쿠아즈로 덮어 샌드한다., 6. 콩가루를 골고루 뿌리고 냉장실에서 10분 동안 식혀 마무리한다.
