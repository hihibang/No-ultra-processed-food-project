# 요리명: 녹담밥

## 기본 정보
- 요리 분류: 일품
- 조리 방식: 기타
- 열량(칼로리): 498.3 kcal
- 나트륨 함량: 749.2 mg

## 필요한 재료
주재료 
녹차 300ml, 건다시마 2g, 콩나물 40g, 달래 30g,
대구살(냉동) 150g, 현미밥 210g, 가다랑어포 10g, 달걀 50g

콩나물밥 양념 
간장 6g, 다진 마늘 8g, 들기름 8g

대구살 양념 
간장 6g, 유자청 15g, 다진 마늘 12g, 들기름 12g, 물 45ml

양념 
통깨 12g, 양파가루 8g, 고춧가루 5g

## 조리 순서
1. 볼에 실온의 녹차, 건다시마를 넣어 녹차물을 만든다. 콩나물, 달래는 깨끗이 씻어 손질한다. 대구살은 한입 크기로 잘라 키친타월로 물기를 제거한다., 2. 끓는 물에 손질한 콩나물을 2분간 데친 후 물기를 제거한다. 팬에 데친 콩나물, 현미밥, 콩나물밥 양념을 넣고 볶는다. 불을 끄고 가다랑어포(5g), 손질한 달래를 잘게 잘라 넣고 섞어 콩나물밥을 만든다., 3. 볼에 대구살 양념을 모두 넣고 섞은 후 손질한 대구살을 넣고 전자레인지에서 3분간(700W 기준) 조리한다., 4. 볼에 통깨, 가다랑어포(5g), 양파가루, 고춧가루를 넣고 곱게 빻은 뒤 조리한 대구살에 뿌린다., 5. 그릇에 콩나물밥을 넣고 조리한 대구살을 올린 후 달걀지단을 만들어 고명으로 올린다., 6. 다시마를 제거한 녹차물을 따뜻하게 데워 콩나물밥에 붓고 마무리한다.
