# 요리명: 바지락가자미완탕국

## 기본 정보
- 요리 분류: 국&찌개
- 조리 방식: 끓이기
- 열량(칼로리): 126.6 kcal
- 나트륨 함량: 177.5 mg

## 필요한 재료
가자미살 40g, 두부 20g, 양파 10g, 대파 5g, 후추 1.1g, 전분 3g, 바지락 60g, 무우 40g, 마늘 2g, 쑥갓 1g, 청홍고추 0.1g, 팽이버섯 0.1g, 물 300ml

## 조리 순서
1. 가시를 제거한 가자미와 양파, 대파는 다진다., 2. ①에 으깬두부와 후추를 넣어 동그랗게 완자를 만든다., 3. 무는 나박 썰기, 청?홍고추는 어슷썰기한다., 4. 바지락은 해감 후 무와 함께 끓인다., 5. 바지락 육수에 완자를 넣어 한소끔 끊인다., 6. 마지막에 쑥갓, 청홍고추, 팽이버섯을 넣어 마무리한다.
