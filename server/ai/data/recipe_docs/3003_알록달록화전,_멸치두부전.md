# 요리명: 알록달록화전, 멸치두부전

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 147.88 kcal
- 나트륨 함량: 86.13 mg

## 필요한 재료
찹쌀가루 15g, 알비트 5g, 시금치 5g, 두부 10g, 잔멸치 5g, 식용꽃 10g, 쑥갓 10g, 부침가루 10g, 꿀 20g

## 조리 순서
1. 두부는 살짝 구워 물기를 제거하고 멸치는 설탕과 함께 볶는다., 2. 알비트, 시금치에 약간의 물을 넣고 각각 믹서에 간다., 3. 찹쌀가루를 알비트, 시금치 간 물에 반죽한다., 4. 두부를 으깨 볶은 멸치와 함께 부침가루에 넣고 반죽한다., 5. 식용꽃과 쑥갓을 씻어 물기를 제거한다., 6. 팬에 3과 4를 각각 부치고 식용꽃과 쑥갓으로 장식하고 꿀을 곁들인다.
