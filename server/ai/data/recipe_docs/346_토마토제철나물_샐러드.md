# 요리명: 토마토제철나물 샐러드

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 80.0 kcal
- 나트륨 함량: 72.3 mg

## 필요한 재료
영양부추 20g, 치커리 20g, 적양배추 50g, 알배추 30g, 방울토마토 100g, 양파70g
두부크루통 : 두부 60g, 식용유 20g
소스 : 마늘 7g, 참깨 5g, 흑임자 5g, 꿀 15g, 참기름 15g, 맛간장 45g, 레몬즙 15g, 식초 5g

## 조리 순서
1. 마늘과 흑임자 참깨를 다져서 소스를 만든다., 2. 영양부추는 5cm 길이로 잘라주고 알배추는 채 썰어 냉수에 담가둔다., 3. 방울토마토는 먹기 좋게 자르고 적양배추, 양파를 채 썬다., 4. 두부는 기름에 구워서 크루통을 만든다., 5. 준비된 채소를 물기를 빼고 접시에 담아 두부크루통을 올린 뒤 소스와 함께 셋팅한다.
