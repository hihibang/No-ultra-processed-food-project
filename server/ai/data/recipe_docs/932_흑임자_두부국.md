# 요리명: 흑임자 두부국

## 기본 정보
- 요리 분류: 국&찌개
- 조리 방식: 끓이기
- 열량(칼로리): 164.0 kcal
- 나트륨 함량: 2.0 mg

## 필요한 재료
불린 쌀 30g, 으깬 두부 35g, 검은 깨 5g, 물 90g, 소금적당량

## 조리 순서
1. 쌀을 씻어 불린 뒤 믹서나 절구에 넣고 곱게 간다., 2. 두부를 곱게 으깬다., 3. 검은깨를 물에 넣어 돌맹이가 없도록 거른다., 4. 3의 물기를 빼고 볶은 뒤 동량의 물을 넣고 곱게 간다., 5. 냄비에 쌀과 두부, 적당량의 물을 넣고 센불에서 끓인다., 6. 불을 줄여 쌀이 퍼지면 2의 검은깨를 넣고 더 끓여 소금으로 간한다.
