# 요리명: 양배추 고기말이

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 찌기
- 열량(칼로리): 162.9 kcal
- 나트륨 함량: 113.1 mg

## 필요한 재료
양배추(120g), 돼지고기(등심, 50g), 두부(50g), 시금치(30g),
달걀(1개), 마늘(10g), 소금(0.2g), 후춧가루(0.01g)

## 조리 순서
1. 돼지고기 등심은 곱게 다진다., 2. 두부는 꼭 짜서 물기를 제거하고, 시금치는 데친 후 다진다., 3. 두부와 다진 등심에 시금치, 소금, 후춧가루, 다진마늘 및 달걀을 넣고 골고루 잘 섞는다., 4. 양배추는 김이 오른 찜통에서 약 5분 정도 찐다., 5. 김발에 양배추를 넓게 편다., 6. 양배추 위에 ?을 넣고 돌돌말아 한 번 더 찐다.
