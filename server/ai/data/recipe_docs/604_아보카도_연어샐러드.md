# 요리명: 아보카도 연어샐러드

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 239.0 kcal
- 나트륨 함량: 102.1 mg

## 필요한 재료
연어(훈제연어, 120g), 양파(1/2개), 아보카도(1/2개),
파프리카(1/2개), 오렌지(1/2개), 사워크림(20g), 어린잎(20g)

## 조리 순서
1. 연어는 주사위 모양으로 썬다., 2. 양파, 파프리카도 주사위 모양으로 썬다., 3. 아보카도와 오렌지도 같은 형태로 썬다., 4. 사워크림에 다진 양파를 섞어 소스를 만든다., 5. 어린잎은 찬물에 담궈 싱싱하게 한다., 6. 원형 몰드에 연어를 넣고, 옆으로 야채와 과일을 담고 그 위에 사워크림소스와 어린잎을 올린다.
