# 요리명: 오징어튀김&딸기쨈

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 튀기기
- 열량(칼로리): 591.6 kcal
- 나트륨 함량: 135.9 mg

## 필요한 재료
오징어 35g, 밀가루 70g, 물 50g, 계란 32.5g 후추 0.1g, 식용유 500g, 딸기쨈 5g

## 조리 순서
1. 오징어를 먹기 좋은 크기로 썬다., 2. 오징어를 살짝 데친 후 물기를 제거한다., 3. 밀가루에 물, 계란, 후추를 넣어 튀김반죽을 만든다., 4. 오징어에 튀김 반죽을 묻혀 식용유에 튀긴다., 5. 키친타올에 올려 기름을 제거한다., 6. 딸기잼과 같이 곁들여 낸다.
