# 요리명: 닭고기 편육

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 굽기
- 열량(칼로리): 262.0 kcal
- 나트륨 함량: 238.0 mg

## 필요한 재료
닭고기가슴살 100g [소스소개] 밑간양념:요구르트 6g, 식용유 1g, 후춧가루 0.03g<br /> 조림장:간장 3g, 설탕 5g, 꿀 1g, 홍고추마른것 1g, 정종 5g, 참기름 0.8g, 대파 10g

## 조리 순서
1. 오븐을 175℃로 예열한다., 2. 닭고기 밑간 양념으로 30분정도 재운다., 3. 재워 놓은 닭고기를 175℃의 오븐에서 15분 굽는다., 4. 조림장을 모두 넣고 끓인다., 5. 닭고기 구운 것을 넣고 10~15분 간 졸인다., 6. 닭고기를 먹기 좋게 잘라 남은 소스를 얹어 낸다.
