# 요리명: 생선까스&타르타르소스

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 튀기기
- 열량(칼로리): 277.3 kcal
- 나트륨 함량: 201.2 mg

## 필요한 재료
•필수재료 : 명태포(40g), 튀김가루(20g), 달걀(1/4개), 식용유(5g), 물(30g)
•밑간 : 후춧가루(1g), 레몬즙(3g)
•타르타르 소스 : 삶은 달걀(1/2개), 마요네즈(5g), 홍고추(1g), 청양고추(1g), 양파(3g), 후추(2g), 레몬즙(10g)

## 조리 순서
1. 명태포는 키친타월에 올려 물기를 제거한다., 2. 후춧가루와 레몬즙을 뿌려 비린내를 제거한다., 3. 볼에 튀김가루와 달걀, 식용유, 물을 섞어 튀김옷을 만든다, 4. 명태포에 튀김옷을 입힌 뒤 170℃ 기름에서 두 번 튀긴다., 5. 삶은 달걀, 홍고추, 청양고추, 양파를 다져 볼에 섞은 뒤 마요네즈와 레몬즙, 후춧가루를 섞어 소스를 만든다, 6. 생선까스에 타르타르소스를 곁들여 담는다.
