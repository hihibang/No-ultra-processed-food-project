# 요리명: 홍합 배춧국

## 기본 정보
- 요리 분류: 국&찌개
- 조리 방식: 끓이기
- 열량(칼로리): 23.07 kcal
- 나트륨 함량: 60.48 mg

## 필요한 재료
홍합 50g, 배추 50g, 무 30g, 마늘 2g, 파 3g, 홍고추 1g, 소금 0.3g

## 조리 순서
1. 끓는 물에 한 입 크기로 썬 무를 넣는다., 2. 무가 투명해지면 배추를 넣고 끓인다., 3. 홍합을 넣는다., 4. 홍합이 입을 벌리면 마늘을 다져 넣어 조미한다., 5. 소금을 넣는다., 6. 어슷 썬 파와 홍고추를 고명으로 올린다.
