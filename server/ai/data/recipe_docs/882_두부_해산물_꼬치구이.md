# 요리명: 두부 해산물 꼬치구이

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 굽기
- 열량(칼로리): 182.6 kcal
- 나트륨 함량: 146.0 mg

## 필요한 재료
두부 100g, 소라살 16g, 패주 16g, 소금 0.2 [소스소개]마늘올리브유소스:마늘 0.2g, 올리브유 7g, 바질다진것 0.6g, 방울토마토 8g

## 조리 순서
1. 두부는 4x1.5x1cm 크기로 썬 후 소금을 뿌려 물기를 제거한다., 2. 소라살은 내장을 뺀 뒤 반으로 가르고 패주는 주위의 지저분한 막을 벗겨 깨끗이 손질한 뒤 2~3등분 한다., 3. 바질 잎은 다진다., 4. 볼에 다진 마늘을 담고 소금 간을 한 뒤 올리브유를 조금씩 넣으면서 한 방향으로 젓다가 다진 바질을 넣어 마늘 올리브유 소스를 만든다., 5. 두부와 해산물을 차례로 꼬치에 끼워 붓으로 소스를 고루 바른다., 6. 예열된 250℃ 오븐이나 그릴에서 노릇하게 구워낸다.
