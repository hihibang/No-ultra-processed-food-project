# 요리명: 쌀콩죽 요거트

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 기타
- 열량(칼로리): 166.5 kcal
- 나트륨 함량: 8.7 mg

## 필요한 재료
우유(65g), 배(60g), 고구마(35g),
요거트(3g), 쌀가루(5g), 메주콩(5g)

## 조리 순서
1. 우유에 요거트를 넣어 발효시킨다., 2. 메주콩을 3시간 정도 불린 뒤 불린 콩의 3배의 물을 넣고 삶아 믹서에 간다., 3. 쌀가루와 2번을 섞은 뒤 냄비에 끓여 쌀콩죽을 만든다., 4. 배는 껍질을 제거하고 밥솥에 푹 삶아 믹서에 간다., 5. 고구마는 삶아 껍질을 제거한다., 6. 제조한 요거트(1번)에 쌀콩죽, 배즙, 고구마를 넣고 믹서에 곱게 간다.
