# 요리명: 된장숙성저수분수육

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 찌기
- 열량(칼로리): 342.6 kcal
- 나트륨 함량: 178.0 mg

## 필요한 재료
앞다리살 돈육(보쌈용) 100g, 양파 40g, 대파 20g,저염된장 4g, 통후추 1g, 월계수잎 1g, 생강가루 2g, 다진마늘 4g

## 조리 순서
1. 돼지고기 앞다리 살에 칼집을 낸다., 2. 돼지고기에 된장, 생강가루, 다진마늘, 통후추, 월계수잎을 입혀 숙성시킨다., 3. 파와 대파는 큼지막하게 썰어 준비한다., 4. 냄비 혹은 오븐용기의 밑 부분에 양파와 대파를 놓아준다., 5. ④에 숙성시킨 돼지고기를 올려 약 50분 정도 가열하여 완전히 익혀준다., 6. 0.5cm 두께로 썰어서 제공한다.
