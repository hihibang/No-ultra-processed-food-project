# 요리명: 잡채

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 볶기
- 열량(칼로리): 197.7 kcal
- 나트륨 함량: 255.0 mg

## 필요한 재료
당면 20g, 등심얇게썬것 20g, 당근 5g, 표고버섯마른것 10g, 느타리버섯 10g, 양파 10g, 호부추 5g, 도라지 10g, 달걀 5g, 간장 2g, 설탕 5g, 마늘 1g, 대파 10g, 후춧가루 0.1g, 깨소금 1g, 참기름 2g, 식용유 1g [소스소개] 저나트륨간장소스:간장 1g, 물 2g, 설탕 1g, 식초 1g

## 조리 순서
1. 당면은 물에 불렸다가 끓는 물에 충분히 삶아 부드러워지면 차가운 물에 헹구어 물기를 뺀다., 2. 표고버섯은 불려 꼭 짜 채썬 후 간장, 들기름에 무쳐 팬에 볶는다., 3. 양배추, 오이, 당근, 깻잎, 상추, 피망, 파프리카는 곱게 채썬다., 4. 배를 강판에 간다., 5. 배와 간장, 소금, 식초, 겨자, 설탕을 넣어 잡채 양념을 만든다., 6. 큰 접시에 준비된 채소를 예쁘게 돌려 담고 가운데 당면을 놓은 후 양념을 부어준다.
