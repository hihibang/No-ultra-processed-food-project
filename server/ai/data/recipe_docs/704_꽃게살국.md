# 요리명: 꽃게살국

## 기본 정보
- 요리 분류: 국&찌개
- 조리 방식: 끓이기
- 열량(칼로리): 114.0 kcal
- 나트륨 함량: 579.9 mg

## 필요한 재료
꽃게 70g(꽃게살 30g), 양배추 20g, 토마토 20g, 된장 6g, 파 5g, 건다시마 3g, 다진 마늘 2.5g, 물 200g

## 조리 순서
1. 꽃게는 손질하여 먹기 좋은 크기로 자른다., 2. 물 1컵에 건다시마와 꽃게를 넣고 끓여 육수 ⅔컵을 만든다., 3. 양배추와 토마토는 씻어 1cm×1cm 크기로 썬다., 4. 파는 씻어 어슷썰기 한다., 5. 육수 낸 꽃게는 건져 살을 발라낸다., 6. 육수에 된장을 풀고 양배추와 토마토를 넣고 한소끔 끓인 후 발라놓은 꽃게 살과 파, 다진 마늘을 넣어 완성한다.
