# 요리명: 달콤과일깍두기

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 19.9 kcal
- 나트륨 함량: 19.8 mg

## 필요한 재료
•필수 재료 : 무(20g), 배(10g), 참외(10g), 마늘(1g), 새우젓(0.5g), 생강(0.5g), 실파(1g)
•양념 : 고춧가루(1g), 통깨(0.5g)

## 조리 순서
1. 배와 참외는 1~1.5cm 크기로 깍둑 썬다., 2. 무는 1~1.5cm 크기로 깍둑 썬다., 3. 실파는 1cm 길이로 썬다., 4. 새우젓, 마늘, 생강은 곱게 다진다., 5. 고춧가루, 새우젓, 마늘, 생강, 통깨를 버무려 양념장을 만든다., 6. 배, 참외, 무, 실파에 양념장을 넣어 버무린다.
