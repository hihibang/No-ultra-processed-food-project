# 요리명: 고구마 바나나 무스

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 기타
- 열량(칼로리): 211.2 kcal
- 나트륨 함량: 24.7 mg

## 필요한 재료
고구마(50g), 바나나(17g), 달걀(1개),
크림치즈(10g), 우유(20g), 생크림(25g),
딸기잼(15g), 젤라틴(8g), 바닐라빈(1g),
올리고당(2g)

## 조리 순서
1. 삶아 으깬 고구마와 으깬 바나나를 섞는다., 2. 볼에 달걀노른자, 올리고당, 우유, 바닐라빈을 넣고 중탕시켜 걸쭉하게 만든 뒤 1번과 섞는다., 3. 2번에 휘핑한 생크림을 넣고 섞은 뒤 젤라틴을 넣는다., 4. 딸기잼에 우유를 넣고 끓여 젤리를 만든다., 5. 무스 틀에 3번과 딸기잼 젤리를 차곡차곡 넣어 굳힌다., 6. 굳힌 무스위에 크림치즈를 올린다.
