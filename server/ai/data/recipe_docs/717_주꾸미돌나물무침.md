# 요리명: 주꾸미돌나물무침

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 69.6 kcal
- 나트륨 함량: 350.1 mg

## 필요한 재료
주꾸미 50g, 돌나물 15g, 오이 10g, 노랑파프리카 5g, 빨강파프리카 5g, 양파 5g 고추장 9g, 식초 6g, 매실액 5g, 다진 파 5g, 다진 마늘 2.5g, 통깨 1g, 고춧가루 1g

## 조리 순서
1. 돌나물은 먹기 좋은 크기로 자른다., 2. 오이와 파프리카는 4~5cm 가량의 크기로 채 썬다., 3. 주꾸미는 끓는 물에 데친다., 4. 데친 주꾸미 4~5cm 가량의 크기로 썬다., 5. 고추장, 식초, 매실액, 파, 마늘, 통깨, 고춧가루를 넣고 고추장양념을 만든다., 6. 접시에 1,2,4를 담고 5의 고추장양념을 곁들인다.
