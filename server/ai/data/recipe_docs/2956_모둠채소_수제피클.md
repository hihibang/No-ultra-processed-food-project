# 요리명: 모둠채소 수제피클

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 24.3 kcal
- 나트륨 함량: 1.5 mg

## 필요한 재료
•필수 재료 : 오이(20g), 파프리카(20g), 적양배추(20g)
•피클물 : 설탕(15g), 식초(15g), 피클링스파이스(5g), 물(15g)

## 조리 순서
1. 오이와 파프리카, 적양배추는 한 입 크기로 썬다., 2. 냄비에 물과 피클물 재료를 넣어 끓인다., 3. 다른 냄비에 물을 끓여, 피클을 담을 용기를 넣어 소독한다., 4. 소독한 용기를 잘 말린 뒤 손질한 채소를 담는다., 5. 피클물이 끓으면 식힌 뒤 용기에 붓는다., 6. 피클을 30분간 숙성해 마무리한다.
