# 요리명: 닭고기 찰깨빵

## 기본 정보
- 요리 분류: 일품
- 조리 방식: 기타
- 열량(칼로리): 500.6 kcal
- 나트륨 함량: 852.1 mg

## 필요한 재료
방울토마토(60g), 양파(70g), 파프리카(120g), 할라피뇨(10g), 훈제 닭가슴살(40g), 찰깨빵(45g), 모차렐라치즈(30g), 파슬리가루(약간), 설탕(1g), 소금(0.5g), 레몬즙(15㎖), 후춧가루(0.5g)

## 조리 순서
1. 방울토마토, 양파, 파프리카, 할라피뇨, 훈제 닭가슴살은 작게 깍둑썬다., 2. 손질한 재료에 양념을 고루 섞는다., 3. 찰깨빵의 윗부분 1cm를 도려낸다., 4. 빵 안에 버무린 재료를 채운 뒤 모차렐라치즈를 올린다., 5. 180℃로 예열한 오븐에 속을 채운 빵을 넣고 5분간 구워 꺼낸다., 6. 그릇에 구운 빵을 올린 뒤 파슬리가루를 뿌린다.
