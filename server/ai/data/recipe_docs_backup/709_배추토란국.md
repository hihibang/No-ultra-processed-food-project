# 요리명: 배추토란국

## 기본 정보
- 요리 분류: 국&찌개
- 조리 방식: 끓이기
- 열량(칼로리): 77.7 kcal
- 나트륨 함량: 564.9 mg

## 필요한 재료
토란 50g, 쇠고기 양지 15g, 배추 10g, 대파 2.5g 다진 마늘 1.25g, 고춧가루 1.7g, 된장 9g, 물 180g, 참기름 1g

## 조리 순서
1. 토란은 감자칼로 껍질을 벗겨 3~4 등분한다., 2. 소고기와 배추는 5mm 너비로 썰고 대파는 어슷 썬다., 3. 토란을 연한 소금물(물 1컵 + 소금 1g)에 담근다., 4. 참기름에 소고기와 다진 마늘을 볶다가 향이 우러나면 고춧가루를 넣고 잠시 더 볶는다., 5. 볶은 고기에 물을 붓고 된장을 풀어 넣는다., 6. 국물이 끓으면 배추, 토란, 대파를 넣고 한소끔 끓인다.
