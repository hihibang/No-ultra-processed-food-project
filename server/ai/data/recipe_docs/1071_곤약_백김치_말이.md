# 요리명: 곤약 백김치 말이

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 44.2 kcal
- 나트륨 함량: 2.7 mg

## 필요한 재료
오징어(30g), 곤약(100g), 백김치(50g),
삼색파프리카(20g), 부추(10g), 청주(15g),
통후추(5알), 월계수잎(1장)

## 조리 순서
1. 곤약은 얇게 편으로 썰어 데친 뒤 백김치 국물에 절인다., 2. 물에 월계수잎, 통후추, 청주를 넣고 오징어를 질기지 않게 살짝 삶는다., 3. 파프리카는 채썰고 백김치는 물기를 제거한다., 4. 곤약을 깔고 백김치, 오징어, 파프리카를 얹어 말아준다., 5. 부추로 풀어지지 않게 단단히 매듭을 짓는다., 6. 아랫부분을 정리하고 접시에 담는다.
