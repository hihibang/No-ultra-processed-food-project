# 요리명: 영양밥

## 기본 정보
- 요리 분류: 밥
- 조리 방식: 끓이기
- 열량(칼로리): 321.5 kcal
- 나트륨 함량: 102.0 mg

## 필요한 재료
쌀 30g, 현미찹쌀 30g, 표고버섯 30g, 당근 30g, 대추 7.5g, 은행 3g, 밤 12g, 다시마 육수 20g [소스소개]저나트륨 간장양념장:간장 1g, 사과쥬스 4g, 겨자 0.5g, 참기름 3g, 깨소금 1g, 청고추 1g, 홍고추 1g

## 조리 순서
1. 쌀과 현미찹쌀을 씻어 불린다., 2. 표고버섯, 당근은 은행크기로 썬다, 3. 대추도 돌려깍아 은행크기로 썬다., 4. 1에 표고버섯, 당근, 대추와 은행, 밤을 고루 섞어 솥에 담는다., 5. 다시마 육수를 평상시 밥물보다 적게 넣고 밥을 짓는다., 6. 밥이 뜸이 들면 간장양념과 함께 제공한다.
