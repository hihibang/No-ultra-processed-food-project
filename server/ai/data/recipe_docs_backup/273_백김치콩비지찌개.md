# 요리명: 백김치콩비지찌개

## 기본 정보
- 요리 분류: 국&찌개
- 조리 방식: 끓이기
- 열량(칼로리): 195.3 kcal
- 나트륨 함량: 447.2 mg

## 필요한 재료
재료 풋고추(10g), 백김치(100g), 콩비지(100g)
양념 참기름(8g), 후춧가루(0.2g), 다진 마늘(10g), 간장(2g)

## 조리 순서
1. 풋고추는 잘게 다진다., 2. 백김치는 먹기 좋은 크기로 썬다., 3. 냄비에 백김치를 볶다가 김치가 익으면 참기름, 후춧가루, 다진 마늘을 넣고 볶는다., 4. 물(200g)을 넣고 끓인다., 5. 물이 끓으면 콩비지와 간장, 풋고추를 넣어 약한 불에서 15분 정도 끓여 마무리한다.
