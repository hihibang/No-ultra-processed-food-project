# 요리명: 검은콩 스프

## 기본 정보
- 요리 분류: 일품
- 조리 방식: 굽기
- 열량(칼로리): 220.1 kcal
- 나트륨 함량: 117.0 mg

## 필요한 재료
콩 30g, 닭육수 70g, 토마토 30g, 큐민파우더 1g, 파슬리말린것 1g, 카엔패퍼 2g, 사워크림 2g, 두유 70g, 식용유 4g, 양파다진것 7g, 샐러리 3g, 마늘 1g

## 조리 순서
1. 양파, 셀러리, 마늘, 토마토를 굵게 다진다., 2. 팬에 양파를 볶다가 셀러리와 마늘을 볶는다., 3. 콩과 두유를 넣은 뒤 토마토, 육수, 큐민, 파슬리, 카엔패퍼를 넣는다., 4. 볶은 재료들을 모두 믹서로 간다., 5. 믹서에 간 재료들을 체에 거른다., 6. 체에 거른 것을 끓여주고 사워크림으로 장식한다
