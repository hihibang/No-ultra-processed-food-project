# 요리명: 아욱 된장무침

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 11.26 kcal
- 나트륨 함량: 142.6 mg

## 필요한 재료
아욱 200g, 된장 15g, 마늘 10g, 저염간장 5g, 참기름 2g, 참깨 1g, 소금 2g

## 조리 순서
1. 아욱 줄기 끝부분을 꺽어 손질한다., 2. 손질한 아욱을 소금을 약간 넣은 물에 넣어 치대듯이 주무른다., 3. 끓는 물에 아욱을 삶은 뒤 찬물에 헹궈 물기를 짠다., 4. 아욱을 먹기 좋은 크기로 썬다., 5. 마늘을 곱게 다진다., 6. 아욱에 된장, 다진마늘, 참기름, 저염간장, 깨를 넣고 버무린다.
