# 요리명: 오리들깨 겨자소스 초무침

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 179.7 kcal
- 나트륨 함량: 45.2 mg

## 필요한 재료
1인분 기준<br>
[주재료]오리고기(90g), 양파(10g), 당근(10g), 오이(10g)<br>
[양념]들깻가루(8g), 겨잣가루(4g), 식초(10g), 레몬즙(5g), 물(15ml)

## 조리 순서
1. 달군 팬에 오리고기를 넣고 센 불에서 볶는다., 2. 들깻가루, 겨잣가루, 식초, 레몬즙, 물을 섞어 양념장을 만든다., 3. 양파, 당근, 오이는 채 썬다., 4. 볶은 오리고기는 한 김 식힌다., 5. 볼에 오리고기, 손질한 채소, 양념장을 넣고 버무린다., 6. 접시에 담아 마무리한다.
