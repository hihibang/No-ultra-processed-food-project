# 요리명: 초코바나나 두부크림빵

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 기타
- 열량(칼로리): 246.5 kcal
- 나트륨 함량: 138.1 mg

## 필요한 재료
주재료 > 박력 쌀가루 56g, 강력 밀가루 140g, 무가당 코코아가루① 8g, 드라이 이스트 16g, 소금 4g, 설탕 8g, 물 115ml, 바닐라 에센스 30g, 달걀 16g, 무염버터 22g
두부크림 > 바나나 98g, 두부 33g, 무가당 코코아가루② 12g, 알룰로스 30g
부재료 > 달걀물 약간, 무염버터 약간

## 조리 순서
1. 볼에 박력 쌀가루, 강력 밀가루, 무가당 코코아가루①, 드라이 이스트, 소금, 설탕, 물, 바닐라 에센스, 달걀을 넣고 섞다가 무염버터를 넣으며 한 덩어리가 될 때까지 반죽한 후 상온에서 30분 동안 1차 발효한다., 2. 믹서에 바나나, 물기를 제거한 두부, 무가당 코코아가루②, 알룰로스를 넣고 큰 덩어리가 없어질 정도로 살짝 갈아 두부크림을 만든다., 3. 반죽을 40g씩 분할하여 둥굴리기한 후 상온에서 15분 동안 중간 발효한다., 4. 반죽을 성형하여 오븐 팬에 올리고 30°C에서 20분 동안 2차 발효한다., 5. 달걀물을 바르고 175°C로 예열한 오븐에 12분 동안 구운 후 꺼내 완전히 식힌다., 6. 두부크림을 짤주머니에 담아 40g씩 빵 속에 채우고 무염버터를 발라 마무리한다.
