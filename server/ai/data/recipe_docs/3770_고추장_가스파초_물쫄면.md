# 요리명: 고추장 가스파초 물쫄면

## 기본 정보
- 요리 분류: 일품
- 조리 방식: 기타
- 열량(칼로리): 652.6 kcal
- 나트륨 함량: 332.1 mg

## 필요한 재료
주재료 
양배추 30g, 양파 150g, 오이 20g, 토마토 250g,
빨간 파프리카 60g, 청양고추 4g, 닭가슴살 40g, 바질 5장(2g),
다진 마늘 4g, 빵가루 20g, 쫄면 사리 100g

양념 
올리브유 30g, 화이트와인식초 20g, 고추장 5g, 소금 0.5g,
식용유 5g, 후춧가루 0.3g, 참기름 10g

## 조리 순서
1. 양배추와 양파는 채 썰고, 오이는 어슷하게 썬다. 토마토, 빨간 파프리카, 청양고추는 한입 크기로 썬다. 닭가슴살은 칼로 기름기를 제거하고 키친타월로 물기를 제거한다., 2. 믹서에 손질한 토마토, 빨간 파프리카, 청양고추, 양파(50g), 바질(4장), 다진 마늘, 올리브유(20g), 화이트와인식초, 고추장, 소금을 넣고 곱게 갈아 가스파초 소스를 만든다., 3. 올리브유(10g)를 두른 팬에 빵가루를 넣어 바삭하게 볶아 꺼내고, 같은 팬에 식용유를 두르고 손질한 양파(100g)를 넣어 갈색이 나도록 볶는다., 4. 냄비에 손질한 닭가슴살을 넣고 잠길 만큼 물을 부어 센 불에서 삶는다. 닭가슴살이 익으면 식힌 후 곱게 찢어 후춧가루, 참기름으로 간한다., 5. 끓는 물에 쫄면 사리를 넣고 삶아 찬물에 헹궈 식힌다., 6. 그릇에 쫄면 사리를 담고 가스파초 소스를 뿌린다. 손질한 양배추, 오이, 닭가슴살, 볶은 빵가루, 볶은 양파, 바질(1장)을 올려 마무리한다.
