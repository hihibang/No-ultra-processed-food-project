# 요리명: 코울슬로샐러드

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 44.1 kcal
- 나트륨 함량: 26.8 mg

## 필요한 재료
•필수 재료 : 양배추(30g), 양파(10g), 적파프리카(3g), 청피망(3g)
•마요네즈드레싱 : 마요네즈(5g), 설탕(1g), 식초(0.5g)

## 조리 순서
1. 양배추와 양파, 적파프리카, 청피망을 깨끗이 씻는다., 2. 양배추와 양파를 잘게 썬다., 3. 적파프리카와 청피망은 씨를 제거하고 잘게 썬다., 4. 마요네즈드레싱 재료를 고루 섞는다., 5. 볼에 썰어둔 채소를 담는다., 6. 마요네즈드레싱을 넣고 버무려 마무리한다.
