# 요리명: 유부 달걀찜

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 찌기
- 열량(칼로리): 87.0 kcal
- 나트륨 함량: 209.0 mg

## 필요한 재료
유부 8g, 달걀 30g, 당근 7g, 멸치 육수 50g, 간장 3g, 설탕 2g, 소금적당량

## 조리 순서
1. 유부는 윗면을 잘라 내고 입을 벌려서 주머니를 만든다., 2. 1을 끓는 물에 데친 뒤 냉수에 헹군다., 3. 달걀을 그릇에 풀고 다진 당근과 소금을 넣고 섞는다., 4. 2에 3을 넣어 꼬지로 주름을 잡아 끝부분을 마무리한다., 5. 냄비에 멸치 육수와 간장, 설탕, 소금을 넣는다., 6. 5에 4를 넣어 10분정도 끓인다.
