# 요리명: 사과비트에이드

## 기본 정보
- 요리 분류: 후식
- 조리 방식: 기타
- 열량(칼로리): 30.4 kcal
- 나트륨 함량: 5.2 mg

## 필요한 재료
사과(60g), 비트(2g), 레몬즙(0.5g),
탄산수(100g)

## 조리 순서
1. 사과(55g)와 비트는 깨끗하게 손질한 뒤 적당한 크기로 썬다., 2. 나머지 사과는 0.5cm 주사위 모양으로 자르고 물에 담근다., 3. 믹서에 1번을 넣고 간다., 4. 냄비에 물기를 제거한 2번과 레몬즙을 넣고 졸인다., 5. 냄비에 3번을 넣고 졸인다., 6. 유리컵에 4,5번을 넣고 탄산수를 부어 완성한다.
