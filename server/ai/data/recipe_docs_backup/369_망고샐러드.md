# 요리명: 망고샐러드

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 105.7 kcal
- 나트륨 함량: 50.3 mg

## 필요한 재료
증편 200g, 망고 150g, 양상추 30g, 치커리 20g, 방울토마토 60g, 양파 60g
소스 : 올리브오일 30g, 유자청 15g, 식초 15g, 볶은소금 2g, 후추 1g, 다진 파프리카(노랑) 15g
다진 청피망 15g, 다진 홍피망 15g, 통깨 5g

## 조리 순서
1. 증편은 팬에 구워준다., 2. 망고와 방울토마토는 먹기 좋게 잘라준다., 3. 모든 채소는 먹기 좋게 잘라서 물에 담근다., 4. 소스 재료를 섞어 소스를 만들고, 접시에 준비된 채소를 담고 소스를 뿌려준 후 구운 떡과 망고 를 올려 완성한다.
