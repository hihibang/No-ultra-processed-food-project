# 요리명: 카카오 깜빠뉴

## 기본 정보
- 요리 분류: 기타
- 조리 방식: 기타
- 열량(칼로리): 304.0 kcal
- 나트륨 함량: 11.22 mg

## 필요한 재료
(반죽재료) 강력분 500g, 소금 8g, 코코아 30g, 버터 38g, 생이스트 8g, 드라이이스트(레드) 4g, 파트 페레멘테 95g, 우유 114ml, 물 236g 

(속재료) 카카오 닙스 94g, 호두 94g, 건포도 150g

## 조리 순서
1. 버터를 제외한 모든 재료를 넣어 반죽하다가 버터를 넣어 최종까지 믹스한다. 믹스된 반죽에 속재료를 넣어 골고루 섞는다., 2. 1차 발효 30분 후 punch 후 35분 발효 시킨다. ★punch는 가스를 빼는 과정을 얘기해요., 3. 200g 분할 후 중간발효 20분을 한다., 4. 중간 발효된 반죽은 둥글게 성형한다., 5. 스프레이를 뿌린 후 덧가루를 묻혀 50분 동안 2차 발효 한다., 6. X모양 칼집을 주고 195℃ 12분 스팀 5초로 설정하여 굽는다. ★칼집은 날이 얇은 면도칼 등을 이용하면 좋아요.
