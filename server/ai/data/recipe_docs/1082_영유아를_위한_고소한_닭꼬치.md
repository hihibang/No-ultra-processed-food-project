# 요리명: 영유아를 위한 고소한 닭꼬치

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 굽기
- 열량(칼로리): 324.0 kcal
- 나트륨 함량: 1.3 mg

## 필요한 재료
닭고기(가슴살, 25g), 우유(10g),
아몬드슬라이스(10g), 참깨(2g),
흑임자(1g), 소금(0.1g), 후춧가루(0.1g)

## 조리 순서
1. 닭가슴살은 10cm 길이로 얇게 자른다., 2. 닭가슴살에 소금, 후춧가루로 밑간을 한다., 3. 아몬드슬라이스를 잘게 다지고 흑임자, 참깨와 섞는다., 4. 닭가슴살에 3번을 묻힌다., 5. 팬에 식용유를 두르고 4번을  노릇하게 굽는다., 6. 꼬지에 꽂는다.
