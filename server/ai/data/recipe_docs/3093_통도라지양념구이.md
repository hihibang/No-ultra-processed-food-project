# 요리명: 통도라지양념구이

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 굽기
- 열량(칼로리): 84.8 kcal
- 나트륨 함량: 263.9 mg

## 필요한 재료
통도라지 80g, 배 5g, 다진마늘 3g, 골파 15g, 통깨 3g, 고추장 10g, 간장 7.5g, 참기름 15g, 소금(쓴맛 제거용) 5g

## 조리 순서
1. 통도라지는 세척 후 껍질을 제거한다., 2. 통도라지를 소금물에 담궈 쓴맛을 우려낸 후 물기를 없앤다., 3. 통도라지를 반으로 갈라서 방망이로 두들겨 얇고 넓적하게 만든다., 4. 갈은 배, 다진 마늘, 고추장, 간장, 참기름을 이용하여 양념장을 만든다., 5. 팬에 도라지를 구워 익히다가, 양념장을 발라 약한불에서 다시 굽는다., 6. 골파와 통깨를 뿌려 완성한다.
