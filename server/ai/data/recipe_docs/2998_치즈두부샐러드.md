# 요리명: 치즈두부샐러드

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 104.06 kcal
- 나트륨 함량: 101.08 mg

## 필요한 재료
까망베르치즈 8g, 두부 25g, 새싹채소 5g, 아몬드슬라이스 1g, 유자청 6g, 식초 1g, 레몬즙 2g, 올리브유 3g, 저염간장 2g

## 조리 순서
1. 유자청을 잘게 다진 뒤 저염간장, 식초, 올리브유, 레몬즙을 섞어 드레싱을 만든다., 2. 두부는 2cm 크기로 깍둑썰기 한다., 3. 까망베르치즈도 깍둑썰기 한다., 4. 새싹채소는 세척 후 건져 물기를 제거한다., 5. 그릇에 새싹채소를 담고 두부, 치즈를 얹는다., 6. 드레싱과 아몬드를 뿌린다.
