# 요리명: 곤드레야 순두부 아란치니

## 기본 정보
- 요리 분류: 일품
- 조리 방식: 튀기기
- 열량(칼로리): 733.9 kcal
- 나트륨 함량: 406.5 mg

## 필요한 재료
주재료 
다진 돼지고기 100g, 순두부 100g, 건곤드레나물 15g,
현미밥 200g, 다진 마늘 35g, 감자전분 50g, 밀가루 50g, 달걀 50g,
빵가루 50g, 대파 30g, 참외 50g

양념 
참기름 30g, 올리브유 50g, 레몬즙 30g, 후추 5g, 쌈장 15g,
알룰로스 30g, 식용유 200g, 간장 5g, 전분물 60g(전분 30g + 물 30ml)

## 조리 순서
1. 다진 돼지고기는 키친타월로 핏물을 제거하고 순두부는 물기를 제거한다. 건곤드레나물은 물에 12시간 정도 불린다., 2. 불린 곤드레나물을 잘게 다진다. 팬에 손질한 곤드레나물, 참기름(15g), 다진 마늘(15g)을 넣고 볶은 후 식힌다. 따뜻한 현미밥, 볶은 곤드레나물을 섞어 곤드레나물밥을 만든다., 3. 믹서에 감자전분, 올리브유, 레몬즙, 물기를 제거한 순두부를 넣고 섞은 후, 팬에 넣고 약한 불로 볶은 후 식힌다., 4. 다른 팬에 식용유(20g), 다진 돼지고기, 다진 마늘(15g), 후추(4g), 쌈장, 알룰로스를 넣어 볶은 후 식힌다., 5. 볶은 순두부에 볶은 돼지고기를 넣어 감싸준 후, 곤드레나물밥에 넣어 동그랗게 만든다. 밀가루, 달걀, 빵가루를 차례로 묻힌 후 180℃로 예열한 식용유(180g)에 넣어 1분간 튀겨 아란치니를 만든다., 6. 팬에 간장, 참기름(15g), 다진 마늘(5g), 후추(1g), 다진 파를 넣고 끓이다 전분물을 넣어 농도를 맞춰 소스를 만든다. 그릇에 아란치니를 담고 소스를 뿌린 후, 얇게 썬 참외를 올려 마무리한다.
