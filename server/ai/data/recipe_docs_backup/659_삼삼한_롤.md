# 요리명: 삼삼한 롤

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 323.6 kcal
- 나트륨 함량: 189.8 mg

## 필요한 재료
연어(훈제연어, 120g), 양파(30g), 아보카도(1/4개), 당근(30g),
감자(50g), 새송이버섯(1개), 레몬(1/4개), 사워크림(50g),
소금(0.2g)

## 조리 순서
1. 훈제연어는 길게 손질한다, 2. 아보카도는 길게 채 썬다., 3. 양파, 당근, 새송이버섯도 길게 채 썬다., 4. 감자는 삶아 체에 내려 소금과 사워크림을 넣고 잘 섞어서 틀에 담는다., 5. 팬에 양파, 당근, 새송이버섯을 각각 볶는다., 6. 사워크림과 레몬즙을 섞어 소스를 만들고 훈제 연어에 준비된 야채를 넣고 돌돌 말아 먹기 좋게 썰어 접시에 담고, 한쪽에 감자를 담은 뒤 사워소스를 올린다.
