# 요리명: 우엉들깨무침

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 22.3 kcal
- 나트륨 함량: 94.2 mg

## 필요한 재료
•필수재료 : 우엉(25g), 파(2g), 물(300g)
•양념 : 들깻가루(2g), 다진마늘(2g), 들기름(1g), 간장(3g)

## 조리 순서
1. 우엉은 껍질을 벗긴다., 2. 껍질을 벗긴 우엉은 4cm 길이로 가늘게 채 썬다., 3. 냄비에 물과 우엉을 넣어 3~5분간 삶는다., 4. 삶은 우엉을 체에 건진다., 5. 파를 어슷 썬다., 6. 삶은 우엉, 손질한 파, 양념 재료를 넣고 골고루 무쳐 마무리한다.
