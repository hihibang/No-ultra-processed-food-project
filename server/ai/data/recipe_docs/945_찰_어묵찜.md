# 요리명: 찰 어묵찜

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 찌기
- 열량(칼로리): 103.0 kcal
- 나트륨 함량: 397.0 mg

## 필요한 재료
찰어묵 50g, 새우살 20g, 전분 5g 양념 마늘다진것 2g, 참기름 1g, 깨소금 1g, 청주 1g, 소금적당량, 후추 적당량

## 조리 순서
1. 찰어묵을 2cm 두께로 썬 후 가운데 칼집을 넣는다., 2. 새우살을 입자있게 다진다., 3. 2에 양념재료를 넣고 잘 버무린다, 4. 찰어묵의 칼집 사이에 전분을 묻힌다., 5. 칼집 사이에 3를 끼워 넣는다., 6. 김이 오른 찜통에 10분간 찐다.
