# 요리명: 참치 쇠고기 양상추 쌈

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 굽기
- 열량(칼로리): 181.0 kcal
- 나트륨 함량: 313.0 mg

## 필요한 재료
쇠고기 25g, 밥 60g, 상추 5g, 캔참치 5g[밑간] 후추약간, 달걀흰자 10g, 간장 3g, 설탕 2g, 전분 2g[참치양념] 마요네즈 3g, 양파다진것 3g, 샐러리다진것 2g, 소금적당량, 설탕 적당량, 후춧가루 적당량

## 조리 순서
1. 소고기는 소금, 후추로 밑간을 하고 실파는 송송 썬다., 2. 참치는 기름을 제거하고 양파, 셀러리, 마요네즈, 소금, 후추, 설탕을 넣고 양념한다., 3. 상추는 작게 다듬어 얼음물에 담근다., 4. 팬에 기름을 두르고 다진 마늘을 넣고 볶다가 밑간한 소고기를 넣고 볶는다., 5. 4에 기호에 맞게 참기름과 실파를 넣는다., 6. 물기를 제거한 상추에 밥 한 숟가락을 놓고 볶은 소고기, 참치, 마요네즈, 소스 순으로 얹는다.
