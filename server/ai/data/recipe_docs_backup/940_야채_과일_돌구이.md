# 요리명: 야채 과일 돌구이

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 굽기
- 열량(칼로리): 71.0 kcal
- 나트륨 함량: 5.0 mg

## 필요한 재료
단호박 30g, 고구마 30g, 오렌지 30g, 소금적당량

## 조리 순서
1. 냄비 전체에 작은 돌을 깔고 돌이 뜨거워질 때까지 불에 올려놓는다., 2. 단호박, 고구마, 오렌지를 0.5cm 두께로 자른다., 3. 2의 표면에 소금을 살짝 뿌린다., 4. 뜨거워진 돌 위에 3을 올린다., 5. 뚜껑을 닫고 약한 불에서 속이 익을 때 까지 굽는다., 6. 소금, 된장소스, 참깨소스 등 취향에 맞는 소스를 골라 찍어 먹는다.
