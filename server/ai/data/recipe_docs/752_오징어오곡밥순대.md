# 요리명: 오징어오곡밥순대

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 찌기
- 열량(칼로리): 105.0 kcal
- 나트륨 함량: 617.2 mg

## 필요한 재료
주재료: 오징어 30, 오곡밥 30, 데친 취나물 10, 간장 3, 다진 마늘 2.5, 후추 0.01, 참기름 1 소스: 데쳐서 다진 취나물 5, 청양고추 2, 간장 1.5, 참기름 1, 설탕 1, 다진 마늘 1, 된장 0.75

## 조리 순서
1. 오징어는 다리를 떼 내서 내장과 눈을 제거하고, 데친 취나물은 물기를 짜내고 다진다., 2. 오곡밥에 다진 취나물, 간장, 마늘, 후추, 참기름을 넣어 고루 섞는다., 3. 오징어 몸통에 양념한 밥을 넣어 이쑤시개로 끝을 고정시킨다., 4. 김이 오른 찜통에 오징어를 넣고 3분간 쪄낸다., 5. 소스 재료를 섞어 취나물된장소스를 만든다., 6. 쪄낸 오징어순대를 썰어 접시에 담고 소스를 곁들여 낸다.
