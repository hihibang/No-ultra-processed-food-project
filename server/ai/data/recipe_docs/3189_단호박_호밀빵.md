# 요리명: 단호박 호밀빵

## 기본 정보
- 요리 분류: 기타
- 조리 방식: 기타
- 열량(칼로리): 271.0 kcal
- 나트륨 함량: 1.83 mg

## 필요한 재료
(반죽재료) 통밀가루 200g, 강력분 200g, 전립분 40g, 소금 15g, 드라이이스트 5g, 물 150ml, 베이킹파우더 10g
(속재료) 단호박 20g, 참깨 10g

## 조리 순서
1. (속재료) 단호박은 쪄서 먹기 좋은 크기로 썰어둔다., 2. 통밀가루와 강력분, 전립분, 물, 소금을 섞어 5℃에서 반나절동안 1차 발효를 시킨다., 3. 반죽을 썰어 모양을 잡고, 중간발효를 15분동안 한다., 4. 반죽 가운데에 썰은 단호박과 참깨를 넣고 가볍게 접어서 말아 면포에 올린다., 5. 굽기 전에 쿠프(칼집내기)를 한다., 6. 230℃ 로 예열한 오븐에 넣고 스팀 후 210℃에서 25분 굽는다.
