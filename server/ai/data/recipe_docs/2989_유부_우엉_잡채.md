# 요리명: 유부 우엉 잡채

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 40.71 kcal
- 나트륨 함량: 128.73 mg

## 필요한 재료
우엉 20g, 유부 6g, 양파 10g, 당근 10g, 올리브유 5g, 올리고당 6g, 간장 5g, 설탕 0.5g, 참깨 0.5g, 참기름 1g

## 조리 순서
1. 우엉을 깨끗이 씻어 채 썬다., 2. 양파와 당근을 채 썬다., 3. 간장과 양념들을 넣고 채 썬 우엉을 졸인다., 4. 3이 80% 정도 졸았을 대 채 썬 양파와 당근을 넣는다., 5. 거의 다 졸여지면 채 썬 유부를 넣는다., 6. 참깨를 뿌려 마무리한다.
