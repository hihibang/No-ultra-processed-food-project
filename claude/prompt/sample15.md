4개 수정사항 중 '4. 인플루언서 페이지 분리' 기능을 구현해줘.
현재는 인플루언서 관련 기능/요소가 메인 페이지에 섞여 있어 화면이 산만하고 독립된 탐색 경험이 부족해.
메인 페이지에서 인플루언서 요소를 정리/분리하고, 독립된 `/influencers` 전용 페이지를 구축해줘.

### 1. 프론트엔드 라우팅 및 메인 페이지 정리
- `/influencers` 전용 라우트를 추가하고, 상단 내비게이션(헤더)에 `인플루언서` 메뉴를 추가해 `/influencers`로 이동할 수 있게 해줘.
- 메인 페이지(홈)에 인플루언서 관련 카드나 섹션이 과하게 섞여 있다면 메인 화면의 깔끔함을 위해 축소하거나 `/influencers` 페이지로 유도하는 링크/배너 수준으로 정돈해줘.

### 2. `/influencers` 전용 페이지 구성
- **인플루언서 프로필 목록 및 찜하기(팔로우):** 클린 식단·건강 레시피 크리에이터 목록을 보여주고, 인플루언서 찜하기/해제 토글(기존 찜 API 또는 관련 상태 연동)을 지원해줘.
- **인플루언서 레시피 & 추천/공구 상품 모아보기:** 선택한 인플루언서(또는 전체 인플루언서 탭)의 검증된 레시피와 연관/추천 상품을 함께 볼 수 있게 구성해줘.
- **팬덤 CF 기반 추천 영역:** 내가 찜한 인플루언서 또는 나와 비슷한 유저들이 찜한 인플루언서/레시피·상품을 모아 보여주는 영역을 포함해줘. (데이터가 적거나 없는 경우에도 에러 없이 빈 상태 안내 또는 숨김으로 자연스럽게 처리해줘.)

### 3. 백엔드 API 확인 및 연결
- 기존 인플루언서 목록, 인플루언서 찜 토글, 인플루언서 레시피/상품 조회 엔드포인트가 있는지 확인하고, 프론트엔드 `/influencers` 페이지와 연결해줘. (필요한 엔드포인트가 부족하면 최소한의 형태로 구현해줘.)

수정 후 `/influencers` 페이지 접근, 인플루언서 찜하기 동작, 레시피/상품 보기 및 기존 페이지(홈, 상품 목록, AI 챗봇) 깨짐 여부가 없는지 확인해줘.
