# 요리명: 떠먹는 송편

## 기본 정보
- 요리 분류: 일품
- 조리 방식: 기타
- 열량(칼로리): 1082.2 kcal
- 나트륨 함량: 724.0 mg

## 필요한 재료
주재료 
배추 60g, 콩가루 25g, 구운 호두 15g, 레몬즙 10g, 청양고추 5g,
양송이버섯 30g, 마늘 10g, 양파 30g, 우유 150g, 생크림 150g, 대파 5g

반죽 재료 
멥쌀가루 180g, 소금 2.5g, 치자가루 5g, 고추기름 10g

양념 
식용유 10g, 통후추 2g, 무염 버터 20g, 통깨 2g, 올리고당 5g

## 조리 순서
1. 멥쌀가루, 소금을 체친다. 3개의 볼에 나누고 2개의 볼에는 각각 치자가루, 고추기름을 넣고 익반죽해 반죽을 만든다., 2. 배추를 다져 3개의 볼에 나누고 콩가루 + 구운 호두(10g), 레몬즙, 청양고추를 각각 넣어 볶은 후 물기를 제거해 송편소를 만든다., 3. 반죽을 45g씩 떼어 치자가루 반죽에는 레몬즙을 넣은 송편소를 넣는다. 고추기름 반죽에는 청양고추를 넣은 송편소를 넣고 나머지 반죽에는 콩가루 + 구운 호두를 넣은 송편소를 넣어 송편을 빚는다., 4. 팬에 식용유를 두르고 송편을 굽는다. 다른 팬에 올리고당, 구운 호두(5g)를 넣고 조린다., 5. 팬에 다진 양송이버섯, 마늘, 양파, 통후추, 무염 버터를 넣어 볶는다. 우유, 생크림을 넣고 함께 끓여 생크림 소스를 만든다., 6. 그릇에 생크림 소스, 구운 송편을 올린다. 다진 대파, 통깨, 올리고당에 조린 호두를 올려 마무리한다.
