# 요리명: 들깨곤약수제비

## 기본 정보
- 요리 분류: 일품
- 조리 방식: 끓이기
- 열량(칼로리): 137.7 kcal
- 나트륨 함량: 51.4 mg

## 필요한 재료
곤약(150g), 표고버섯(1개), 새송이버섯(1개), 들깨가루(200g),
사골육수(400g), 마늘(5g), 식초(0.3g)

## 조리 순서
1. 곤약은 얇게 썬다., 2. 끓는 물에 식초를 한두 방울 넣고, 썰어 놓은 곤약을 데친다., 3. 표고는 불려서 채를 썬다., 4. 마늘을 다져서 냄비에 볶는다., 5. 냄비에 표고버섯과 새송이버섯을 넣고 함께 볶는다., 6. 냄비에 들깨가루와 사골육수를 넣고 끓인 뒤 데친 곤약을 넣은 뒤 한소끔 더 끓인다.
