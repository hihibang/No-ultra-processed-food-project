# 요리명: 새우두부만두

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 찌기
- 열량(칼로리): 397.5 kcal
- 나트륨 함량: 563.2 mg

## 필요한 재료
칵테일 새우 50g, 두부 80g, 부추 10g, 표고버섯, 8g, 소금 1g, 후추 0.25g, 만두피 75g, 간장 1.5g, 식초 0.75g, 물 5g, 고춧가루 0.4g

## 조리 순서
1. 칼등으로 두부를 으깨 면보에 싸서 물기를 짜낸다., 2. 새우, 부추, 표고버섯은 잘게 다진다., 3. 두부에 다진 새우, 부추, 표고버섯, 소금, 후추를 넣어 소를 만든다., 4. 만두피에 소를 10g씩을 올리고 새우 꼬리를 밖으로 나오게 넣고 오므린다., 5. 찜기에 젖은 면보를 깔고 만두를 넣어 7분 간 찐다., 6.  양념장과 함께 곁들여 낸다.
