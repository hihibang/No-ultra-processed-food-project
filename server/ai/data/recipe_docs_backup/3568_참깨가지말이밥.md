# 요리명: 참깨가지말이밥

## 기본 정보
- 요리 분류: 밥
- 조리 방식: 볶기
- 열량(칼로리): 575.9 kcal
- 나트륨 함량: 55.6 mg

## 필요한 재료
1인분기준<br>
[주재료]닭다리살(25g), 닭안심살(30g), 토마토(35g), 방울토마토(15g), 시금치(5g), 양파(10g), 감자(7g), 스파게티면(건면)(5g)<br>
[양념]고추장(5g), 고춧가루(3g), 다진 마늘(3g), 진간장(4g), 알룰로스(4g),

## 조리 순서
1. 가지는 0.3cm 두께로 얇게 썰고 방울토마토, 파프리카, 양파는 잘게 자른다., 2. 손질한 가지는 오븐에 굽는다. (180℃, 10분), 3. 달군 팬에 올리브유(6g)를 두르고 양파를 볶다가 현미밥, 방울토마토, 파프리카를 넣고 볶는다., 4. 채소가 익으면 약한 불로 줄이고 토마토 페이스트, 쿠민가루를 넣어 볶음밥을 만든다., 5. 믹서에 참깨, 올리브유(6g)를 넣어 갈고 요거트, 다진 마늘을 섞어 참깨 소스를 만든다., 6. 구운 가지 위에 볶음밥을 올려 돌돌 말고, 참깨 소스를 얹어 마무리한다.
