# PingPong UI/UX 리팩토링 작업계획

## 프로젝트 개요
- **서비스명**: PingPong (핑퐁)
- **슬로건**: 여러 번의 클릭에서 단 한 번의 선택을 찾다 (Long Click, One Select)
- **목표**: 퀴즈/팝업 없이 자연스러운 상품 둘러보기 경험에서 성분 분석 및 비교 기능 제공

---

## 핵심 UX 철학
사용자에게 별도 질문이나 숙제를 주지 않고, 상품 상세 보기/모달 내에서:
- NOVA 가공등급 기반 성분 분석 제공
- 유사 인기 상품과의 스펙 비교표 제공
- 자연스럽게 최적의 하나(One Select)에 도달하도록 유도

---

### Phase 2: 카탈로그 및 상세보기 컴포넌트 개편
**담당**: 프론트엔드 리팩토링 엔지니어
**예상 기간**: 1주

#### 2-1. 카탈로그 페이지 기본 개편
- [ ] CatalogPage.jsx에 PingPong 브랜딩 톤앤매너 반영
- [ ] CatalogHeader 스타일 업데이트
- [ ] **핵심**: 별도의 핑퐁 팝업/퀴즈 덱 전면 삭제
  - 검색창 및 카탈로그 기능의 자유도 유지
- [ ] 기존 상품 카드 클릭 흐름 유지 (모달 오픈)

#### 2-2. 상세보기/모달에 신규 컴포넌트 추가
- [ ] A. **NOVA & 가치 성분 분석 칩 컴포넌트** 개발
  - NOVA 가공등급 표시 (1~4단계 칼라 칩)
  - 저당, 고단백, 무첨가 뱃지
  - AI 셰프의 한 줄 해석 노트
  
- [ ] B. **유사 상품 스펙 1초 비교표 컴포넌트** 개발 (핵심 UX)
  - 현재 상품 vs 카테고리 유사 대표 상품 비교
  - 비교 항목: 당류, 단백질, NOVA 등급, 조리 도구 적합도
  - AI 핑퐁 팁: 두 상품의 차이점을 한 줄로 요약
  - 목표: 사용자 구매 확신 제공 (One Select)
