# 요리명: 매실동치미

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 기타
- 열량(칼로리): 76.8 kcal
- 나트륨 함량: 79.2 mg

## 필요한 재료
무 50g, 연근 25g, 사과 25g, 배 30g, 함초소금 2g
국물 : 매실청 30g, 생강청 15g, 함초소금 1g, 청양고추 10g

## 조리 순서
1. 무는 모양 틀로 자른다., 2. 무와 연근을 손질해 놓은 후 소금에 살짝 절여준다., 3. 사과와 배는 먹기 좋게 잘라 레몬즙에 뿌려 갈변을 막아준다., 4. 물에 청양고추를 넣어 끓여서 식힌다., 5. 식힌 물에 국물 재료를 넣어 국물을 만든다., 6. 만들어진 국물에 절여진 무, 연근, 사과, 배를 넣어주어 완성한다. 24시간 이후부터 시원하게 먹는다.
