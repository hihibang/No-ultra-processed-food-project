# 요리명: 참나물 매콤함박스테이크

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 굽기
- 열량(칼로리): 99.6 kcal
- 나트륨 함량: 135.5 mg

## 필요한 재료
1인분 기준<br>
[주재료] 참나물(5g), 부침두부(15g), 닭가슴살(40g), 청양고추(2g)<br>
[양념] 올리브유(12g), 고추장(10g), 고춧가루(2g), 알룰로스(5g), 후추(1g), 다진 마늘(4g), 깨(1g), 소금(1g), 물(15m)

## 조리 순서
1. 닭가슴살, 부침두부, 참나물, 청양고추를 잘게 다진다., 2. 볼에 담아 소금으로 밑간하고 4등분하여 둥글게 다져 함박스테이크를 만든다., 3. 달군 팬에 올리브유를 두르고 함박스테이크를 굽는다., 4. 고추장, 고춧가루, 알룰로스, 후추, 다진 마늘, 물을 넣어 소스를 만든다., 5. 달군 팬에 소스를 넣고 살짝 졸인다., 6. 접시에 함박스테이크를 담고 소스를 올린 후 깨를 뿌려 마무리한다.
