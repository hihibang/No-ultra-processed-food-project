# 요리명: 감태샐러드말이와 버섯말이깐풍

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 굽기
- 열량(칼로리): 125.2 kcal
- 나트륨 함량: 120.1 mg

## 필요한 재료
1인분 기준<br>
[주재료] 감태 (2g(2장)), 라이스페이퍼(60g), 양상추(80g), 적채(20g), 건표고버섯(5g), 느타리버섯(10g), 만가닥버섯(10g), 청고추(5g), 홍고추(5g), 대파(5g), 마늘(5g)<br>
[양념] 마요네즈(18g), 홀그레인 머스터드(6g), 파인애플청(6g), 진간장(3g), 굴 소스(6g), 올리고당(10g), 식초(8g), 참기름(6g), 식용유(20g)

## 조리 순서
1. 양상추, 적채는 채 썰어 찬물에 담근다. 마요네즈, 홀그레인 머스터드, 파인애플청을 섞어 샐러드 드레싱을 만든다., 2. 데친 느타리버섯, 만가닥버섯과 불린 건표고버섯의 물기를 제거하고 깍둑 썰기하여 예열한 팬에 볶고 진간장,참기름(3g)으로 간한다., 3. 라이스페이퍼에 올리고 한입 크기로 싼다. 예열한 팬에 식용유(10g)를 두르고 굽는다., 4. 물기를 제거한 양상추, 적채를 라이스페이퍼에 올리고 싼 뒤, 감태 위에 올려 돌돌 말고 한입 크기로 썬다., 5. 예열한 팬에 식용유(10g)를 두르고 다진 청고추, 홍고추, 대파, 마늘을 볶아 향을 내고 굴 소스, 올리고당, 식초, 참기름(3g)을 넣어 깐풍 소스를 만든다., 6. 접시에 담고 샐러드 드레싱과 깐풍 소스를 곁들여 마무리한다.
