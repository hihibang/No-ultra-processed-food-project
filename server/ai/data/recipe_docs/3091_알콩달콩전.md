# 요리명: 알콩달콩전

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 굽기
- 열량(칼로리): 175.5 kcal
- 나트륨 함량: 304.1 mg

## 필요한 재료
병아리콩 10g, 검정콩 10g, 완두콩 10g, 두부 25g, 빨간 파프리카 5g, 찹쌀가루 10g, 밀가루 5g, 소금 0.3g, 물 2ml, 식용유 10g

## 조리 순서
1. 파프리카는 콩 크기의 큐브모양으로 썬다., 2. 준비된 콩들은 물에 불린 후, 각각 끓는 물에 삶은 다음 물기를 제거한다., 3. 두부와 삶은 병아리콩을 으깨준다., 4. ③에 밀가루, 찹쌀가루, 소금, 물을 넣어 반죽한다., 5. 반죽에 콩과 파프리카를 섞는다., 6. 팬에 식용유를 두르고, 반죽의 콩들이 잘 보이도록 먹기 좋은 크기로 부친다.
