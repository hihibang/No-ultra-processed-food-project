# 요리명: 구운 주먹밥

## 기본 정보
- 요리 분류: 밥
- 조리 방식: 굽기
- 열량(칼로리): 335.1 kcal
- 나트륨 함량: 79.4 mg

## 필요한 재료
현미(100g), 톳(30g), 생김(5g), 달걀(50g), 밥 밑간 참기름(4g), 참깨(2g), 톳 무침양념 설탕(2g), 식초(2g)

## 조리 순서
1. 현미로 밥을 지은 뒤 밥 밑간을 넣고 섞는다., 2. 톳에 톳 무침양념을 넣고 버무린다., 3. 밥에 톳을 넣고 버무린다., 4. 밥을 먹기 좋은 크기로 둥글게 뭉친 뒤 부순 생김을 골고루 묻힌다., 5. 주먹밥을 달걀물을 입힌다., 6. 팬에 구워 마무리한다.
