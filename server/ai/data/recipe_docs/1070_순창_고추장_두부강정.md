# 요리명: 순창 고추장 두부강정

## 기본 정보
- 요리 분류: 반찬
- 조리 방식: 튀기기
- 열량(칼로리): 350.3 kcal
- 나트륨 함량: 15.7 mg

## 필요한 재료
소고기(불고기용, 60g), 두부(400g),
새송이버섯(40g), 당근(30g), 양파(10g),
마늘(15g), 생강가루(5g), 고추장(50g),
튀김가루(200g), 전분(20g), 맥주(200ml),
소금(1g), 간장(15g), 꿀(15g), 케첩(45g),
올리고당(15g)

## 조리 순서
1. 당근, 새송이버섯, 소고기, 양파는 가늘게 채 썰어 간장, 꿀, 생강가루, 다진 마늘로 양념한 뒤 볶는다., 2. 두부는 반으로 잘라 속에 칼집을  낸 뒤 소금을 뿌려 수분을 제거한다., 3. 두부에 전분을 골고루 묻힌다., 4. 볶은 야채와 고기를 두부 사이에 넣는다., 5. 튀김가루, 전분, 차가운 맥주를 섞어 튀김 반죽을 만든 뒤 두부에 입혀 170℃기름에 튀긴다., 6. 고추장, 케첩, 올리고당을 섞고 냄비에 졸여 소스를 만들고 튀긴 두부를 지진다.
